## 关于

RoboMME 沿四个任务族评测机器人操作策略的记忆能力：计数（按指定次数重复动作）、物体恒存（追踪被遮挡或调换出视野的物体）、指代（对之前通过视频或高亮指定的目标行动）、模仿（复现演示的动作模式）。每族有独立的成功率指标，使记忆失效可归因。

WorldFoundry 通过仓内闭环仿真适配器 `worldfoundry/evaluation/tasks/embodied/simulators/robomme/`（别名 `robo-mme`）以及共享官方结果归一化器集成 RoboMME。catalog 校验状态为 `normalizer_only`。

官方来源：

- 论文：[arXiv:2603.04639](https://arxiv.org/abs/2603.04639)（catalog `paper_url`）
- 官方仓库：[RoboMME/robomme_policy_learning](https://github.com/RoboMME/robomme_policy_learning)
- 许可：上游条款（见仓库）

## 仓内路径

- Catalog：`worldfoundry/data/benchmarks/catalog/embodied/robomme.yaml`
- 任务清单：`worldfoundry/data/benchmarks/tasks/external/robomme.yaml`
- 运行时 profile：`worldfoundry/data/benchmarks/runtime_profiles/official/robomme.yaml`
- 仿真适配器：`worldfoundry/evaluation/tasks/embodied/simulators/robomme/`
- 闭环 eval config：`worldfoundry/data/benchmarks/eval_configs/embodied/robomme/eval.yaml`
- 结果归一化器：`worldfoundry.evaluation.tasks.embodied.normalizer`（track `vla`）

## 评测协议与数据布局

结果导入侧，embodied normalizer 接受 JSON、JSONL、CSV、TSV 及 `result.txt` 风格日志。行记录按 `success`、`success_rate`、`task_success` 等数值字段匹配；布尔值与百分比字符串会被强制转换为 [0,1] 浮点数。

内置 eval config 串联全部四族，对 `ws://localhost:8000` 上的外部 policy server 以 `joint_angle` 动作空间、1300 步上限、每任务 50 个 episode 运行：计数（`BinFill`、`PickXtimes`、`SwingXtimes`、`StopCube`）、恒存（`VideoUnmask`、`VideoUnmaskSwap`、`ButtonUnmask`、`ButtonUnmaskSwap`）、指代（`PickHighlight`、`VideoRepick`、`VideoPlaceButton`、`VideoPlaceOrder`）、模仿（`MoveCube`、`InsertPeg`、`PatternLock`、`RouteStick`）。

## 指标

主指标（scorecard 主键）：`success_rate`。

| 指标 | 含义 |
| --- | --- |
| `success_rate` | 跨族总体 rollout 成功率；leaderboard 主值。 |
| `counting_success_rate` | 计数族成功率。 |
| `permanence_success_rate` | 物体恒存族成功率。 |
| `reference_success_rate` | 指代族成功率。 |
| `imitation_success_rate` | 模仿族成功率。 |

成功类指标经共享 registry 的 `percent_or_fraction_to_unit` 归一化；不涉及视频生成类指标。

## 准备命令与环境变量

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_ROBOMME_ROOT=/path/to/robomme
export WORLDFOUNDRY_ROBOMME_RESULTS_PATH=/path/to/robomme_results.json
```

闭环 rollout 需要 RoboMME 运行时、记忆任务 assets，以及通过 WebSocket 提供动作的策略 checkpoint（catalog `required_assets`）。

校验运行时接线：

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile robomme \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/robomme.yaml \
  --output-dir tmp/worldfoundry_preflight/robomme \
  --json
```

## 导入官方结果（official-validation）

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id robomme \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_ROBOMME_RESULTS_PATH}" \
  --output-dir tmp/robomme/official-validation \
  --json
```

该路径在进程内走 embodied `vla` track normalizer，不执行任何仿真代码。

## 闭环 rollout（原生仿真器）

```bash
worldfoundry-eval embodied run \
  --config worldfoundry/data/benchmarks/eval_configs/embodied/robomme/eval.yaml \
  --output-dir tmp/robomme/embodied-run \
  --json
```

`embodied run` 入口支持 `--server-url`、`--shard-id`/`--num-shards`、`--no-docker`。

## 输出

- `scorecard.json`：WorldFoundry scorecard；leaderboard 块以 `success_rate` 为主键。
- `raw_results.jsonl`：提取的原始结果行。
- `evaluation/summary.json`：按指标聚合的统计。
- `evaluation/per_sample_metrics.jsonl`：归一化后的逐 episode 行。

## 不能声称的边界

- catalog 状态为 `normalizer_only`，`leaderboard_valid: false`、`official_benchmark_verified: false`。导入的数字是调用方结果的归一化副本，不是官方复现的 leaderboard 值。
- RoboMME 运行时、记忆任务 assets、策略 checkpoint 均未随仓库分发；闭环 rollout 需要外部部署并运行 policy server。本页不声称任何本地 GPU rollout 证据。
- catalog blocker：官方 rollout 执行并导入之前，不声称完整 leaderboard 对齐。
