## About

**Publisher:** Google DeepMind (verified protocol packaged by Anates Labs)

Physics-IQ-Verified is the recommended revision of the Physics-IQ protocol. It fixes prompt/mask inconsistencies found in the original release, ships verified conditioning frames and switch-view metadata as a Hugging Face dataset (`Anates-Labs-Research/Physics-IQ-Verified`), and scores per view before aggregation. The underlying physical-understanding methodology is unchanged from Google DeepMind's Physics-IQ.

WorldFoundry runs it through the same in-tree runner as Physics-IQ with `--protocol physics-iq-verified`, with verified assets tracked under `worldfoundry/data/benchmarks/assets/physics-iq-verified`.

Official references:

- Paper: [arxiv.org/abs/2606.18943](https://arxiv.org/abs/2606.18943)
- Project page: [physics-iq-verified.anates.ai](https://physics-iq-verified.anates.ai/)
- Official repository: [google-deepmind/physics-IQ-benchmark](https://github.com/google-deepmind/physics-IQ-benchmark)

## Evaluation protocol

Per run, 198 generated five-second videos are scored against verified real continuations with per-view masks; the maintainers recommend averaging four runs for leaderboard claims. Import (`--official-results-path raw_metrics.csv`) and recompute (`--run-official`) paths mirror the base protocol.

Primary metric: `physics_iq_verified_score`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `physics_iq_verified_score` | Arithmetic mean after per-scenario, per-view physical-variance normalization. | Higher is better |
| `physics_iq_verified_spatiotemporal` | Spatiotemporal IoU: where and when motion happens vs. the verified real continuation. | Higher is better |
| `physics_iq_verified_spatial` | Spatial IoU: where action happens, regardless of timing. | Higher is better |
| `physics_iq_verified_weighted_spatial` | Weighted spatial IoU: where and how much action happens. | Higher is better |
| `physics_iq_verified_mse` | Pixel-wise MSE against the verified real continuation. | Higher is better |

## Data and artifact layout

In-tree paths:

```text
worldfoundry/data/benchmarks/tasks/external/physics-iq-verified.yaml
worldfoundry/data/benchmarks/assets/physics-iq-verified
worldfoundry/evaluation/tasks/execution/runners/physics_iq
```

Download the verified dataset and stage generated continuations by scenario id:

```bash
hf download Anates-Labs-Research/Physics-IQ-Verified \
  --repo-type dataset \
  --local-dir /path/to/physics-iq-verified

export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/physics-iq-verified/generated_videos
```

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id physics-iq-verified \
  --mode official-validation \
  --official-results-path <raw_metrics.csv> \
  --output-dir <out> \
  --json
```

Recompute verified metrics from generated continuations:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/physics_iq/run_physics_iq_official_runner.py \
  --protocol physics-iq-verified \
  --run-official \
  --dataset-root /path/to/physics-iq-verified \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --output-dir tmp/physics-iq-verified/official-run \
  --strict \
  --json
```

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metrics.csv`
- `official_metrics.json`
- `results_summary.csv`
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.

Scorecard primary key: `physics_iq_verified_score` (leaderboard key `physics_iq_verified_score`), stored in `scorecard.json`.

## Limitations

- Verified media must be pulled from the Hugging Face dataset; nothing is redistributed in tree.
- One run covers 198 videos; leaderboard-grade claims require the recommended four-run average.
- Verified scores are not comparable with original-protocol Physics-IQ scores and are not official leaderboard entries.
