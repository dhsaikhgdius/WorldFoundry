## About

**Publisher:** IIIT Hyderabad, Adobe & IISER Thiruvananthapuram

PhyEduVideo (WACV 2026) evaluates whether text-to-video models can produce accurate educational physics illustrations. Sixty core concepts from seven classical-physics domains (mechanics, waves, thermodynamics, electromagnetism, fluids, optics) are decomposed into granular teaching points, each with a visually descriptive prompt. Upstream scoring combines an InternVL/CLIP/VQA judging stack over the generated videos.

WorldFoundry bundles the prompt manifests and provides a result importer: it normalizes caller-provided PhyEduVideo result files, checks prompt/video coverage, and emits per-sample rows plus the aggregate scorecard.

Official references:

- Paper: [arxiv.org/abs/2601.00943](https://arxiv.org/abs/2601.00943)
- Project page: [meghamariamkm.github.io/phyeduvideo26](https://meghamariamkm.github.io/phyeduvideo26/)
- Official repository: [meghamariamkm/PhyEduVideo](https://github.com/meghamariamkm/PhyEduVideo)

## Evaluation protocol

The in-tree runner is import-only for scoring: `official-validation` (or `--run-official`, which imports a results file for WorldFoundry-generated artifacts) normalizes upstream result exports into the five metric families and verifies coverage against the bundled `Prompts/*.json`. The raw-video InternVL/CLIP/VQA judging stack is not executed in tree.

Primary metric: `phyeduvideo_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `semantic_adherence` | semantic_adherence normalized benchmark score. | Higher is better |
| `physics_commonsense` | physics_commonsense normalized benchmark score. | Higher is better |
| `motion_smoothness` | motion_smoothness normalized benchmark score. | Higher is better |
| `temporal_flickering` | temporal_flickering normalized benchmark score. | Higher is better |
| `phyeduvideo_average` | phyeduvideo_average normalized benchmark score. | Higher is better |

```text
worldfoundry/evaluation/tasks/execution/runners/phyeduvideo/
${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}/                   # candidate videos for coverage checks
```

Result files are caller-supplied; no Hugging Face dataset is required.

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id phyeduvideo \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_PHYEDUVIDEO_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_PHYEDUVIDEO_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `results_summary.csv`
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.

Scorecard primary key: `phyeduvideo_average` (leaderboard key `phyeduvideo_average`), stored in `scorecard.json`.

## Limitations

- Raw-video scoring requires the upstream InternVL/CLIP/VQA judge assets and protocol, which are not run in tree.
- Result import is not official benchmark or leaderboard evidence.
- Coverage checks confirm prompt/video pairing only; they do not validate how upstream scores were produced.
