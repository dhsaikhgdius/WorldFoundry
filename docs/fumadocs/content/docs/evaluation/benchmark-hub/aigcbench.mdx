## About

**Publisher:** BenchCouncil, Institute of Computing Technology, Chinese Academy of Sciences

AIGCBench evaluates image-to-video generation with metric families spanning first-frame fidelity (MSE/SSIM against the conditioning image), image-video and text-video CLIP alignment, reference-video comparisons (keyframe and corresponding-frame CLIP, SSIM), motion strength (optical-flow square mean), temporal coherence (adjacent-frame CLIP), and perceptual quality (DOVER).

WorldFoundry materializes the AIGCBench prompt list from the official Hugging Face dataset, generates candidates through its own model integrations, and imports metric artifacts through the in-tree runner, which writes the standard scorecard. Bundled assets live under `worldfoundry/data/benchmarks/assets/aigcbench`.

Official references:

- Paper: [arxiv.org/abs/2401.01651](https://arxiv.org/abs/2401.01651)
- Project page: [huggingface.co/papers/2401.01651](https://huggingface.co/papers/2401.01651)
- Official repository: [BenchCouncil/AIGCBench](https://github.com/BenchCouncil/AIGCBench)
- License: `apache-2.0`

## Evaluation protocol

The runner imports official metric CSV exports (`--official-results-path`) or WorldFoundry pipeline metric outputs (`--run-official` over staged artifact scores). Reference-image and reference-video metric families require the corresponding official assets; `--prompt-manifest` restricts scoring to a chosen prompt subset and `--strict` fails on coverage gaps.

Primary metric: `aigcbench_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `mse_first` | AIGCBench MSE between the condition image and first generated frame; lower is better. | Lower is better |
| `ssim_first` | AIGCBench SSIM between the condition image and first generated frame. | Higher is better |
| `image_genvideo_clip` | AIGCBench CLIP similarity between condition image and generated video. | Higher is better |
| `genvideo_text_clip` | AIGCBench CLIP similarity between generated video and text prompt. | Higher is better |
| `genvideo_refvideo_clip_keyframes` | AIGCBench CLIP similarity between generated and reference video keyframes. | Higher is better |
| `flow_square_mean` | AIGCBench optical-flow square mean for generated video motion effects. | Higher is better |
| `genvideo_refvideo_clip_corresponding_frames` | AIGCBench CLIP similarity for generated and reference corresponding frames. | Higher is better |
| `genvideo_clip_adjacent_frames` | AIGCBench adjacent-frame CLIP similarity for temporal consistency. | Higher is better |
| `frame_count` | AIGCBench generated video frame count. | Higher is better |
| `dover` | AIGCBench DOVER video quality score. | Higher is better |
| `genvideo_refvideo_ssim` | AIGCBench SSIM between generated and reference videos. | Higher is better |
| `aigcbench_average` | AIGCBench official aggregate when supplied by the official scorer or normalized output. | Higher is better |

## Data and artifact layout

In-tree paths:

```text
worldfoundry/data/benchmarks/tasks/external/aigcbench.yaml
worldfoundry/data/benchmarks/assets/aigcbench
```

```bash
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/aigcbench/generated_videos
export WORLDFOUNDRY_AIGCBENCH_RESULTS_PATH=/path/to/aigcbench_metrics.csv
```

Bundled `prompt_suite.json` supports request materialization without downloading the full dataset; full leaderboard parity uses the official dataset assets.

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id aigcbench \
  --mode official-validation \
  --official-results-path <official_results.csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_AIGCBENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

This benchmark reuses the shared base-model dependency stack: `video_quality_motion_stack`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.

Scorecard primary key: `aigcbench_average` (leaderboard key `aigcbench_average`), stored in `scorecard.json`.

## Limitations

- Reference-dependent metrics (first-frame fidelity, reference-video CLIP/SSIM) are only meaningful with the official reference assets staged.
- Full leaderboard parity requires generated videos for the official prompt suite plus CLIP/DOVER/flow metric outputs.
- A local scorecard is not an official AIGCBench leaderboard result.
