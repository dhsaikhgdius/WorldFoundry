## 简介

**发表机构：** UCLA（联合 Sony AI、Yale、DEVCOM ARL）

WorldBench 诊断世界模型与物理世界的距离。它用 Kubric（PyBullet + Blender）渲染 425 个物理精确场景，覆盖四个概念——运动物理、物体恒存、支撑关系、尺度/透视——每个场景带真值深度、法线、分割与光流。模型从初始帧生成视频续写；SAM2 将首帧物体框传播到生成视频中，并把 mask 与真值仿真对比（前景 mIoU、背景 RMSE）。文本子集另含多选与是/否问题。

WorldFoundry 在仓内以 model-backed runner 实现该 evaluator，作用于 `worldbenchmark/IntuitivePhysics` 数据集，并把常规 mIoU 与公开实现中名为 mIoU 实为 Dice 的兼容值分开报告。

官方参考：

- Paper: [arxiv.org/abs/2601.21282](https://arxiv.org/abs/2601.21282)
- 项目主页: [world-bench.github.io](https://world-bench.github.io/)

## 评测协议

`--run-official` 评测原始生成视频（需要 SAM2.1-hiera-large 权重）或通过 `--predicted-mask-dir` 使用预计算 mask；`--video-only` / `--text-only` 限定赛道，`--answer-manifest` 提供文本答案。兼容导入通过 `WORLDFOUNDRY_WORLDBENCH_RESULTS_PATH` 归一化已有结果文件。帧对齐参数（`--ground-truth-start-frame`、`--generated-skip-frames`）处理条件帧偏移。

主指标是 `foreground_miou`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `foreground_miou` | 按物体、帧、场景平均的常规逐物体 IoU。 | 越高越好 |
| `foreground_dice` | 公开实现名为 mIoU、实际计算的兼容值。 | 越高越好 |
| `background_rmse` | 真值分割标为背景的像素上的 RGBA RMSE。 | 越低越好 |
| `text_based_accuracy` | 可用 WorldBench 文本问题上的严格归一化答案准确率。 | 越高越好 |
| `multiple_choice_accuracy` | 含显式选项列表的问题的准确率。 | 越高越好 |
| `binary_accuracy` | WorldBench 是/否问题的准确率。 | 越高越好 |

## 运行评测

对生成续写运行视频赛道：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/worldbench/run_worldbench_official_runner.py \
  --run-official \
  --video-only \
  --dataset-root "${WORLDFOUNDRY_WORLDBENCH_DATASET_ROOT}" \
  --generated-video-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --sam2-checkpoint "${WORLDFOUNDRY_WORLDBENCH_SAM2_CKPT}" \
  --output-dir tmp/worldbench/video \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_WORLDBENCH_DATASET_ROOT`: 本地官方数据集根目录。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。
- `WORLDFOUNDRY_WORLDBENCH_ANSWER_MANIFEST`
- `WORLDFOUNDRY_WORLDBENCH_SAM2_CKPT`
- `WORLDFOUNDRY_WORLDBENCH_RESULTS_PATH`

共享 checkpoint 资产：`facebook/sam2.1-hiera-large`。

该 benchmark 复用共享 base-model 依赖栈：`worldbench_dataset_assets`, `sam2`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `per_sample_scores.jsonl`: 当结果源包含逐样本数值时写出的逐样本行。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `worldbench_evaluation.json`

Scorecard 主键：`foreground_miou`（leaderboard key `foreground_miou`），写入 `scorecard.json`。

## 边界与限制

- 数据集与 evaluator 包未声明再分发许可；资产以上游为准。
- 公开 evaluator 把 Dice 称作 "mIoU" 且存在未解决的运行缺陷；WorldFoundry 将两种重叠定义分开报告。
- 全量数值对齐与官方提交协议尚未审计。
