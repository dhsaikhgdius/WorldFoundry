## 简介

**发表机构：** Imperial College London（帝国理工学院 Dyson 机器人实验室）

RLBench 来自帝国理工学院 Dyson 机器人实验室，是大规模视觉引导操作评测：在 CoppeliaSim（经 PyRep）中的 Franka Panda 上提供 100+ 手工设计任务，每个任务都可由运动规划器生成无限程序化演示，支持模仿学习、RL 与少样本协议。

WorldFoundry 以官方结果 runner 集成 RLBench：rollout 导出被归一化为统一 scorecard；CoppeliaSim/PyRep 执行保持显式且在上游完成。

官方参考：

- Paper: [arxiv.org/abs/1909.12271](https://arxiv.org/abs/1909.12271)
- 项目主页: [sites.google.com/corp/view/rlbench](https://sites.google.com/corp/view/rlbench)
- 官方仓库: [stepjam/RLBench](https://github.com/stepjam/RLBench)

## 评测协议

WorldFoundry 通过统一的结果导入路径集成该 benchmark：`worldfoundry-eval zoo benchmark-run --mode official-validation` 把调用方提供的官方结果导出（JSON/CSV rollout 汇总）归一化为 WorldFoundry scorecard，不执行模拟器。模拟器执行、策略加载与 rollout 采集仍是使用官方工具完成的显式上游步骤。

主指标是 `success_rate`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `success_rate` | 评测 rollout 上的主成功率（逐 episode 成功比例）。 | 越高越好 |
| `task_success` | 按任务聚合的成功率。 | 越高越好 |
| `episode_success` | 逐 episode 成功指示的聚合值。 | 越高越好 |
| `reward` | 平均 episode 奖励 / 回报。 | 越高越好 |
| `normalized_return` | 归一化 episode 回报。 | 越高越好 |

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/rlbench.yaml
```

```text
<official_results.json>                 # 官方工具产出的 rollout 汇总导出
${WORLDFOUNDRY_RLBENCH_RESULTS_PATH}   # 默认导入路径
```
上游 rollout 需要 CoppeliaSim、PyRep 与 RLBench 任务资产。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id rlbench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_RLBENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_results.jsonl`: 从官方结果导出解析出的归一化行。

Scorecard 主键：`success_rate`（leaderboard key `success_rate`），写入 `scorecard.json`。

## 边界与限制

- WorldFoundry 只归一化所提供的 rollout 结果；不在仓内运行官方模拟器或策略。
- 在用就位的模拟器资产与策略权重执行官方 rollout 并导入之前，不声称完整 leaderboard 对齐。
- 导入的 scorecard 是集成证据，不是 leaderboard 提交。
