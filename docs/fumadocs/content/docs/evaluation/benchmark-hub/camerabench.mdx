## About

**Publisher:** Carnegie Mellon University

CameraBench evaluates camera-motion understanding in video models. Built on a taxonomy of camera-motion primitives designed with cinematographers and refined through expert annotation, it scores models on binary motion classification (average precision / ROC AUC), camera-motion VQA, text/image/group retrieval, and caption quality. In WorldFoundry it can also seed camera-control evaluation prompts and labels for generation-side experiments.

The in-tree integration aggregates prepared CameraBench score directories into the official metric families and imports official result exports; the upstream repos (`sy77777en/CameraBench`, `linzhiqiu/t2v_metrics`) host the actual VLM/SfM scoring stacks.

Official references:

- Paper: [arxiv.org/abs/2504.15376](https://arxiv.org/abs/2504.15376)
- Project page: [linzhiqiu.github.io/papers/camerabench](https://linzhiqiu.github.io/papers/camerabench/)
- Official repository: [sy77777en/CameraBench](https://github.com/sy77777en/CameraBench)
- Official repository: [linzhiqiu/t2v_metrics](https://github.com/linzhiqiu/t2v_metrics)

## Evaluation protocol

Two paths: import an official result export via `--official-results-path`, or aggregate a prepared CameraBench `score_dir` (via `--score-dir` or `WORLDFOUNDRY_CAMERABENCH_SCORE_DIR`) into binary, VQA/retrieval, caption, and aggregate score families. `--task` restricts scoring to one family. Caption GPT judging is opt-in: it only runs when explicitly enabled and needs `OPENAI_API_KEY` (disable with `--no-gpt`).

Primary metric: `camerabench_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `camera_motion_average_precision` | CameraBench binary-classification mean average precision. | Higher is better |
| `camera_motion_roc_auc` | CameraBench binary-classification ROC AUC. | Higher is better |
| `camera_vqa_accuracy` | Mean of CameraBench yes/no binary and question accuracy. | Higher is better |
| `camera_retrieval_accuracy` | Mean of CameraBench text, image, and group retrieval scores. | Higher is better |
| `camera_caption_score` | Mean caption score from official CameraBench caption evaluation outputs. | Higher is better |
| `camerabench_average` | Mean over available official CameraBench metric families. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id camerabench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --benchmark-data-root <camerabench_data_root> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_CAMERABENCH_DATA_ROOT`: Local root of the syCen/CameraBench testset.
- `WORLDFOUNDRY_CAMERABENCH_RESULTS_PATH`: Default official-result path for import mode.
- `WORLDFOUNDRY_CAMERABENCH_SCORE_DIR`: Prepared CameraBench score directory for in-tree aggregation.
- `OPENAI_API_KEY`: Needed only when caption GPT judging is explicitly enabled.

This benchmark reuses the shared base-model dependency stack: `camera_geometry_stack`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `camera_predictions.jsonl`
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `upstream_stdout.log`: Captured stdout of the upstream official scorer.
- `upstream_stderr.log`: Captured stderr of the upstream official scorer.

Scorecard primary key: `camerabench_average` (leaderboard key `camerabench_average`), stored in `scorecard.json`.

## Limitations

- WorldFoundry aggregates prepared score files; VLM/SfM score generation happens upstream and is not source-audited in tree.
- Full leaderboard validation requires source-audited score generation, full-suite CameraBench score files, and the upstream submission protocol.
- Partial `--task` runs are per-family signals, not `camerabench_average`.
