## 简介

**发表机构：** TIGER-Lab（滑铁卢大学）

GenAI-Bench（随 GenAI-Arena 平台发布）衡量自动 judge 与人类偏好的对齐程度。每条记录把同一 prompt 的候选输出配对并附人类偏好标签；judge 的预测按 pairwise accuracy 打分，整体与分任务（图像生成、图像编辑、视频生成）分别统计。

WorldFoundry 通过仓内 runner 把官方 GenAI-Bench 结果导出归一化为 pairwise accuracy 指标与标准 scorecard。

官方参考：

- Paper: [arxiv.org/abs/2406.04485](https://arxiv.org/abs/2406.04485)
- 项目主页: [github.com/TIGER-AI-Lab/GenAI-Bench](https://github.com/TIGER-AI-Lab/GenAI-Bench)
- 官方仓库: [TIGER-AI-Lab/GenAI-Bench](https://github.com/TIGER-AI-Lab/GenAI-Bench)

## 评测协议

结果行必须包含任务字段（`image_generation`、`image_editing` 或 `video_generation`）、人类标签（`human_label`/`human_preference`）与 judge 预测（`prediction`/`judge_prediction`）。`--preference-pairs-path` 提供 pair 清单；`--run-fixture` 用内置 fixture 验证接线。

主指标是 `genai_bench_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `pairwise_accuracy` | GenAI-Bench pairwise accuracy against human preference labels across available tasks. | 越高越好 |
| `image_generation_preference_accuracy` | GenAI-Bench image-generation preference accuracy against human labels. | 越高越好 |
| `image_editing_preference_accuracy` | GenAI-Bench image-editing preference accuracy against human labels. | 越高越好 |
| `video_preference_accuracy` | GenAI-Bench video-generation preference accuracy against human labels. | 越高越好 |
| `genai_bench_average` | Mean of task preference accuracies when task-level labels and predictions are available. | 越高越好 |

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/genai-bench.yaml
```

```bash
export WORLDFOUNDRY_GENAI_BENCH_RESULTS_PATH=/path/to/genai_bench_results.jsonl
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/generated_artifacts
```

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id genai-bench \
  --mode official-validation \
  --official-results-path <official_results.jsonl> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_GENAI_BENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。

该 benchmark 复用共享 base-model 依赖栈：`genai_bench_dataset_assets`, `t2v_metrics_source_assets`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。

Scorecard 主键：`genai_bench_average`（leaderboard key `genai_bench_average`），写入 `scorecard.json`。

## 边界与限制

- 这是 judge 对齐评测：它把预测与人类偏好标签对比打分，本身不生成偏好数据。
- Leaderboard 级结论需要官方人类偏好标签（或 judge 输出）以及对应的生成产物。
- 本地 scorecard 不是 GenAI-Arena leaderboard 条目。
