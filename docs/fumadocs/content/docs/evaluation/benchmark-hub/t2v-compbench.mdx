## About

**Publisher:** The University of Hong Kong (with CUHK & Huawei Noah's Ark Lab)

T2V-CompBench is the first benchmark dedicated to *compositional* text-to-video generation: binding the right attributes, actions, and motions to the right objects. Its 1,400 prompts (200 per category) cover consistent attribute binding, dynamic attribute binding, spatial relationships, motion binding, action binding, object interactions, and generative numeracy. Categories are scored by three metric types validated against human judgment: MLLM-based (LLaVA-style video judging), detection-based (GroundingDINO plus depth/SAM for spatial and numeracy categories), and tracking-based (DOT for motion binding).

WorldFoundry vendors the T2V-CompBench runtime in tree. A strict model-artifact manifest bridge stages generated videos into the official `category/NNNN.mp4` layout; the in-tree official `generative_numeracy` evaluator has been executed on a real MP4 (scorecard records `official_component_verified=true`), and the runner can normalize official CSV outputs or execute other categories when their metric assets are prepared.

Official references:

- Paper: [arxiv.org/abs/2407.14505](https://arxiv.org/abs/2407.14505)
- Project page: [t2v-compbench-2025.github.io](https://t2v-compbench-2025.github.io/)
- Official repository: [KaiyueSun98/T2V-CompBench](https://github.com/KaiyueSun98/T2V-CompBench)

## Evaluation protocol

Generated videos need the persisted generation manifest (or the exact official `category/NNNN.mp4` layout). `--category` selects one category; `generative_numeracy` needs a local GroundingDINO checkpoint plus a BERT-compatible text encoder; the four MLLM categories need LLaVA-compatible weights; `motion_binding` needs DOT and `--run-motion-two-stage`; spatial categories need Depth-Anything/SAM assets. `--preflight` validates assets before execution.

Primary metric: `t2v_compbench_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `consistent_attribute_binding` | T2V-CompBench MLLM score for binding static attributes to the correct objects. | Higher is better |
| `dynamic_attribute_binding` | T2V-CompBench MLLM score for temporal attribute changes and bindings. | Higher is better |
| `spatial_relationships` | T2V-CompBench detection/depth score for 2D and 3D spatial relationships. | Higher is better |
| `motion_binding` | T2V-CompBench tracking score for foreground/background motion binding. | Higher is better |
| `action_binding` | T2V-CompBench MLLM score for action-object binding. | Higher is better |
| `object_interactions` | T2V-CompBench MLLM score for interaction consistency between objects. | Higher is better |
| `generative_numeracy` | T2V-CompBench detection score for generated object counts. | Higher is better |
| `t2v_compbench_average` | Mean emitted only when all seven official T2V-CompBench category scores are available. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id t2v-compbench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_T2V_COMPBENCH_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_T2V_COMPBENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_T2V_COMPBENCH_GROUNDINGDINO_CKPT`: GroundingDINO checkpoint for detection-based categories.
- `WORLDFOUNDRY_T2V_COMPBENCH_LLAVA_MODEL_PATH`: LLaVA-compatible MLLM weights for the four MLLM categories.
- `WORLDFOUNDRY_T2V_COMPBENCH_SAM_CKPT`: SAM checkpoint for spatial-category segmentation.

This benchmark reuses the shared base-model dependency stack: `grounded_depth_segmentation_stack`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `leaderboard_csv_manifest.json`
- `generated_video_manifest.json`
- `dataset_manifest.json`
- `upstream_stdout.log`: Captured stdout of the upstream official scorer.
- `upstream_stderr.log`: Captured stderr of the upstream official scorer.

Scorecard primary key: `t2v_compbench_average` (leaderboard key `t2v_compbench_average`), stored in `scorecard.json`.

## Limitations

- Full-suite verification requires all 1,400 generated videos (200 × 7 categories), not the bounded one-video component run.
- The MLLM categories need a compatible LLaVA runtime/checkpoint; motion_binding needs DOT; other detection paths need category-specific depth/SAM assets.
- `t2v_compbench_average` is emitted only when all seven official category scores are available; full official benchmark and leaderboard parity have not been executed.
