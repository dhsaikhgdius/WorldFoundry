## About

**Publisher:** Koç University (Cyberiada Lab, KUIS AI)

PhysVidBench evaluates physical commonsense in text-to-video generation through a caption-mediated QA protocol: candidate videos are first captioned (upstream uses AuroraCap), then an LLM judge answers physics-grounded yes/no questions about each caption. Score families cover affordance understanding, tool-use consistency, material-property consistency, and temporal dynamics, aggregated into `physvidbench_average`.

WorldFoundry bundles the official `prompts_questions.csv` and caption tracks, and can run Gemini QA over caller-supplied captions or normalize prepared QA results into a scorecard.

Official references:

- Paper: [arxiv.org/abs/2507.15824](https://arxiv.org/abs/2507.15824)
- Project page: [cyberiada.github.io/PhysVidBench](https://cyberiada.github.io/PhysVidBench/)
- Official repository: [ensanli/PhysVidBenchCode](https://github.com/ensanli/PhysVidBenchCode)
- License: `cc-by-4.0`

## Evaluation protocol

Two supported paths:

- **Result import** (`official-validation`): normalize an upstream `output.csv` QA export into the WorldFoundry metric surface.
- **Bounded caption QA** (`--run-official`): run the in-tree Gemini QA component over caller-supplied caption tracks against the bundled question set. Candidate-video captioning itself is *not* executed in tree — WorldFoundry cannot prove supplied captions came from your videos.

Select the judge backend with `WORLDFOUNDRY_PHYSVIDBENCH_JUDGE_BACKEND`.

Primary metric: `physvidbench_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `physical_commonsense_accuracy` | Overall physical commonsense QA accuracy. | Higher is better |
| `affordance_understanding` | Affordance and interaction understanding score. | Higher is better |
| `tool_use_consistency` | Tool-mediated physical interaction consistency. | Higher is better |
| `material_property_consistency` | Material property consistency. | Higher is better |
| `temporal_dynamics_consistency` | Physical temporal dynamics consistency. | Higher is better |
| `physvidbench_average` | Mean over available physical commonsense score families. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id physvidbench \
  --mode official-validation \
  --official-results-path <output.csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

Run the bounded caption-QA component over bundled captions:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/physvidbench/run_physvidbench_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --captions-dir worldfoundry/data/benchmarks/assets/physvidbench/captions \
  --output-dir tmp/physvidbench/official \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_PHYSVIDBENCH_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_PHYSVIDBENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.
- `WORLDFOUNDRY_PHYSVIDBENCH_JUDGE_BACKEND`: Selects the QA judge backend (Gemini vs. mock wiring).

This benchmark reuses the shared base-model dependency stack: `physvidbench_dataset_assets`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `output.csv`
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.

Scorecard primary key: `physvidbench_average` (leaderboard key `physvidbench_average`), stored in `scorecard.json`.

## Limitations

- AuroraCap caption generation from candidate videos, and caption provenance, are not implemented in tree.
- Gemini QA over supplied captions — and every mock run — is not official benchmark or leaderboard evidence.
- Only upstream-produced full-pipeline results imported through `official-validation` carry official weight.
