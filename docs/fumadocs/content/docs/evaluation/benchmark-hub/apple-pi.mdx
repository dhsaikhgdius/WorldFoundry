## About

**Publisher:** S-Lab, Nanyang Technological University & CUHK

Apple-PI (Apple-π) anchors video-model evaluation explicitly in physical laws. Built on Orchard — 400 classical-mechanics videos from Isaac Sim simulation, lab recordings, and internet footage — it runs a three-stage scientific-reasoning protocol via chain-of-frames prompting: Perception (read physical quantities / ground objects), Formulation (select the governing law / predict the state at a target time), and Deduction (generate the full law-consistent trajectory). Perception and Formulation each split into text and graphic subtracks, giving five subtracks total. Scoring is hybrid: Gemini-based subjective judging plus physics-grounded objective metrics (SAM3 segmentation/tracking, MoGe depth, trajectory overlap, velocity error).

WorldFoundry integrates Apple-PI as a model-backed in-tree runner that consumes upstream-format GT and prediction directories and reuses existing SAM3/MoGe capability paths for the objective metrics.

## Evaluation protocol

Predictions follow the upstream contract: three independent rollouts per case and subtrack, frame 0 as the conditioning frame. The runner selects subtracks with `--subtrack` (`perception_text`, `perception_graphic`, `formulation_text`, `formulation_graphic`, `deduction`) and the protocol with `--protocol`. Subjective judging uses Gemini (`--gemini-model`, `--judge-backend`); objective metrics load SAM3 and MoGe-2 checkpoints. `--no-foundation-models` skips the model-backed objective metrics for wiring checks.

Primary metric: `deduction`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `perception_text` | Final-frame text annotation artifact score. | Higher is better |
| `perception_graphic` | Final-frame object-only grounding artifact score. | Higher is better |
| `formulation_text` | Governing-law and formula answer score. | Higher is better |
| `formulation_graphic` | Target-time state, velocity-arrow, and label score. | Higher is better |
| `deduction` | Full-dynamics trajectory score combining upstream subjective and objective evaluation. | Higher is better |
| `apple_pi_average` | Arithmetic mean of the available Apple-PI subtrack means. | Higher is better |

## Run the benchmark

Evaluate the deduction subtrack against a staged GT directory:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/apple_pi/run_apple_pi_official_runner.py \
  --run-official \
  --gt-dir "${WORLDFOUNDRY_APPLE_PI_GT_DIR}" \
  --pred-dir "${WORLDFOUNDRY_APPLE_PI_PREDICTION_DIR}" \
  --subtrack deduction \
  --output-dir tmp/apple_pi/deduction \
  --json
```

## Checkpoints and environment variables

Full evaluation needs a Gemini API key for subjective judging; SAM3 and MoGe-2 checkpoints ride the existing WorldFoundry capability paths.

- `WORLDFOUNDRY_APPLE_PI_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_APPLE_PI_GT_DIR`
- `WORLDFOUNDRY_APPLE_PI_PREDICTION_DIR`
- `WORLDFOUNDRY_APPLE_PI_JUDGE_BACKEND`
- `WORLDFOUNDRY_APPLE_PI_SAM3_CHECKPOINT`
- `WORLDFOUNDRY_APPLE_PI_MOGE_CHECKPOINT`

Shared checkpoint assets: `sam3`, `moge_v2_vitl_normal`.

This benchmark reuses the shared base-model dependency stack: `sam3`, `moge_v2_vitl_normal`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).

Scorecard primary key: `deduction` (leaderboard key `deduction`), stored in `scorecard.json`.

## Limitations

- The upstream GT dataset is documented but was not public at integration time; full-suite official execution and leaderboard parity are unverified in this workspace.
- SAM3 and MoGe-2 objective metrics require their checkpoints and a compatible environment.
- Wiring runs with `--no-foundation-models` or mock judges are not benchmark evidence.
