## About

**Publisher:** Stanford, UC Berkeley & USC (maintained by Farama Foundation)

Meta-World (CoRL 2019) is the standard benchmark for multi-task and meta reinforcement learning in manipulation: 50 distinct MuJoCo tabletop tasks with a Sawyer arm, organized into the MT1/MT10/MT50 multi-task and ML1/ML10/ML45 meta-learning suites. Originally from Stanford/Berkeley/USC researchers, it is now maintained by the Farama Foundation.

WorldFoundry integrates Meta-World as an official-results runner: result JSON/CSV exports are normalized into the unified scorecard with the MT/ML suite mapping declared by the caller.

Official references:

- Paper: [arxiv.org/abs/1910.10897](https://arxiv.org/abs/1910.10897)
- Project page: [meta-world.github.io](https://meta-world.github.io/)
- Official repository: [Farama-Foundation/Metaworld](https://github.com/Farama-Foundation/Metaworld)
- License: `mit`

## Evaluation protocol

WorldFoundry integrates this benchmark through the unified result-import path: `worldfoundry-eval zoo benchmark-run --mode official-validation` normalizes a caller-provided official result export (JSON/CSV rollout summaries) into the WorldFoundry scorecard without executing the simulator. Simulator execution, policy loading, and rollout collection remain explicit upstream steps performed with the official tooling.

Primary metric: `success_rate`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `success_rate` | Primary episode success rate over evaluated rollouts. | Higher is better |
| `task_success` | Per-task success aggregate. | Higher is better |
| `reward` | Mean episode reward / return. | Higher is better |
| `normalized_return` | Normalized episode return. | Higher is better |

## Data and artifact layout

In-tree paths:

```text
worldfoundry/data/benchmarks/tasks/external/metaworld.yaml
```

```text
<official_results.json>                 # rollout summary export from the official tooling
${WORLDFOUNDRY_METAWORLD_RESULTS_PATH}   # default import path
```
Requires the official Meta-World package and a MuJoCo-compatible runtime for upstream rollouts.

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id metaworld \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_METAWORLD_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `raw_results.jsonl`: Normalized rows parsed from the official result export.

Scorecard primary key: `success_rate` (leaderboard key `success_rate`), stored in `scorecard.json`.

## Limitations

- WorldFoundry normalizes supplied rollout results; it does not run the official simulator or policies in tree.
- Full leaderboard parity is not claimed until official rollouts are executed with staged simulator assets and policy checkpoints, then imported.
- Imported scorecards are integration evidence, not leaderboard submissions.
