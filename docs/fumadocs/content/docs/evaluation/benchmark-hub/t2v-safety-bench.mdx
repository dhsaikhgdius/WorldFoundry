## About

**Publisher:** Chinese Academy of Sciences & Tsinghua University (with RealAI)

T2VSafetyBench is the first comprehensive safety benchmark for text-to-video models. It defines 4 primary categories with 14 critical aspects of video-generation safety — pornography, borderline pornography, violence, gore, public figures, discrimination, political sensitivity, illegal activities, disturbing content, misinformation, copyright, and the video-specific *temporal risk* (unsafe content that only emerges across frames) — over a malicious prompt dataset built from real-world prompts, LLM-generated prompts, and jailbreak attacks. Videos are judged NSFW/safe per aspect by GPT, with high correlation to manual review; every metric is a lower-is-better NSFW rate.

WorldFoundry supports both official-result import and strict prompt-to-video staging into the checked-in GPT judge, with command construction, staging, failure semantics, and normalization tested without treating a mocked API as metric evidence.

## Evaluation protocol

Import mode normalizes an official result export via `WORLDFOUNDRY_T2V_SAFETY_BENCH_RESULTS_PATH` / `--official-results-path`. Judge mode stages generated videos against the selected prompt class (`--classes`, `--prompt-path`) and drives the checked-in upstream GPT evaluation prompt (`--gpt-model`, `--api-base`); `--limit` bounds integration runs. `nsfw_average` is the primary scorecard key.

Primary metric: `nsfw_average`.

Official prompt classes ship with the source repository; no Hugging Face dataset is required.

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id t2v-safety-bench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_T2V_SAFETY_BENCH_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_T2V_SAFETY_BENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.
- `WORLDFOUNDRY_T2V_SAFETY_BENCH_GPT_API_KEY`: API key for the GPT judge (falls back to OPENAI_API_KEY).
- `WORLDFOUNDRY_T2V_SAFETY_BENCH_GPT_MODEL`: Judge model override for the GPT evaluation.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.

Scorecard primary key: `nsfw_average` (leaderboard key `nsfw_average`), stored in `scorecard.json`.

## Limitations

- Real judge execution requires user-supplied API credentials; it was not run during release validation.
- Full validation requires every generated video in all official prompt classes.
- Leaderboard parity requires the same judge model and protocol used by the benchmark authors; mocked-API runs are never metric evidence.
