## 关于

MolmoSpaces-Bench 在 AllenAI MolmoBot 栈的程序化生成抓放场景上评测具身操作策略。内置配置面向 `FrankaPickandPlaceHardBench` episode 集（ProcTHOR/Objaverse 场景上的 200 个 episode），使用 Franka 机械臂、腕部相机观测与本体感知状态流。

WorldFoundry 通过仓内闭环仿真适配器 `worldfoundry/evaluation/tasks/embodied/simulators/molmospaces/`（别名 `molmo-spaces`、`molmospaces-bench`）以及共享官方结果归一化器集成 MolmoSpaces-Bench。catalog 校验状态为 `normalizer_only`。

官方来源：

- 论文：[arXiv:2603.16861](https://arxiv.org/abs/2603.16861)（catalog `paper_url`）
- 官方仓库：[allenai/MolmoBot](https://github.com/allenai/MolmoBot)
- 许可：上游条款（见仓库）

## 仓内路径

- Catalog：`worldfoundry/data/benchmarks/catalog/embodied/molmospaces.yaml`
- 任务清单：`worldfoundry/data/benchmarks/tasks/external/molmospaces.yaml`
- 运行时 profile：`worldfoundry/data/benchmarks/runtime_profiles/official/molmospaces.yaml`
- 仿真适配器：`worldfoundry/evaluation/tasks/embodied/simulators/molmospaces/`
- 闭环 eval config：`worldfoundry/data/benchmarks/eval_configs/embodied/molmospaces/pick_and_place.yaml`
- 结果归一化器：`worldfoundry.evaluation.tasks.embodied.normalizer`（track `vla`）

## 评测协议与数据布局

结果导入侧，embodied normalizer 接受 JSON、JSONL、CSV、TSV 及 `result.txt` 风格日志。行记录按 `success`、`success_rate`、`task_success`、`pick_success_rate`、`reward` 等数值字段匹配；布尔值与百分比字符串会被强制转换为 [0,1] 浮点数。

内置 eval config 把 `benchmark_dir` 指向部署在 `/assets/benchmarks/molmospaces-bench-v2/procthor-objaverse/` 下的 `FrankaPickandPlaceHardBench` 200-episode JSON 基准，使用 `olmo.eval.configure_molmo_spaces` 的 `FrankaState8ClampAbsPosConfig` eval-config 类，推送腕部图像与状态，最多 200 个任务、每任务 1 个 episode、时程 600 步，policy server 超时 600 秒（`ws://localhost:8000`）。

## 指标

主指标（scorecard 主键）：`success_rate`。

| 指标 | 含义 |
| --- | --- |
| `success_rate` | 成功完成的 episode 占比；leaderboard 主值。 |
| `pick_success_rate` | 有上报时，限定在抓取阶段的成功率。 |
| `task_success` | 按任务的成功指示。 |
| `reward` | 有定义时的 episode 累计奖励。 |

成功类指标经共享 registry 的 `percent_or_fraction_to_unit` 归一化；不涉及视频生成类指标。

## 准备命令与环境变量

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_MOLMOSPACES_ROOT=/path/to/MolmoBot
export WORLDFOUNDRY_MOLMOSPACES_RESULTS_PATH=/path/to/molmospaces_results.json
```

运行时 profile 标记 `needs_new_env: true`，并建议只部署所选的 MolmoSpaces-Bench 子集——完整公开 asset 库非常大。闭环 rollout 还需要 MolmoSpaces 运行时、基准子集 assets，以及通过 WebSocket 提供动作的策略 checkpoint（catalog `required_assets`）。

校验运行时接线：

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile molmospaces \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/molmospaces.yaml \
  --output-dir tmp/worldfoundry_preflight/molmospaces \
  --json
```

## 导入官方结果（official-validation）

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id molmospaces \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_MOLMOSPACES_RESULTS_PATH}" \
  --output-dir tmp/molmospaces/official-validation \
  --json
```

该路径在进程内走 embodied `vla` track normalizer，不执行任何仿真代码。

## 闭环 rollout（原生仿真器）

```bash
worldfoundry-eval embodied run \
  --config worldfoundry/data/benchmarks/eval_configs/embodied/molmospaces/pick_and_place.yaml \
  --output-dir tmp/molmospaces/embodied-run \
  --json
```

修改 config 中的 `benchmark_dir`（或复制一份）指向你部署的 asset 路径。支持 `--server-url`、`--shard-id`/`--num-shards`、`--no-docker`。

## 输出

- `scorecard.json`：WorldFoundry scorecard；leaderboard 块以 `success_rate` 为主键。
- `raw_results.jsonl`：提取的原始结果行。
- `evaluation/summary.json`：按指标聚合的统计。
- `evaluation/per_sample_metrics.jsonl`：归一化后的逐 episode 行。

## 不能声称的边界

- catalog 状态为 `normalizer_only`，`leaderboard_valid: false`、`official_benchmark_verified: false`。导入的数字是调用方结果的归一化副本，不是官方复现的 leaderboard 值。
- MolmoSpaces 基准 assets 与策略 checkpoint 均未随仓库分发（完整 asset 库非常大）；闭环 rollout 需要外部部署并运行 policy server。本页不声称任何本地 GPU rollout 证据。
- catalog blocker：官方 rollout 执行并导入之前，不声称完整 leaderboard 对齐。
