## About

**Publisher:** Central South University (CSU-JPG Group)

MIND evaluates memory consistency and action control in interactive world models through open-domain closed-loop *revisit* protocols: the model rolls out under camera/action commands, leaves a region, and returns — its continuation is compared against ground truth (long-context memory: PSNR/SSIM/LPIPS/MSE plus DINOv3 patch-token MSE), while a *mirror test* plays a rollout and its time-reversed half to score general scene consistency. Action control is measured as relative pose error between ViPE-estimated trajectories of generated and ground-truth videos; visual quality uses MUSIQ-SPAQ and the LAION aesthetic predictor.

WorldFoundry vendors the MIND metric runtime and drives it with `run_mind_official_runner.py`: `--run-official` computes metrics from a staged MIND-Data ground-truth root and model outputs; `--official-results-path` normalizes an existing MIND result JSON; `--run-fixture` keeps the normalizer testable without GPUs.

Official references:

- Paper: [arxiv.org/abs/2602.08025](https://arxiv.org/abs/2602.08025)
- Project page: [csu-jpg.github.io/MIND.github.io](https://csu-jpg.github.io/MIND.github.io/)
- Official repository: [CSU-JPG/MIND](https://github.com/CSU-JPG/MIND)

## Evaluation protocol

Model outputs follow `<model>/{1st,3rd}_data/<test_type>/<name>/video.mp4`. `--run-official` needs `--gt-root <MIND-Data>`, `--generated-artifact-dir`, and `--dino-path <dinov3_vitb16>`; the action metric additionally needs a ViPE checkout via `--vipe-repo` plus the `vipe` CLI. `--metrics` selects metric groups; all mutable state (work dir, `MIND_CACHE_DIR`, staged links, logs) is written under `--output-dir` — the vendored runtime stays read-only.

Primary metric: `mind_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `lcm_psnr` | Long-context-memory PSNR between the predicted continuation and the ground-truth frames. | Higher is better |
| `lcm_ssim` | Long-context-memory SSIM against the ground-truth continuation. | Higher is better |
| `lcm_lpips` | Long-context-memory LPIPS (AlexNet) against the ground-truth continuation; lower is better. | Lower is better |
| `lcm_mse` | Long-context-memory pixel MSE against the ground-truth continuation; lower is better. | Lower is better |
| `dino_mse` | MSE between L2-normalized DINOv3 patch tokens of predicted and ground-truth frames; lower is better. | Lower is better |
| `imaging_quality` | MUSIQ-SPAQ imaging quality of the generated frames, divided by 100 upstream. | Higher is better |
| `aesthetic_quality` | LAION CLIP ViT-L/14 aesthetic predictor score, divided by 10 upstream. | Higher is better |
| `action_rpe_trans_mean` | Mean translation relative pose error between the ViPE trajectories of generated and ground-truth videos; lower is better. | Lower is better |
| `action_rpe_rot_mean_deg` | Mean rotation relative pose error in degrees between the ViPE trajectories; lower is better. | Lower is better |
| `action_rpe_trans_median` | Median translation relative pose error over all valid action steps; lower is better. | Lower is better |
| `action_rpe_rot_median_deg` | Median rotation relative pose error in degrees over all valid action steps; lower is better. | Lower is better |
| `action_translation_rpe_trans_mean` | Mean translation RPE restricted to pure translation actions; lower is better. | Lower is better |
| `action_rotation_rpe_rot_mean_deg` | Mean rotation RPE in degrees restricted to pure camera-rotation actions; lower is better. | Lower is better |
| `gsc_psnr` | General scene consistency PSNR between a mirror-test rollout and its time-reversed half. | Higher is better |
| `gsc_ssim` | General scene consistency SSIM on the mirror-test rollout. | Higher is better |
| `gsc_lpips` | General scene consistency LPIPS on the mirror-test rollout; lower is better. | Lower is better |
| `gsc_mse` | General scene consistency pixel MSE on the mirror-test rollout; lower is better. | Lower is better |
| `memory_consistency_score` | WorldFoundry-derived mean of the normalized LCM and DINOv3 component metrics. | Higher is better |
| `visual_quality_score` | WorldFoundry-derived mean of the normalized imaging and aesthetic metrics. | Higher is better |
| `action_control_score` | WorldFoundry-derived mean of the normalized overall RPE translation and rotation metrics. | Higher is better |
| `scene_consistency_score` | WorldFoundry-derived mean of the normalized mirror-test GSC metrics. | Higher is better |
| `mind_average` | WorldFoundry-derived mean of the available MIND ability-group scores. MIND publishes no official composite score, so this is never a leaderboard number. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
python worldfoundry/evaluation/tasks/execution/runners/mind/run_mind_official_runner.py \
  --run-fixture \
  --output-dir <out> \
  --json
```

Execute the in-tree MIND metric runtime over staged ground truth and model outputs:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/mind/run_mind_official_runner.py \
  --run-official \
  --gt-root /path/to/MIND-Data \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --dino-path /path/to/dinov3_vitb16 \
  --output-dir tmp/mind/official \
  --json
```

## Checkpoints and environment variables

The lcm/visual/dino/gsc metrics need CUDA plus LPIPS/torchmetrics/pyiqa/CLIP assets; the action metric needs the ViPE CLI and checkout.

- `WORLDFOUNDRY_MIND_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_MIND_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

Shared checkpoint assets: `facebook/dinov3-vitb16-pretrain-lvd1689m` (metric_weights).

This benchmark reuses the shared base-model dependency stack: `video_world_perception_stack`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).

Scorecard primary key: `mind_average` (leaderboard key `mind_average`), stored in `scorecard.json`.

## Limitations

- `mind_average` is a WorldFoundry-derived aggregate: MIND publishes no official composite score, so it is never a leaderboard number.
- Leaderboard-valid scores require the complete official split and a published MIND leaderboard (not yet open).
- The DINOv3 checkpoint is never vendored in tree; supply it via `--dino-path` or `<weights-dir>/dinov3_vitb16`.
