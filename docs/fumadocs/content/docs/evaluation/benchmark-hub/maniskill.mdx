## About

ManiSkill is a large-scale robot manipulation benchmark and framework built on the SAPIEN simulator. It provides GPU-parallelized environments spanning pick-and-place, articulated-object interaction, and dexterous manipulation, with standardized policy evaluation by rollout success rate across task suites.

WorldFoundry tracks the `maniskill` catalog id as an official result normalizer: caller-provided rollout result files are converted into WorldFoundry scorecards. In the in-tree simulator registry, `maniskill` is an alias of the ManiSkill2 adapter (`worldfoundry/evaluation/tasks/embodied/simulators/maniskill2/`), so closed-loop rollouts run through the [ManiSkill2](/docs/evaluation/benchmark-hub/maniskill2) eval config. The catalog verification status is `normalizer_only`.

## In-tree integration

- Catalog: `worldfoundry/data/benchmarks/catalog/embodied/maniskill.yaml`
- Task manifest: `worldfoundry/data/benchmarks/tasks/external/maniskill.yaml`
- Runtime profile: `worldfoundry/data/benchmarks/runtime_profiles/official/maniskill.yaml`
- Simulator adapter: `worldfoundry/evaluation/tasks/embodied/simulators/maniskill2/` (alias `maniskill`)
- Result normalizer: `worldfoundry.evaluation.tasks.embodied.normalizer` (track `vla`)

## Evaluation protocol and result layout

The embodied normalizer accepts JSON, JSONL, CSV, TSV, and `result.txt`-style logs. Rows are matched on numeric fields such as `success`, `success_rate`, `task_success`, `reward`, and `normalized_return`; booleans and percent strings are coerced to unit-interval floats, and episode identity is read from `sample_id`/`episode_id`/`task_id`/`task`/`id`/`name`.

Producing the raw results requires the official ManiSkill repository checkout (cached at `cache/vla_va_wam/repos/haosulab--ManiSkill`), SAPIEN/ManiSkill simulator assets, a policy checkpoint or controller, and an explicit task suite selection (catalog `requires`).

## Metrics

Primary metric (scorecard key): `success_rate`.

| Metric | Meaning |
| --- | --- |
| `success_rate` | Share of rollouts completed successfully; primary leaderboard value. |
| `task_success` | Per-task success aggregated across episodes. |
| `reward` | Cumulative episode reward. |
| `normalized_return` | Return normalized against task-specific reference ranges, when reported. |

Success metrics are normalized via the shared registry (`percent_or_fraction_to_unit`). No video-generation metrics apply.

## Preparation and environment

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_MANISKILL_RESULTS_PATH=/path/to/maniskill_results.json
```

The runtime profile notes that ManiSkill/SAPIEN imports are visible in the checked environment (`needs_new_env: false`), but full official status still requires task suites, assets, and policy rollouts, which are not executed in this tree.

Verify runtime wiring:

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile maniskill \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/maniskill.yaml \
  --output-dir tmp/worldfoundry_preflight/maniskill \
  --json
```

## Import official results (official-validation)

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id maniskill \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_MANISKILL_RESULTS_PATH}" \
  --output-dir tmp/maniskill/official-validation \
  --json
```

This routes through the embodied `vla`-track normalizer in-process; no simulator code is executed.

## Closed-loop rollouts (via the ManiSkill2 adapter)

There is no `maniskill`-specific eval config; the bundled closed-loop config lives under the `maniskill2` id:

```bash
worldfoundry-eval embodied run \
  --config worldfoundry/data/benchmarks/eval_configs/embodied/maniskill2/eval.yaml \
  --output-dir tmp/maniskill2/embodied-run \
  --json
```

See the [ManiSkill2](/docs/evaluation/benchmark-hub/maniskill2) page for the task list and requirements.

## Outputs

- `scorecard.json`: WorldFoundry scorecard; leaderboard block keyed by `success_rate`.
- `raw_results.jsonl`: extracted raw result rows.
- `evaluation/summary.json`: aggregated per-metric statistics.
- `evaluation/per_sample_metrics.jsonl`: normalized per-episode rows.

## What this page does not claim

- Catalog status is `normalizer_only` with `leaderboard_valid: false` and `official_benchmark_verified: false`. Imported numbers are normalized copies of caller-provided results, not officially reproduced leaderboard values.
- SAPIEN/ManiSkill simulator assets and policy checkpoints are not bundled; closed-loop rollouts require external staging plus a policy server. No local GPU rollout evidence is claimed.
- Official ManiSkill task suite, simulator assets, and policy rollout result mapping must be validated before integrated status (catalog blocker).
