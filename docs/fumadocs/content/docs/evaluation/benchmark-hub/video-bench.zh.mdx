## 简介

**发表机构：** Shanghai Jiao Tong University（上海交通大学，联合新加坡国立大学、CMU、斯坦福等）

Video-Bench（CVPR 2025）用与人类偏好对齐的 MLLM judge 评测生成视频。其维度分两族：视频质量（成像质量、美学、时序一致性、运动效果，1-5 分制）与视频-条件对齐（整体视频-文本一致性 1-5 分；物体类别、颜色、动作、场景一致性 1-3 分）。few-shot 评分与 chain-of-query 技术让 GPT-4o judge 输出结构化、与人工高度相关的评估；官方还发布了用于校准的人工标注数据集。

WorldFoundry 内置 Video-Bench runtime 并做了包装：官方 `*_score_results.json` 输出按 1-5 / 1-3 分制映射到 0-1 归一化；runtime 执行把解析出的生成视频目录传给官方 `evaluate.py`；`VideoBench_full.json` 不可用时从人工标注 JSON 重建 prompt 元数据；私有临时配置由环境变量生成，不改动上游 `config.json`。

## 评测协议

导入模式通过 `--official-results-path` 归一化官方评分结果。runtime 模式需要生成视频目录（`--generated-video-dir` / `--model-output-dir`）、人工标注根目录以及 GPT-4o（可选 GPT-4o-mini）API 凭据；`--dimension` 限定评审维度，`--mode` 选择评审协议。本地 preflight 会校验标注镜像、prompt manifest、视频解码、布局匹配与依赖导入。

主指标是 `videobench_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `imaging_quality` | Video-Bench 静态画质得分（官方 1-5 分制）。 | 越高越好 |
| `aesthetic_quality` | Video-Bench 美学质量得分（官方 1-5 分制）。 | 越高越好 |
| `temporal_consistency` | Video-Bench 时序一致性得分（官方 1-5 分制）。 | 越高越好 |
| `motion_effects` | Video-Bench 运动效果得分（官方 1-5 分制）。 | 越高越好 |
| `video_text_consistency` | Video-Bench 整体视频-文本一致性得分（官方 1-5 分制）。 | 越高越好 |
| `object_class_consistency` | Video-Bench 物体类别一致性得分（官方 1-3 分制）。 | 越高越好 |
| `color_consistency` | Video-Bench 颜色一致性得分（官方 1-3 分制）。 | 越高越好 |
| `action_consistency` | Video-Bench 动作一致性得分（官方 1-3 分制）。 | 越高越好 |
| `scene_consistency` | Video-Bench 场景一致性得分（官方 1-3 分制）。 | 越高越好 |
| `videobench_average` | 可用 Video-Bench 维度的归一化均分。 | 越高越好 |

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id video-bench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_VIDEOBENCH_ROOT`: 可选覆盖项，指向外部 runtime checkout。
- `WORLDFOUNDRY_VIDEOBENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。
- `WORLDFOUNDRY_VIDEOBENCH_GPT4O_API_KEY`: GPT-4o judge 的 API key（回退到 `OPENAI_API_KEY`）。
- `WORLDFOUNDRY_VIDEOBENCH_ANNOTATION_ROOT`: 人工标注数据集根目录覆盖项。
- `WORLDFOUNDRY_VIDEOBENCH_MODEL_OUTPUT_DIR`: 存放待评审生成视频的模型输出树。

该 benchmark 复用共享 base-model 依赖栈：`video_bench_dataset_assets`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `per_sample_scores.jsonl`: 当结果源包含逐样本数值时写出的逐样本行。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `upstream_stdout.log`: 上游官方 scorer 的 stdout 日志。
- `upstream_stderr.log`: 上游官方 scorer 的 stderr 日志。

Scorecard 主键：`videobench_average`（leaderboard key `overall_average`），写入 `scorecard.json`。

## 边界与限制

- 官方 GPT judge 执行仅受用户显式提供的 API 凭据限制；缺少凭据属于运行时配置要求，不是集成阻塞。
- 仅在需要官方视频时才需访问 gated 的 Video-Bench_videos 数据集。
- 完整 leaderboard 对齐需要全部官方资产、生成产物与经验证的 scorecard 证据。
