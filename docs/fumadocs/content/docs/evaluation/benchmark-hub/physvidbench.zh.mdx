## 简介

**发表机构：** Koç University（Cyberiada 实验室 / KUIS AI）

PhysVidBench 通过字幕中介的 QA 协议评测文生视频的物理常识：候选视频先生成字幕（上游用 AuroraCap），再由 LLM judge 针对每条字幕回答物理相关的是/否问题。得分族覆盖可供性理解（affordance）、工具使用一致性、材料属性一致性与时序动力学一致性，聚合为 `physvidbench_average`。

WorldFoundry 捆绑了官方 `prompts_questions.csv` 与字幕轨道，可对调用方提供的字幕运行 Gemini QA，或把已准备好的 QA 结果归一化为 scorecard。

官方参考：

- Paper: [arxiv.org/abs/2507.15824](https://arxiv.org/abs/2507.15824)
- 项目主页: [cyberiada.github.io/PhysVidBench](https://cyberiada.github.io/PhysVidBench/)
- 官方仓库: [ensanli/PhysVidBenchCode](https://github.com/ensanli/PhysVidBenchCode)
- License: `cc-by-4.0`

## 评测协议

支持两条路径：

- **结果导入**（`official-validation`）：把上游 `output.csv` QA 导出归一化到 WorldFoundry 指标面。
- **有界字幕 QA**（`--run-official`）：用仓内 Gemini QA 组件对调用方提供的字幕轨道跑捆绑问题集。候选视频的字幕生成本身*不在*仓内执行——WorldFoundry 无法证明所供字幕确实来自你的视频。

judge 后端通过 `WORLDFOUNDRY_PHYSVIDBENCH_JUDGE_BACKEND` 选择。

主指标是 `physvidbench_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `physical_commonsense_accuracy` | 整体物理常识 QA 准确率。 | 越高越好 |
| `affordance_understanding` | 可供性（affordance）与交互理解得分。 | 越高越好 |
| `tool_use_consistency` | 工具中介的物理交互一致性。 | 越高越好 |
| `material_property_consistency` | 材料属性一致性。 | 越高越好 |
| `temporal_dynamics_consistency` | 物理时序动力学一致性。 | 越高越好 |
| `physvidbench_average` | 可用物理常识得分族的均值。 | 越高越好 |

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id physvidbench \
  --mode official-validation \
  --official-results-path <output.csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

对捆绑字幕运行有界 caption-QA 组件：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/physvidbench/run_physvidbench_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --captions-dir worldfoundry/data/benchmarks/assets/physvidbench/captions \
  --output-dir tmp/physvidbench/official \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_PHYSVIDBENCH_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_PHYSVIDBENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。
- `WORLDFOUNDRY_PHYSVIDBENCH_JUDGE_BACKEND`: 选择 QA judge 后端（Gemini 或 mock 接线）。

该 benchmark 复用共享 base-model 依赖栈：`physvidbench_dataset_assets`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `output.csv`
- `per_sample_scores.jsonl`: 当结果源包含逐样本数值时写出的逐样本行。

Scorecard 主键：`physvidbench_average`（leaderboard key `physvidbench_average`），写入 `scorecard.json`。

## 边界与限制

- 候选视频的 AuroraCap 字幕生成以及字幕来源证明未在仓内实现。
- 对所供字幕的 Gemini QA——以及一切 mock 运行——都不是官方 benchmark / leaderboard 证据。
- 只有通过 `official-validation` 导入的上游全流水线结果才具官方效力。
