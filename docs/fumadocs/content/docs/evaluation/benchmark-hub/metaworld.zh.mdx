## 关于

Meta-World 是构建在 MuJoCo 上的多任务与元强化学习基准。它定义了 50 个使用同一 Sawyer 机械臂的仿真操作任务，并给出标准化套件——MT1/MT10/MT50 用于多任务学习，ML1/ML10/ML45 用于向留出任务的元学习泛化——成功由任务特定的目标谓词判定。

WorldFoundry 仅以官方结果归一化器方式集成 Meta-World：调用方提供的 rollout 结果文件（套件评测的 JSON/CSV 导出）被转换为 WorldFoundry scorecard。仓内没有 Meta-World 仿真适配器，运行时 profile 标记默认 checkout 未部署 Meta-World/MuJoCo 运行时（`needs_new_env: true`）。

官方来源：

- 论文：[arXiv:1910.10897](https://arxiv.org/abs/1910.10897)
- 项目主页：[meta-world.github.io](https://meta-world.github.io/)
- 官方仓库：[Farama-Foundation/Metaworld](https://github.com/Farama-Foundation/Metaworld)（固定 `c26e9a6c`）
- 许可：MIT

## 仓内路径

- Catalog：`worldfoundry/data/benchmarks/catalog/embodied/metaworld.yaml`
- 任务清单：`worldfoundry/data/benchmarks/tasks/external/metaworld.yaml`
- 运行时 profile：`worldfoundry/data/benchmarks/runtime_profiles/official/metaworld.yaml`
- 结果归一化器：`worldfoundry.evaluation.tasks.embodied.normalizer`（track `vla`）
- 该 benchmark id 不存在仿真适配器与闭环 eval config。

## 评测协议与数据布局

embodied normalizer 接受 JSON、JSONL、CSV、TSV 及 `result.txt` 风格日志。行记录按 `success`、`success_rate`、`task_success`、`reward`、`normalized_return` 等数值字段匹配；布尔值与百分比字符串会被强制转换为 [0,1] 浮点数，episode 标识从 `sample_id`/`episode_id`/`task_id`/`task`/`id`/`name` 中读取。

产出原始结果需要官方 Meta-World 包或仓库 checkout、兼容 MuJoCo 的运行时、明确的 MT/ML 套件映射，以及策略 checkpoint 或控制器（catalog `requires`）。

## 指标

主指标（scorecard 主键）：`success_rate`。

| 指标 | 含义 |
| --- | --- |
| `success_rate` | 满足任务成功谓词的 episode 占比；leaderboard 主值。 |
| `task_success` | 按任务聚合的成功率。 |
| `reward` | 每 episode 的累计 shaped reward。 |
| `normalized_return` | 有上报时，按任务参考区间归一化的 return。 |

成功类指标经共享 registry 的 `percent_or_fraction_to_unit` 归一化；不涉及视频生成类指标。

## 准备命令与环境变量

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_METAWORLD_RESULTS_PATH=/path/to/metaworld_results.json
```

运行时 profile 标记 `needs_new_env: true`：套件映射之前需要独立的 `mujoco`/`metaworld` 环境，默认 checkout 未部署。

校验运行时接线：

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile metaworld \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/metaworld.yaml \
  --output-dir tmp/worldfoundry_preflight/metaworld \
  --json
```

## 导入官方结果（official-validation）

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id metaworld \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_METAWORLD_RESULTS_PATH}" \
  --output-dir tmp/metaworld/official-validation \
  --json
```

该路径在进程内走 embodied `vla` track normalizer，不执行任何仿真代码。Meta-World 没有仓内 `official-run` rollout 路径——完整运行必须用上游包执行后再导入。

## 输出

- `scorecard.json`：WorldFoundry scorecard；leaderboard 块以 `success_rate` 为主键。
- `raw_results.jsonl`：提取的原始结果行。
- `evaluation/summary.json`：按指标聚合的统计。
- `evaluation/per_sample_metrics.jsonl`：归一化后的逐 episode 行。

## 不能声称的边界

- catalog 状态为 `normalizer_only`，`leaderboard_valid: false`、`official_benchmark_verified: false`。导入的数字是调用方结果的归一化副本，不是官方复现的 leaderboard 值。
- MuJoCo 仿真器与 Meta-World 包未安装在默认 WorldFoundry 环境中；运行本基准需要外部环境。本页不声称任何本地 rollout 证据。
- catalog blocker：Meta-World 任务套件映射与官方格式策略结果验证完成之前，不达到 integrated 状态。
