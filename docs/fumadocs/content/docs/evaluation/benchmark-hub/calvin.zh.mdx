## 关于

CALVIN（Composing Actions from Language and Vision）评测长时程、语言条件的机器人操作。策略需要在桌面 PyBullet 环境中串联多个自然语言指定的子任务；标准协议 rollout 1000 条指令序列，报告策略在每条序列中连续完成的子任务数。

WorldFoundry 通过仓内闭环仿真适配器 `worldfoundry/evaluation/tasks/embodied/simulators/calvin/` 以及共享官方结果归一化器集成 CALVIN。catalog 校验状态为 `normalizer_only`：结果导入已验证，官方 rollout 需要 CALVIN 数据集、序列评测器与策略 checkpoint。

官方来源：

- 论文：[IEEE RA-L 2022（9788026）](https://ieeexplore.ieee.org/document/9788026)
- 项目主页：[calvin.cs.uni-freiburg.de](http://calvin.cs.uni-freiburg.de/)
- 官方仓库：[mees/calvin](https://github.com/mees/calvin)（固定 `fa03f01f`）
- 许可：MIT

## 仓内路径

- Catalog：`worldfoundry/data/benchmarks/catalog/embodied/calvin.yaml`
- 任务清单：`worldfoundry/data/benchmarks/tasks/external/calvin.yaml`
- 运行时 profile：`worldfoundry/data/benchmarks/runtime_profiles/official/calvin.yaml`
- 仿真适配器：`worldfoundry/evaluation/tasks/embodied/simulators/calvin/`
- 闭环 eval config：`worldfoundry/data/benchmarks/eval_configs/embodied/calvin/eval.yaml`
- 结果归一化器：`worldfoundry.evaluation.tasks.embodied.normalizer`（track `vla`）

## 评测协议与数据布局

结果导入侧，embodied normalizer 接受 JSON、JSONL、CSV、TSV 及 `result.txt` 风格日志。行记录按 `success`、`success_rate`、`task_success`、`sequence_success`、`completion` 等数值字段匹配；布尔值与百分比字符串会被强制转换为 [0,1] 浮点数。

内置 eval config 以 seed 0 评测 1000 条指令序列（每序列 1 个 episode），使用 `/data/calvin/dataset/validation` 的验证集，由 `ws://localhost:8000` 上的外部 policy server 驱动。

## 指标

主指标（scorecard 主键）：`success_rate`。

| 指标 | 含义 |
| --- | --- |
| `success_rate` | 评测 rollout 的成功占比；leaderboard 主值。 |
| `sequence_success` | 完整多步指令序列的成功率。 |
| `task_success` | 按子任务跨序列聚合的成功率。 |
| `completion` | 每序列连续完成子任务的平均数量/比例。 |

成功类指标经共享 registry 的 `percent_or_fraction_to_unit` 归一化；不涉及视频生成类指标。

## 准备命令与环境变量

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_CALVIN_RESULTS_PATH=/path/to/calvin_results.json
```

闭环 rollout 需要官方 CALVIN 仓库 checkout（缓存于 `cache/vla_va_wam/repos/mees--calvin`）、CALVIN 数据集根目录，以及通过 WebSocket 提供动作的策略 checkpoint。运行时 profile 仅做轻量 preflight（`needs_new_env: false`），不启动仿真器也不下载数据集。

校验运行时接线：

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile calvin \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/calvin.yaml \
  --output-dir tmp/worldfoundry_preflight/calvin \
  --json
```

## 导入官方结果（official-validation）

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id calvin \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_CALVIN_RESULTS_PATH}" \
  --output-dir tmp/calvin/official-validation \
  --json
```

该路径在进程内走 embodied `vla` track normalizer，不执行任何仿真代码。

## 闭环 rollout（原生仿真器）

```bash
worldfoundry-eval embodied run \
  --config worldfoundry/data/benchmarks/eval_configs/embodied/calvin/eval.yaml \
  --output-dir tmp/calvin/embodied-run \
  --json
```

修改 config 中的 `dataset_path`（或复制一份）指向你的 CALVIN 验证 split。支持 `--server-url`、`--shard-id`/`--num-shards`、`--no-docker`。

## 输出

- `scorecard.json`：WorldFoundry scorecard；leaderboard 块以 `success_rate` 为主键。
- `raw_results.jsonl`：提取的原始结果行。
- `evaluation/summary.json`：按指标聚合的统计。
- `evaluation/per_sample_metrics.jsonl`：归一化后的逐序列行。

## 不能声称的边界

- catalog 状态为 `normalizer_only`，`leaderboard_valid: false`、`official_benchmark_verified: false`。导入的数字是调用方结果的归一化副本，不是官方复现的 leaderboard 值。
- CALVIN 数据集、PyBullet 仿真 assets、策略 checkpoint 均未随仓库分发；闭环 rollout 需要外部部署并运行 policy server。本页不声称任何本地 GPU rollout 证据。
- catalog blocker：官方 CALVIN 数据集 split、序列评测器与策略 checkpoint 验证完成之前，不达到 integrated 状态。
