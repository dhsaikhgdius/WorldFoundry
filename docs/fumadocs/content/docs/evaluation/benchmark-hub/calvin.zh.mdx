## 简介

**发表机构：** University of Freiburg（弗莱堡大学）

CALVIN（Composing Actions from Language and Vision）由弗莱堡大学发布，评测长时程语言条件操作：策略在 PyBullet 桌面环境中需按顺序串联最多五条语言指令，并跨 A/B/C/D 四种环境配置检验零样本迁移。标志性协议报告各链长的成功率与平均完成指令数。

WorldFoundry 以官方结果 runner 集成 CALVIN：官方长时程序列评测器的导出被归一化为统一 scorecard。

官方参考：

- Paper: [ieeexplore.ieee.org/document/9788026](https://ieeexplore.ieee.org/document/9788026)
- 项目主页: [calvin.cs.uni-freiburg.de](http://calvin.cs.uni-freiburg.de/)
- 官方仓库: [mees/calvin](https://github.com/mees/calvin)
- License: `mit`

## 评测协议

WorldFoundry 通过统一的结果导入路径集成该 benchmark：`worldfoundry-eval zoo benchmark-run --mode official-validation` 把调用方提供的官方结果导出（JSON/CSV rollout 汇总）归一化为 WorldFoundry scorecard，不执行模拟器。模拟器执行、策略加载与 rollout 采集仍是使用官方工具完成的显式上游步骤。

主指标是 `success_rate`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `success_rate` | 评测 rollout 上的主成功率（逐 episode 成功比例）。 | 越高越好 |
| `sequence_success` | 五指令链的成功率（长时程协议）。 | 越高越好 |
| `task_success` | 按任务聚合的成功率。 | 越高越好 |
| `completion` | 每条序列平均完成的指令数。 | 越高越好 |

```text
<official_results.json>                 # 官方工具产出的 rollout 汇总导出

```
上游 checkout 镜像在 `cache/vla_va_wam/repos/mees--calvin`；数据集根与策略权重遵循 CALVIN 官方文档。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id calvin \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_CALVIN_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_results.jsonl`: 从官方结果导出解析出的归一化行。

Scorecard 主键：`success_rate`（leaderboard key `success_rate`），写入 `scorecard.json`。

## 边界与限制

- WorldFoundry 只归一化所提供的 rollout 结果；不在仓内运行官方模拟器或策略。
- 在用就位的模拟器资产与策略权重执行官方 rollout 并导入之前，不声称完整 leaderboard 对齐。
- 导入的 scorecard 是集成证据，不是 leaderboard 提交。
