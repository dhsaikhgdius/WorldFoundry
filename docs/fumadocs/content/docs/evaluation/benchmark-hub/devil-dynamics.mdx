## About

**Publisher:** University of Chinese Academy of Sciences & Baidu (NeurIPS 2024)

DEVIL evaluates text-to-video models on the dynamics dimension. It builds a prompt benchmark stratified by dynamics grades and defines dynamics scores at multiple temporal granularities, from which three protocol metrics are derived: dynamics range (how much content variation a model can produce), dynamics controllability (whether prompted dynamics levels are respected), and dynamics-based quality. The official protocol reports >90% correlation with human ratings.

WorldFoundry provides an in-tree runtime entry that materializes DEVIL metric rows from WorldFoundry artifact-score outputs, plus a normalizer for caller-provided official result files.

Official references:

- Paper: [arxiv.org/abs/2407.01094](https://arxiv.org/abs/2407.01094)
- Project page: [huggingface.co/papers/2407.01094](https://huggingface.co/papers/2407.01094)
- Official repository: [MingXiangL/DEVIL](https://github.com/MingXiangL/DEVIL)

## Evaluation protocol

Two paths: import official DEVIL result JSON via `--official-results-path`, or compute metric rows from staged artifact scores via `WORLDFOUNDRY_DEVIL_DYNAMICS_ARTIFACT_SCORE_DIR`. Full official recomputation depends on the upstream scorer checkpoints (RAFT, CLIP ViT-L/14 and ViT-B/32, ViCLIP, DINOv2, AMT, dynamics regression checkpoint) surfaced through the runner's checkpoint flags.

Primary metric: `devil_dynamics_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `dynamics_range` | Dynamics Range normalized benchmark score. | Higher is better |
| `dynamics_controllability` | Dynamics Controllability normalized benchmark score. | Higher is better |
| `dynamics_quality` | Dynamics Quality normalized benchmark score. | Higher is better |
| `devil_dynamics_average` | DEVIL Dynamics Average normalized benchmark score. | Higher is better |

## Data and artifact layout

In-tree paths:

```text
worldfoundry/data/benchmarks/tasks/external/devil-dynamics.yaml
worldfoundry/evaluation/tasks/execution/runners/devil_dynamics
```

```bash
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/devil/generated_videos
export WORLDFOUNDRY_DEVIL_DYNAMICS_ARTIFACT_SCORE_DIR=/path/to/artifact_scores   # runtime execution
export WORLDFOUNDRY_DEVIL_DYNAMICS_RESULTS_PATH=/path/to/devil_results.json      # import runs
```

Generate one video per official DEVIL prompt; the dynamics-grade stratification comes from the official prompt metadata.

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id devil-dynamics \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_DEVIL_DYNAMICS_ARTIFACT_SCORE_DIR`
- `WORLDFOUNDRY_DEVIL_DYNAMICS_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.

Scorecard primary key: `devil_dynamics_average` (leaderboard key `devil_dynamics_average`), stored in `scorecard.json`.

## Limitations

- The Gemini-based naturalness component requires an external API key and is not part of local recomputation.
- Full protocol parity requires the complete upstream checkpoint set (RAFT/CLIP/ViCLIP/DINOv2/AMT plus the dynamics regression checkpoint).
- A local scorecard is not an official DEVIL leaderboard result.
