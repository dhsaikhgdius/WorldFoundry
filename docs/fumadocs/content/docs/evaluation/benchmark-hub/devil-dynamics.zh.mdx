## 简介

**发表机构：** 中国科学院大学与百度（NeurIPS 2024）

DEVIL 从动态性维度评测文生视频模型。它构建了按 dynamics 等级分层的 prompt benchmark，并在多个时间粒度上定义 dynamics scores，进而导出三个协议指标：dynamics range（模型能产生的内容变化幅度）、dynamics controllability（是否遵循 prompt 指定的动态等级）与 dynamics-based quality。官方协议与人工评分相关性超过 90%。

WorldFoundry 提供仓内 runtime 入口，可从 WorldFoundry artifact-score 输出 materialize DEVIL 指标行，也可归一化调用方提供的官方结果文件。

官方参考：

- Paper: [arxiv.org/abs/2407.01094](https://arxiv.org/abs/2407.01094)
- 项目主页: [huggingface.co/papers/2407.01094](https://huggingface.co/papers/2407.01094)
- 官方仓库: [MingXiangL/DEVIL](https://github.com/MingXiangL/DEVIL)

## 评测协议

两条路径：用 `--official-results-path` 导入官方 DEVIL 结果 JSON；或通过 `WORLDFOUNDRY_DEVIL_DYNAMICS_ARTIFACT_SCORE_DIR` 从已准备的 artifact scores 计算指标行。完整官方重算依赖上游 scorer 权重（RAFT、CLIP ViT-L/14 与 ViT-B/32、ViCLIP、DINOv2、AMT、dynamics 回归权重），这些通过 runner 的权重 flag 传入。

主指标是 `devil_dynamics_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `dynamics_range` | Dynamics Range normalized benchmark score. | 越高越好 |
| `dynamics_controllability` | Dynamics Controllability normalized benchmark score. | 越高越好 |
| `dynamics_quality` | Dynamics Quality normalized benchmark score. | 越高越好 |
| `devil_dynamics_average` | DEVIL Dynamics Average normalized benchmark score. | 越高越好 |

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/devil-dynamics.yaml
worldfoundry/evaluation/tasks/execution/runners/devil_dynamics
```

```bash
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/devil/generated_videos
export WORLDFOUNDRY_DEVIL_DYNAMICS_ARTIFACT_SCORE_DIR=/path/to/artifact_scores   # runtime 执行
export WORLDFOUNDRY_DEVIL_DYNAMICS_RESULTS_PATH=/path/to/devil_results.json      # 导入模式
```

按官方 DEVIL prompt 逐条生成视频；dynamics 等级分层来自官方 prompt 元数据。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id devil-dynamics \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_DEVIL_DYNAMICS_ARTIFACT_SCORE_DIR`
- `WORLDFOUNDRY_DEVIL_DYNAMICS_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。

Scorecard 主键：`devil_dynamics_average`（leaderboard key `devil_dynamics_average`），写入 `scorecard.json`。

## 边界与限制

- 基于 Gemini 的 naturalness 组件需要外部 API key，不属于本地重算范围。
- 协议级对齐需要完整上游权重集（RAFT/CLIP/ViCLIP/DINOv2/AMT 及 dynamics 回归权重）。
- 本地 scorecard 不是官方 DEVIL leaderboard 结果。
