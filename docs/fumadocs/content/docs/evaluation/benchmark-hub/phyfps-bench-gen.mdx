## About

**Publisher:** TACO Group, Texas A&M University

PhyFPS-Bench-Gen audits *chronometric hallucination* in video generators: state-of-the-art models produce motion whose implied physical speed (PhyFPS, measured by the Visual Chronometer predictor) diverges from the container's declared frame rate (Meta FPS) and drifts within and across clips. The benchmark ships 100 prompts; a model generates one video per prompt, Visual Chronometer predicts PhyFPS over sliding windows, and the suite reports Meta-vs-PhyFPS error plus intra- and inter-video coefficients of variation. All metrics are lower-is-better.

WorldFoundry runs the Visual Chronometer `predict.py` in tree via the checked-in runtime and normalizes `results.csv` into the official metric surface.

Official references:

- Official repository: [taco-group/Visual_Chronometer](https://github.com/taco-group/Visual_Chronometer)

## Evaluation protocol

Generated videos should follow `0001.mp4` … `0100.mp4` naming aligned with `prompts.txt`. The runner predicts PhyFPS per sliding-window clip (`--stride`, `--clip-length`), aggregates per-video averages, and computes alignment metrics against Meta FPS supplied via `WORLDFOUNDRY_PHYFPS_META_FPS` or a manifest. `official-validation` mode instead normalizes an existing upstream `results.csv`.

Primary metric: `phyfps_bench_gen_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `avg_error_fps` | Mean absolute gap between Meta FPS and average PhyFPS. | Lower is better |
| `pct_error` | Mean relative Meta-vs-PhyFPS error percentage. | Lower is better |
| `inter_video_cv` | Cross-video coefficient of variation over average PhyFPS. | Lower is better |
| `intra_video_cv` | Mean within-video coefficient of variation over sliding-window clips. | Lower is better |
| `phyfps_bench_gen_average` | Mean over available PhyFPS-Bench-Gen score families. | Lower is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id phyfps-bench-gen \
  --mode official-validation \
  --official-results-path <results.csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

Predict PhyFPS in tree and score the full audit:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/phyfps_bench_gen/run_phyfps_bench_gen_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --stride 4 \
  --output-dir tmp/phyfps_bench_gen/official \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_VISUAL_CHRONOMETER_ROOT`: Optional override pointing at an external runtime checkout.
- `WORLDFOUNDRY_PHYFPS_BENCH_GEN_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.
- `WORLDFOUNDRY_PHYFPS_META_FPS`: Declared Meta FPS of the generator, required for alignment metrics.
- `WORLDFOUNDRY_PHYFPS_BENCH_GEN_PROMPT_MANIFEST`: Override for the in-tree PhyFPS prompt manifest.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `results.csv`
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.

Scorecard primary key: `phyfps_bench_gen_average` (leaderboard key `phyfps_bench_gen_average`), stored in `scorecard.json`.

## Limitations

- Full leaderboard parity requires the complete official checkpoint assets, all 100 generated videos, and verified scorecard evidence.
- The released VC-Common checkpoint is for demo/leaderboard reproduction and is not the authors' strongest internal model.
- Alignment metrics are undefined without Meta FPS; runs without it cover only the CV metrics.
