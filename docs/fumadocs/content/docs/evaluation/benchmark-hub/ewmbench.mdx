## About

**Publisher:** AgiBot (AgibotTech)

EWMBench evaluates video world models for embodied manipulation scenarios. Built by AgiBot on top of its AgiBot-World robot data ecosystem, it scores generated robot-manipulation videos along four families — scene consistency (does the workspace stay stable), motion correctness (does the arm trajectory match the task), semantic alignment (does the video match the language instruction), and diversity — aggregated into `ewmbench_average`.

WorldFoundry integrates EWMBench with bundled runtime assets: the unified `benchmark-run` entrypoint normalizes caller-provided official result files, and the runner's `--run-official` path can dispatch the upstream `evaluate.py` scorer when its dependencies are staged.

Official references:

- Paper: [arxiv.org/abs/2505.09694](https://arxiv.org/abs/2505.09694)
- Project page: [huggingface.co/datasets/agibot-world/EWMBench](https://huggingface.co/datasets/agibot-world/EWMBench)
- Official repository: [AgibotTech/EWMBench](https://github.com/AgibotTech/EWMBench)

## Evaluation protocol

`official-validation` normalizes an official EWMBench result export into the WorldFoundry metric surface. `--run-official` executes the in-tree EWMBench scorer (mock wiring or upstream `evaluate.py` dispatch); `--task-manifest` and `--config-path` bind the task set and scorer configuration, `--limit` bounds the run.

Primary metric: `ewmbench_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `scene_consistency` | scene_consistency normalized benchmark score. | Higher is better |
| `motion_correctness` | motion_correctness normalized benchmark score. | Higher is better |
| `semantic_alignment` | semantic_alignment normalized benchmark score. | Higher is better |
| `diversity` | diversity normalized benchmark score. | Higher is better |
| `ewmbench_average` | ewmbench_average normalized benchmark score. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id ewmbench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_EWMBENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

This benchmark reuses the shared base-model dependency stack: `ewmbench_dataset_assets`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.

Scorecard primary key: `ewmbench_average` (leaderboard key `ewmbench_average`), stored in `scorecard.json`.

## Limitations

- Imported scorecards are non-leaderboard setup evidence; official runtime execution and judge assets remain upstream requirements.
- Full leaderboard parity requires generated artifacts for the complete official prompt/task suite plus upstream scorer or judge assets.
- Mock-backend runs are wiring checks only.
