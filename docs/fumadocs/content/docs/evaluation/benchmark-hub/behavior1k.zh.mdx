## 简介

**发表机构：** Stanford University（斯坦福大学 SVL 实验室）

BEHAVIOR-1K 是斯坦福以人为中心的具身 AI 评测：从人类时间使用调查中选出的 1,000 项日常活动（清洁、烹饪、整理），用 BDDL 谓词语言定义，并在 OmniGibson 中以逼真物理、流体与物体状态仿真。成功以满足活动的逻辑目标条件衡量，子目标满足率作为部分得分信号。

WorldFoundry 以官方结果 runner 集成 BEHAVIOR-1K：上游 OmniGibson 工具产出的 rollout 导出被归一化为统一 scorecard。

官方参考：

- Paper: [arxiv.org/abs/2403.09227](https://arxiv.org/abs/2403.09227)
- 官方仓库: [StanfordVL/OmniGibson](https://github.com/StanfordVL/OmniGibson)
- License: `upstream_terms`

## 评测协议

WorldFoundry 通过统一的结果导入路径集成该 benchmark：`worldfoundry-eval zoo benchmark-run --mode official-validation` 把调用方提供的官方结果导出（JSON/CSV rollout 汇总）归一化为 WorldFoundry scorecard，不执行模拟器。模拟器执行、策略加载与 rollout 采集仍是使用官方工具完成的显式上游步骤。

主指标是 `success_rate`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `success_rate` | 评测 rollout 上的主成功率（逐 episode 成功比例）。 | 越高越好 |
| `task_success` | 按任务聚合的成功率。 | 越高越好 |
| `episode_success` | 逐 episode 成功指示的聚合值。 | 越高越好 |
| `subgoal_success` | BDDL 子目标满足率（部分得分）。 | 越高越好 |

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/behavior1k.yaml
```

```text
<official_results.json>                 # 官方工具产出的 rollout 汇总导出
${WORLDFOUNDRY_BEHAVIOR1K_RESULTS_PATH}   # 默认导入路径
```
模拟器 runtime、benchmark 资产与策略权重遵循上游 [StanfordVL/OmniGibson](https://github.com/StanfordVL/OmniGibson) 文档。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id behavior1k \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_BEHAVIOR1K_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_BEHAVIOR1K_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_results.jsonl`: 从官方结果导出解析出的归一化行。
- `evaluation/summary.json`: 聚合评测摘要。

Scorecard 主键：`success_rate`（leaderboard key `success_rate`），写入 `scorecard.json`。

## 边界与限制

- WorldFoundry 只归一化所提供的 rollout 结果；不在仓内运行官方模拟器或策略。
- 在用就位的模拟器资产与策略权重执行官方 rollout 并导入之前，不声称完整 leaderboard 对齐。
- 导入的 scorecard 是集成证据，不是 leaderboard 提交。
