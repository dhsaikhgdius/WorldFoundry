## About

**Publisher:** Alibaba AMAP (AMAP-ML)

VMBench (ICCV 2025) evaluates motion generation quality with five perception-aligned metrics: perceptible amplitude, object integrity, temporal coherence, commonsense adherence, and motion smoothness. Its prompt suite contains 1,050 motion-centric prompts; generated videos are scored by local metric runtimes without any hosted judge API.

WorldFoundry vendors the official VMBench metric code in tree (`runtime/official`), bundles the prompt suite at `worldfoundry/data/benchmarks/assets/vmbench/prompts/prompts.json`, and can either run the vendored metrics or normalize official `results.json`/`scores.csv` exports.

Official references:

- Paper: [openaccess.thecvf.com/content/ICCV2025/html/Ling_VMBench_A_Benchmark_for_Perception-Aligned_Video_Motion_Generation_ICCV_2025_paper.html](https://openaccess.thecvf.com/content/ICCV2025/html/Ling_VMBench_A_Benchmark_for_Perception-Aligned_Video_Motion_Generation_ICCV_2025_paper.html)
- Project page: [amap-ml.github.io/VMBench-Website](https://amap-ml.github.io/VMBench-Website/)
- Official repository: [AMAP-ML/VMBench](https://github.com/AMAP-ML/VMBench)

## Evaluation protocol

Generated videos must follow the official prompt-index naming convention `0001.mp4` … `1050.mp4`. The runner materializes `meta_info` rows from the video directory, dispatches the vendored metric stack (`--run-official`), or imports official result exports (`--official-results-path` / `--from-upstream-results`).

Primary metric: `vmbench_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `perceptible_amplitude_score` | Official VMBench PAS metric for perceptible motion amplitude. | Higher is better |
| `object_integrity_score` | Official VMBench OIS metric for object identity and integrity under motion. | Higher is better |
| `temporal_coherence_score` | Official VMBench TCS metric for temporal coherence. | Higher is better |
| `commonsense_adherence_score` | Official VMBench CAS metric for action and motion commonsense adherence. | Higher is better |
| `motion_smoothness_score` | Official VMBench MSS metric for motion smoothness. | Higher is better |
| `vmbench_average` | Mean of available official VMBench PAS/OIS/TCS/CAS/MSS component scores. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id vmbench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

Run the vendored metric stack over generated videos:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/vmbench/run_vmbench_official_runner.py \
  --run-official \
  --generated-video-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --prompt-manifest "${WORLDFOUNDRY_VMBENCH_PROMPT_MANIFEST}" \
  --output-dir tmp/vmbench/official-run \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_VMBENCH_PROMPT_MANIFEST`: Prompt manifest path; defaults to the bundled in-tree suite.
- `WORLDFOUNDRY_VMBENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

This benchmark reuses the shared base-model dependency stack: `motion_stack`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `per_sample_metrics.jsonl`
- `upstream_stdout.log`: Captured stdout of the upstream official scorer.
- `upstream_stderr.log`: Captured stderr of the upstream official scorer.

Scorecard primary key: `vmbench_average` (leaderboard key `Avg`), stored in `scorecard.json`.

## Limitations

- Full metric recomputation is GPU-heavy and requires CUDA metric dependencies plus multiple detector/tracker checkpoints.
- The official Hugging Face dataset endpoint was not public at integration time; the in-tree prompt bundle is the tracked source.
- A local scorecard is not an official VMBench leaderboard result.
