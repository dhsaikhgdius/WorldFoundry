## 简介

**发表机构：** Stanford University（斯坦福大学）

WorldScore 把世界生成——3D/4D 场景生成与视频式世界模型——的评测统一到一个协议里：模型接收起始场景与一串带相机指令的布局指示，其 rollout 在可控性（相机与物体控制）、质量（视觉与重建保真）、动态（时序行为）三大指标族上打分。官方聚合分 `worldscore_average` 把各族归一到同一尺度。

WorldFoundry 在仓内内置 WorldScore 核心 runtime，由 `run_worldscore_official_runner.py` 驱动：解析数据集（Hugging Face `Howieeeee/WorldScore`）、就位生成输出树、调度上游指标栈，并把 `evaluation.json` 树转换为 scorecard。

官方参考：

- Paper: [arxiv.org/abs/2504.00983](https://arxiv.org/abs/2504.00983)
- 项目主页: [haoyi-duan.github.io/WorldScore](https://haoyi-duan.github.io/WorldScore/)
- 官方仓库: [haoyi-duan/WorldScore](https://github.com/haoyi-duan/WorldScore)
- License: `mit`

## 评测协议

两条路径：通过 `--official-results-path` / `WORLDFOUNDRY_WORLDSCORE_RESULTS_PATH` 归一化已有的 WorldScore 结果产物；或用内置 GPU 指标 runtime 评测已就位的生成输出树（`--generated-root`、`--data-path`、`--num-jobs`）。未传 `--data-path` 时回退到本地 Hugging Face 缓存快照。staging 辅助参数（`--stage-dynamic-source`、`--stage-sample-index`、`--stage-target-frames`）用于准备动态样本。

主指标是 `worldscore_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `controllability` | WorldScore 相机与条件可控性指标族。 | 越高越好 |
| `quality` | WorldScore 视觉与重建质量指标族。 | 越高越好 |
| `dynamics` | WorldScore 时序动态指标族。 | 越高越好 |
| `worldscore_average` | WorldScore 指标族的归一化聚合分。 | 越高越好 |

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id worldscore \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_WORLDSCORE_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。
- `WORLDFOUNDRY_WORLDSCORE_RESULTS_PATH`
- `WORLDFOUNDRY_WORLDSCORE_OUTPUT_DIR`
- `WORLDFOUNDRY_WORLDSCORE_CONFIG_ROOT`: 可选覆盖项，指向捆绑的 WorldScore 配置资产。

该 benchmark 复用共享 base-model 依赖栈：`worldscore_spatial_metric_stack`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `per_sample_metrics.jsonl`
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `official_stdout.log`
- `official_stderr.log`

Scorecard 主键：`worldscore_average`（leaderboard key `worldscore_average`），写入 `scorecard.json`。

## 边界与限制

- 有界官方 GPU 验证只覆盖了一个动态样本；全套验证尚未完成，`official_benchmark_verified` 保持 false。
- 与 leaderboard 对齐需要官方指标定义下完整的 `evaluation.json` 树；不完整的树只能聚合成非 leaderboard scorecard。
- 空间指标栈（DROID、GroundingDINO、SAM、RAFT/SEA-RAFT）需要在本地就位共享权重。
