## 简介

**发表机构：** NVIDIA（联合 UC Berkeley、UC San Diego、MIT）

WorldModelBench（NeurIPS 2025）把视频生成模型当作世界模型来评审，覆盖 7 个应用领域、56 个子领域。其 350 实例套件从指令遵循、常识推理与物理符合度（如物体尺寸异常变化违反质量守恒）三方面打分，并用 6.7 万条众包人工标注校准。官方 judge 是微调的 2B 多模态模型（VILA 系列），在检测世界建模违规上优于 GPT-4o。

WorldFoundry 入库了上游 `evaluation.py` 与 350 实例 manifest，从本地 Hugging Face 快照（`Efficient-Large-Model/worldmodelbench`）解析数据集；提供 VILA 权重或 HF 模型 id 后即可执行官方 judge 路径。

官方参考：

- Paper: [arxiv.org/abs/2502.20694](https://arxiv.org/abs/2502.20694)
- 项目主页: [worldmodelbench-team.github.io](https://worldmodelbench-team.github.io/)
- 官方仓库: [WorldModelBench-Team/WorldModelBench](https://github.com/WorldModelBench-Team/WorldModelBench)

## 评测协议

official-run 通过 `WORLDFOUNDRY_WORLDMODELBENCH_JUDGE`（VILA 权重或 HF 模型 id）选定 judge 后驱动上游 `evaluation.py`；包装器按 N、2N、5N 的类别长度校验 accs/preds 形状，并在 `scorecard.validation` 中记录 350 实例的视频覆盖率。official-validation 模式则归一化调用方提供的官方形状结果文件。

主指标是 `world_model_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `instruction_following` | WorldModelBench 指令遵循得分。 | 越高越好 |
| `common_sense` | WorldModelBench 常识推理得分。 | 越高越好 |
| `physical_adherence` | WorldModelBench 物理符合度得分。 | 越高越好 |
| `world_model_average` | 公开 WorldModelBench 指标族的归一化聚合分。 | 越高越好 |

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id worldmodelbench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --benchmark-data-root <worldmodelbench_data_root> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_WORLDMODELBENCH_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。
- `WORLDFOUNDRY_WORLDMODELBENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_WORLDMODELBENCH_JUDGE`: official-run 时 evaluation.py 使用的 VILA 权重路径或 HF 模型 id。
- `WORLDFOUNDRY_WORLDMODELBENCH_DATA_ROOT`: 不用默认快照时，包含 worldmodelbench.json 的数据根。

该 benchmark 复用共享 base-model 依赖栈：`worldmodelbench_dataset_assets`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `runner_runtime_report.json`
- `judge_responses.jsonl`
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。

Scorecard 主键：`world_model_average`（leaderboard key `world_model_average`），写入 `scorecard.json`。

## 边界与限制

- 上游保留 leaderboard 答案；本地回归只能用公开输出或调用方提供的官方形状结果文件。
- 完整 leaderboard 对齐需要在全部 350 个实例上完成 judge 运行并保留上游提交证据。
- 导入的结果文件始终是非 leaderboard 证据。
