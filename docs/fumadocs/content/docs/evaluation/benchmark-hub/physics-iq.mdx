## About

**Publisher:** Google DeepMind

Physics-IQ tests whether video generation models understand physics rather than merely rendering plausible textures. Each of the 396 test items (66 scenarios × 2 views in the released protocol; the WorldFoundry contract tracks the 198-video single-pass split) shows a real recorded scene and asks the model to continue the next 5 seconds. Scoring compares the generated continuation against the real continuation using motion-mask-based spatial/spatiotemporal agreement and an MSE penalty, aggregated into the Physics-IQ score.

WorldFoundry ships the scoring runtime in tree behind `run_physics_iq_official_runner.py` (shared between the `physics-iq` and `physics-iq-verified` protocols via `--protocol`), plus bundled prompt/scenario metadata under `worldfoundry/data/benchmarks/assets/physics-iq`.

Official references:

- Paper: [arxiv.org/abs/2501.09038](https://arxiv.org/abs/2501.09038)
- Project page: [physics-iq.github.io](https://physics-iq.github.io/)
- Official repository: [google-deepmind/physics-IQ-benchmark](https://github.com/google-deepmind/physics-IQ-benchmark)

## Evaluation protocol

The runner supports three paths: `--run-official` recomputes raw metrics from generated continuations against the official media directory (`--dataset-root`), `--official-results-path` imports an existing `raw_metrics.csv`, and `--from-upstream-results` accepts upstream result exports. Masks are computed from the real videos; `--generated-mask-dir` allows precomputed masks, and `--strict` fails the run on missing scenario videos.

Primary metric: `physics_iq_score`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `physics_iq_score` | Original global-aggregation score (official final_score_orig). | Higher is better |
| `physics_iq_stable_score` | Component-clipped stable score emitted by the current official implementation. | Higher is better |
| `physics_iq_spatiotemporal` |  | Higher is better |
| `physics_iq_spatial` |  | Higher is better |
| `physics_iq_weighted_spatial` |  | Higher is better |
| `physics_iq_mse_penalty` |  | Lower is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id physics-iq \
  --mode official-validation \
  --official-results-path <raw_metrics.csv> \
  --output-dir <out> \
  --json
```

Recompute metrics from generated continuations:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/physics_iq/run_physics_iq_official_runner.py \
  --protocol physics-iq \
  --run-official \
  --dataset-root /path/to/physics-iq-benchmark \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --output-dir tmp/physics-iq/official-run \
  --strict \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory of the 198 generated continuation videos.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metrics.csv`
- `official_metrics.json`
- `results_summary.csv`
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.

Scorecard primary key: `physics_iq_score` (leaderboard key `physics_iq_score`), stored in `scorecard.json`.

## Limitations

- Official media (real videos and masks) must be downloaded separately and are not redistributed in tree.
- Single-pass runs cover 198 videos; the published protocol averages multiple runs, so one local pass understates protocol variance.
- A local Physics-IQ score is not a Google DeepMind leaderboard entry.
