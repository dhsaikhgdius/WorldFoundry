## 简介

**发表机构：** S-Lab（南洋理工大学）与上海人工智能实验室

VBench 把视频生成质量拆分成 16 个评测维度，覆盖时序质量（subject/background consistency、temporal flickering、motion smoothness、dynamic degree）、逐帧质量（aesthetic quality、imaging quality）和语义/文本对齐（object class、multiple objects、human action、color、spatial relationship、scene、appearance style、temporal style、overall consistency）。每个维度由专用感知模型打分，而不是单一 embedding 距离；官方 leaderboard 将其聚合为质量分与语义分。

WorldFoundry 把官方 VBench runtime 内置在 `worldfoundry/evaluation/tasks/execution/runners/vbench/runtime`，公开入口是 `worldfoundry/evaluation/tasks/execution/runners/vbench/run_vbench_official_runner.py`。runner 负责 materialize prompt suite、调度上游各维度 evaluator，并把产出的 `full_json` 结果转换成 WorldFoundry scorecard。

官方参考：

- Paper: [arxiv.org/abs/2311.17982](https://arxiv.org/abs/2311.17982)
- 项目主页: [vchitect.github.io/VBench-project](https://vchitect.github.io/VBench-project/)
- 官方仓库: [Vchitect/VBench](https://github.com/Vchitect/VBench)
- License: `apache-2.0`

## 评测协议

支持两种执行模式：

- `custom_input`：对任意生成视频目录按选定维度打分（不要求官方 prompt suite）。纯视频维度如 `aesthetic_quality`、`imaging_quality`、`subject_consistency`、`temporal_flickering`、`motion_smoothness` 可直接运行；依赖文本的维度需要传 `--prompt` 或 `--prompt-file`。
- `vbench_standard`：对官方 `VBench_full_info.json` prompt suite 做 leaderboard 风格评分。生成视频必须遵守官方命名约定 `"{prompt}-{index}.mp4"`，每条 prompt 5 个样本（`index` 为 `0..4`）；runner 会在调度上游 evaluator 前预检 prompt suite 覆盖率，materialization 不完整则直接失败。

主指标是 `overall_quality`。

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/vbench.yaml
worldfoundry/evaluation/tasks/execution/runners/vbench/runtime
```

准备生成视频并让 runner 指向它：

```bash
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/generated_videos
```

`vbench_standard` 模式要求目录内每条官方 prompt 有 5 个样本：

```text
/path/to/generated_videos/
  "A cat playing piano-0.mp4"
  "A cat playing piano-1.mp4"
  ...
```

各维度权重通过共享 `vbench_perception_metric_stack` base-model 资产解析；`--load-ckpt-from-local` 可强制走本地权重。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} worldfoundry/evaluation/tasks/execution/runners/vbench/run_vbench_official_runner.py run \
  --mode custom_input \
  --dimension aesthetic_quality
```

对自定义视频目录跑单一维度：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/vbench/run_vbench_official_runner.py run \
  --mode custom_input \
  --dimension subject_consistency \
  --videos-path "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --output-dir tmp/vbench/custom \
  --json
```

导入已有的上游 VBench 结果而不重新计算：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/vbench/run_vbench_official_runner.py run \
  --from-upstream-results /path/to/vbench_full_json_dir \
  --output-dir tmp/vbench/imported \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_VBENCH_ROOT`: 可选的外部 VBench checkout 路径；未设置时使用仓内 runtime。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 候选生成视频目录。
- `WORLDFOUNDRY_VBENCH_CACHE_DIR`: VBench 维度权重缓存目录。

该 benchmark 复用共享 base-model 依赖栈：`vbench_perception_metric_stack`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `upstream_stdout.log`: 上游官方 scorer 的 stdout 日志。
- `upstream_stderr.log`: 上游官方 scorer 的 stderr 日志。

Scorecard 主键：`overall_quality`（leaderboard key `overall_quality`），写入 `scorecard.json`。

## 边界与限制

- `custom_input` 模式的部分维度得分只能作为 wiring/开发信号，不能与 leaderboard 的 VBench 总分直接比较。
- Leaderboard 级结论需要完整官方 prompt suite、每条 prompt 5 个样本，以及全部 16 个维度 evaluator 与其发布权重。
- 本地 scorecard 不等于 VBench leaderboard 提交；官方排名以上游维护者发布为准。
