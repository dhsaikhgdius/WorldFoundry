## 关于

LIBERO-Para 评测视觉-语言-动作策略在 LIBERO 任务上的语言泛化能力：每条任务指令被改写为多个语言变体，策略的得分取决于在改写指令下是否仍然成功，而不是只在标准指令措辞下成功。

WorldFoundry 仅以官方结果归一化器方式集成 LIBERO-Para。与基础 LIBERO 套件不同，LIBERO-Para 没有仓内闭环仿真适配器（仿真器注册表显式将其保持为 normalizer-only）；WorldFoundry 把调用方提供的上游结果导出——例如上游仓库 `metrics/analyze_results.py` 的输出或等价结构化导出——转换为 WorldFoundry scorecard。

官方来源：

- 论文：[huggingface.co/papers/2603.28301](https://huggingface.co/papers/2603.28301)（catalog `paper_url`）
- 官方仓库：[cau-hai-lab/LIBERO-Para](https://github.com/cau-hai-lab/LIBERO-Para)（固定 `dec2d93a`）
- 许可：MIT

## 仓内路径

- Catalog：`worldfoundry/data/benchmarks/catalog/embodied/libero-para.yaml`
- 任务清单：`worldfoundry/data/benchmarks/tasks/external/libero-para.yaml`
- 运行时 profile：`worldfoundry/data/benchmarks/runtime_profiles/official/libero-para.yaml`
- 结果归一化器：`worldfoundry.evaluation.tasks.embodied.normalizer`（track `vla`）
- 该 benchmark id 不存在仿真适配器与闭环 eval config。

## 评测协议与数据布局

embodied normalizer 接受 JSON、JSONL、CSV、TSV 及 `result.txt` 风格日志。行记录按 `success`、`success_rate`、`task_success`、`paraphrase_success_rate`、`language_generalization_success`、`action_accuracy` 等数值字段匹配；布尔值与百分比字符串会被强制转换为 [0,1] 浮点数，episode 标识从 `sample_id`/`episode_id`/`task_id`/`task`/`id`/`name` 中读取。

产出原始结果需要上游 LIBERO-Para 运行时：官方仓库 checkout（缓存于 `cache/worldfoundry/repos/cau-hai-lab--LIBERO-Para`）、HAI-Lab/LIBERO-Para 数据集根目录、所选上游 eval 脚本对应的策略 checkpoint，以及 paraphrase split 配置。

## 指标

主指标（scorecard 主键）：`success_rate`。

| 指标 | 含义 |
| --- | --- |
| `success_rate` | 改写指令下的总体 rollout 成功率；leaderboard 主值。 |
| `paraphrase_success_rate` | 限定在改写指令 episode 上的成功率。 |
| `language_generalization_success` | 有上报时，留出语言变体上的成功率。 |
| `task_success` | 按任务聚合的成功率。 |
| `action_accuracy` | 有上报时，预测动作与参考动作的一致度。 |

成功类指标经共享 registry 的 `percent_or_fraction_to_unit` 归一化；不涉及视频生成类指标。

## 准备命令与环境变量

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_LIBERO_PARA_ROOT=/path/to/LIBERO-Para
export WORLDFOUNDRY_LIBERO_PARA_RESULTS_PATH=/path/to/libero_para_results.json
```

运行时 profile 只配置通用 Python 环境（`needs_new_env: false`），不部署上游仿真器。

校验运行时接线：

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile libero-para \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/libero-para.yaml \
  --output-dir tmp/worldfoundry_preflight/libero-para \
  --json
```

## 导入官方结果（official-validation）

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id libero-para \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_LIBERO_PARA_RESULTS_PATH}" \
  --output-dir tmp/libero-para/official-validation \
  --json
```

该路径在进程内走 embodied `vla` track normalizer，不执行任何仿真代码。LIBERO-Para 没有仓内 `official-run` rollout 路径——完整运行必须用上游仓库执行后再导入。

## 输出

- `scorecard.json`：WorldFoundry scorecard；leaderboard 块以 `success_rate` 为主键。
- `raw_results.jsonl`：提取的原始结果行。
- `evaluation/summary.json`：按指标聚合的统计。
- `evaluation/per_sample_metrics.jsonl`：归一化后的逐 episode 行。

## 不能声称的边界

- catalog 状态为 `normalizer_only`，`leaderboard_valid: false`、`official_benchmark_verified: false`。导入的数字是调用方结果的归一化副本，不是官方复现的 leaderboard 值。
- 本树中尚无官方 LIBERO-Para rollout 的 leaderboard 证据；paraphrase split 映射与结果导入字段仍需在真实上游输出上验证（catalog blockers）。
- 该基准没有仓内仿真器；本页不暗示任何本地 rollout 能力。
