## About

**Publisher:** Peking University & Huawei Noah's Ark Lab (NeurIPS 2023)

FETV is a fine-grained text-to-video benchmark whose 619 prompts are categorized along three orthogonal axes: major content, attribute control, and prompt complexity. Its evaluation combines human ratings (static quality, temporal quality, overall/fine-grained alignment) with automatic metrics — CLIPScore variants, BLIP-based alignment, and FID/FVD distribution distances computed per category (FETV-EVAL).

WorldFoundry vendors the FETV-EVAL runtime in tree (`runtime/fetv_eval`), joins generated videos to the official prompt index with strict frame-layout decoding, runs the CLIPScore component through shared base-model assets, and normalizes official FETV-EVAL result directories.

## Evaluation protocol

Runner paths: import an official results CSV or a FETV-EVAL auto/manual result directory via `--official-results-path`; or recompute supported metric families in tree, selecting them with `--fetv-metrics` (e.g. `clip_score`, `blip_score`, `fid`, `fvd`). FID/FVD need reference frame directories (`--fetv-fid-real-video-dir`, `--fetv-fvd-real-video-dir`); videos are decoded to the official 16-frame layout before scoring.

Primary metric: `fetv_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `static_quality` | FETV manual static-quality score. | Higher is better |
| `temporal_quality` | FETV manual temporal-quality score. | Higher is better |
| `overall_alignment` | FETV overall text-video alignment score. | Higher is better |
| `fine_grained_alignment` | FETV fine-grained prompt-aspect alignment score. | Higher is better |
| `clip_score` | FETV automatic CLIPScore component. | Higher is better |
| `blip_score` | FETV automatic BLIPScore component. | Higher is better |
| `fid` | FETV Fréchet Inception Distance component. | Lower is better |
| `fvd` | FETV Fréchet Video Distance component. | Lower is better |
| `fetv_average` | Mean emitted only when every declared FETV component score is available. | Higher is better |

```text
worldfoundry/base_models/perception_core/video_text/fetv_blip/models/blip_retrieval.py
```

Download the FETV dataset (`lyx97/FETV` on Hugging Face) for prompts and reference-video links, generate one video per prompt index, then:

```bash
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/fetv/generated_videos
export WORLDFOUNDRY_FETV_RESULTS_PATH=/path/to/fetv_eval_results   # for import runs
```

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id fetv \
  --mode official-validation \
  --official-results-path <official_results.csv-or-FETV-EVAL-dir> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_FETV_RUNTIME_ROOT`: Optional external FETV-EVAL checkout override.
- `WORLDFOUNDRY_FETV_ARTIFACT_SCORE_DIR`: Directory of precomputed WorldFoundry artifact scores to convert.
- `WORLDFOUNDRY_FETV_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

This benchmark reuses the shared base-model dependency stack: `video_quality_motion_stack`, `fetv_blip_retrieval_source`, `fetv_stylegan_v_fvd_source`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.

Scorecard primary key: `fetv_average` (leaderboard key `fetv_average`), stored in `scorecard.json`.

## Limitations

- Human-rating metrics (`static_quality`, `temporal_quality`, alignment ratings) can only be imported, never recomputed automatically.
- Full automatic-metric parity needs BLIP/FID/FVD packages and reference frame assets staged locally.
- A local scorecard is not an official FETV leaderboard result.
