## 简介

**发表机构：** UCLA 与 Google DeepMind

VideoPhy2 是 VideoPhy 的动作中心续作。其 prompt 套件聚焦对当前生成模型系统性更难的身体活动与物体交互，并在评审中加入规则级分析：AutoEval judge 对每个视频判定哪些候选物理规则适用、各规则被遵守还是被违反，从而在 Semantic Adherence、Physical Commonsense 与主指标 Joint Score 之外给出 `rule_followed_rate`。

WorldFoundry 捆绑官方 prompt 列表，并通过共享 runner 驱动仓内 VideoPhy2 AutoEval judge，支持 LoRA adapter 权重加载。

官方参考：

- Paper: [arxiv.org/abs/2503.06800](https://arxiv.org/abs/2503.06800)
- 项目主页: [videophy2.github.io](https://videophy2.github.io/)
- 官方仓库: [Hritikbansal/videophy](https://github.com/Hritikbansal/videophy)

## 评测协议

`official-validation` 归一化官方结果导出。`--run-official` 执行仓内 VideoPhy2 AutoEval judge，需传 `--autoeval-checkpoint`（可选 `--autoeval-lora-checkpoint`），每个视频采样 `--num-frames` 帧。Joint Score 是 scorecard 主键；规则级判定汇入 `rule_followed_rate`。

主指标是 `joint_score`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `semantic_adherence` | Semantic Adherence（语义符合度）归一化基准分。 | 越高越好 |
| `physical_commonsense` | Physical Commonsense（物理常识）归一化基准分。 | 越高越好 |
| `joint_score` | Joint Score（联合分）归一化基准分。 | 越高越好 |
| `rule_followed_rate` | 判定适用的物理规则中被遵守（而非违反）的比例。 | 越高越好 |


## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id videophy2 \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

执行仓内 VideoPhy2 AutoEval judge：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/videophy2/run_videophy2_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --autoeval-checkpoint /path/to/videophy2_autoeval \
  --output-dir tmp/videophy2/official \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_VIDEOPHY2_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_VIDEOPHY2_JUDGE_BACKEND`: 选择 `--run-official` 使用的 judge 后端。
- `WORLDFOUNDRY_VIDEOPHY2_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。

该 benchmark 复用共享 base-model 依赖栈：`videophy2_dataset_assets`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。

Scorecard 主键：`joint_score`（leaderboard key `joint_score`），写入 `scorecard.json`。

## 边界与限制

- 完整官方 runtime 仍在上游；仓内 fixture 只记录期望的输入/输出形状。
- 与 leaderboard 对齐需要官方 AutoEval 权重（含 LoRA adapter）、完整 prompt 套件与上游结果归一化。
- 使用非官方权重得到的规则级判定不可与已发表 VideoPhy2 数字比较。
