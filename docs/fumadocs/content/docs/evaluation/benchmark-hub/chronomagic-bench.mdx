## About

**Publisher:** Peking University (Yuan Group, with University of Rochester)

ChronoMagic-Bench evaluates text-to-time-lapse video generation: can a model synthesize videos with large physical, biological, or chemical state changes (melting ice, blooming flowers, construction) while staying temporally coherent? The official suite pairs 1,649 prompts with two metric families: CHScore (tracking-point coherence via CoTracker) and MTScore (metamorphic amplitude, judged by InternVideo2 or GPT-4o). The release also includes the ChronoMagic-Pro/ProH training datasets.

WorldFoundry vendors the ChronoMagic-Bench runtime in tree and executes selected official component scripts directly — CHScore, MTScore, GPT4o-MTScore, then the official `get_uploaded_json.py` normalization — via `run_chronomagic_bench_official_runner.py`.

Official references:

- Paper: [arxiv.org/abs/2406.18522](https://arxiv.org/abs/2406.18522)
- Project page: [pku-yuangroup.github.io/ChronoMagic-Bench](https://pku-yuangroup.github.io/ChronoMagic-Bench/)
- Official repository: [PKU-YuanGroup/ChronoMagic-Bench](https://github.com/PKU-YuanGroup/ChronoMagic-Bench)

## Evaluation protocol

Select official components with `--components` (`all`, `chscore`, `mtscore`, `gpt4o_mtscore`) and the evaluation split with `--eval-type` (e.g. `close` for the closed 1,649-prompt set). CHScore needs a CoTracker checkpoint (`--model-pth-chscore`); MTScore needs an InternVideo2 checkpoint (`--model-pth-mtscore`); GPT4o-MTScore needs OpenAI credentials. Existing upstream results can instead be normalized through `--official-results-path` / `--from-upstream-results`.

Primary metric: `chronomagic_score`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `chronomagic_score` | Primary metamorphic time-lapse score family. | Higher is better |
| `temporal_transformation` | Time-lapse transformation and ordering consistency score family. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} worldfoundry/evaluation/tasks/execution/runners/chronomagic_bench/run_chronomagic_bench_official_runner.py \
  --chronomagic-root worldfoundry/evaluation/tasks/execution/runners/chronomagic_bench/runtime/chronomagic_bench \
  --components chscore \
  --generated-video-dir ${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR} \
  --model-name worldfoundry \
  --eval-type close \
  --model-pth-chscore ${WORLDFOUNDRY_CHRONOMAGIC_CHSCORE_CKPT} \
  --output-dir <out> \
  --python ${WORLDFOUNDRY_UNIFIED_PYTHON} \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_CHRONOMAGIC_ROOT`: Optional override pointing at an external runtime checkout.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.
- `WORLDFOUNDRY_CHRONOMAGIC_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_CHRONOMAGIC_CHSCORE_CKPT`: CoTracker checkpoint for CHScore.
- `WORLDFOUNDRY_CHRONOMAGIC_MTSCORE_CKPT`: InternVideo2 checkpoint for MTScore.
- `WORLDFOUNDRY_CHRONOMAGIC_DATASET_ROOT`: Local BestWishYsh/ChronoMagic-Bench dataset root for discovery evidence.
- `OPENAI_API_KEY`: Required for the GPT4o-MTScore component.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `per_sample_metrics.jsonl`
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `generated_video_manifest.json`
- `dataset_manifest.json`
- `upstream_stdout.log`: Captured stdout of the upstream official scorer.
- `upstream_stderr.log`: Captured stderr of the upstream official scorer.

Scorecard primary key: `chronomagic_score` (leaderboard key `chronomagic_score`), stored in `scorecard.json`.

## Limitations

- Component-level validation (e.g. CHScore only) is not leaderboard-valid; leaderboard parity additionally requires full prompt coverage, UMT-FVD, UMTScore, and the official submission protocol.
- Full official core runs need a user-supplied MTScore checkpoint and OpenAI credentials.
- One historical MTScore attempt in the worldscore environment lacked `flash_attn`/`dropout_layer_norm` for InternVideo2; install them before MTScore runs there.
