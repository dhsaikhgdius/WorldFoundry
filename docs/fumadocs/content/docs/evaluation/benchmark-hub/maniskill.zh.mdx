## 关于

ManiSkill 是构建在 SAPIEN 仿真器上的大规模机器人操作基准与框架。它提供 GPU 并行化的环境，覆盖抓放、铰接物体交互与灵巧操作，按任务套件上的 rollout 成功率做标准化策略评测。

WorldFoundry 以官方结果归一化器方式跟踪 `maniskill` catalog id：调用方提供的 rollout 结果文件被转换为 WorldFoundry scorecard。在仓内仿真器注册表中，`maniskill` 是 ManiSkill2 适配器（`worldfoundry/evaluation/tasks/embodied/simulators/maniskill2/`）的别名，闭环 rollout 走 [ManiSkill2](/docs/evaluation/benchmark-hub/maniskill2) 的 eval config。catalog 校验状态为 `normalizer_only`。

官方来源：

- 论文：[arXiv:2302.04659](https://arxiv.org/abs/2302.04659)
- 项目主页：[maniskill.ai](https://maniskill.ai/)
- 官方仓库：[haosulab/ManiSkill](https://github.com/haosulab/ManiSkill)（固定 `a4a4f927`）
- 许可：Apache-2.0

## 仓内路径

- Catalog：`worldfoundry/data/benchmarks/catalog/embodied/maniskill.yaml`
- 任务清单：`worldfoundry/data/benchmarks/tasks/external/maniskill.yaml`
- 运行时 profile：`worldfoundry/data/benchmarks/runtime_profiles/official/maniskill.yaml`
- 仿真适配器：`worldfoundry/evaluation/tasks/embodied/simulators/maniskill2/`（别名 `maniskill`）
- 结果归一化器：`worldfoundry.evaluation.tasks.embodied.normalizer`（track `vla`）

## 评测协议与数据布局

embodied normalizer 接受 JSON、JSONL、CSV、TSV 及 `result.txt` 风格日志。行记录按 `success`、`success_rate`、`task_success`、`reward`、`normalized_return` 等数值字段匹配；布尔值与百分比字符串会被强制转换为 [0,1] 浮点数，episode 标识从 `sample_id`/`episode_id`/`task_id`/`task`/`id`/`name` 中读取。

产出原始结果需要官方 ManiSkill 仓库 checkout（缓存于 `cache/vla_va_wam/repos/haosulab--ManiSkill`）、SAPIEN/ManiSkill 仿真 assets、策略 checkpoint 或控制器，以及明确的任务套件选择（catalog `requires`）。

## 指标

主指标（scorecard 主键）：`success_rate`。

| 指标 | 含义 |
| --- | --- |
| `success_rate` | 成功完成的 rollout 占比；leaderboard 主值。 |
| `task_success` | 按任务聚合的成功率。 |
| `reward` | episode 累计奖励。 |
| `normalized_return` | 有上报时，按任务参考区间归一化的 return。 |

成功类指标经共享 registry 的 `percent_or_fraction_to_unit` 归一化；不涉及视频生成类指标。

## 准备命令与环境变量

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_MANISKILL_RESULTS_PATH=/path/to/maniskill_results.json
```

运行时 profile 记录 ManiSkill/SAPIEN 在已检查环境中可导入（`needs_new_env: false`），但完整官方状态仍需要任务套件、assets 与策略 rollout，本树不执行这些内容。

校验运行时接线：

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile maniskill \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/maniskill.yaml \
  --output-dir tmp/worldfoundry_preflight/maniskill \
  --json
```

## 导入官方结果（official-validation）

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id maniskill \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_MANISKILL_RESULTS_PATH}" \
  --output-dir tmp/maniskill/official-validation \
  --json
```

该路径在进程内走 embodied `vla` track normalizer，不执行任何仿真代码。

## 闭环 rollout（经 ManiSkill2 适配器）

不存在 `maniskill` 专属 eval config；内置闭环 config 在 `maniskill2` id 下：

```bash
worldfoundry-eval embodied run \
  --config worldfoundry/data/benchmarks/eval_configs/embodied/maniskill2/eval.yaml \
  --output-dir tmp/maniskill2/embodied-run \
  --json
```

任务列表与要求见 [ManiSkill2](/docs/evaluation/benchmark-hub/maniskill2) 页面。

## 输出

- `scorecard.json`：WorldFoundry scorecard；leaderboard 块以 `success_rate` 为主键。
- `raw_results.jsonl`：提取的原始结果行。
- `evaluation/summary.json`：按指标聚合的统计。
- `evaluation/per_sample_metrics.jsonl`：归一化后的逐 episode 行。

## 不能声称的边界

- catalog 状态为 `normalizer_only`，`leaderboard_valid: false`、`official_benchmark_verified: false`。导入的数字是调用方结果的归一化副本，不是官方复现的 leaderboard 值。
- SAPIEN/ManiSkill 仿真 assets 与策略 checkpoint 均未随仓库分发；闭环 rollout 需要外部部署并运行 policy server。本页不声称任何本地 GPU rollout 证据。
- catalog blocker：官方 ManiSkill 任务套件、仿真 assets 与策略 rollout 结果映射验证完成之前，不达到 integrated 状态。
