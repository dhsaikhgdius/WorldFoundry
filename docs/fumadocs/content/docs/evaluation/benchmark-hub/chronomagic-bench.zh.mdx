## 简介

**发表机构：** Peking University（北京大学 Yuan Group，联合罗切斯特大学）

ChronoMagic-Bench 评测文本到延时摄影视频的生成能力：模型能否合成具有大幅物理、生物或化学状态变化（融冰、开花、施工）且时间上连贯的视频。官方套件为 1,649 条 prompt 配备两大指标族：CHScore（基于 CoTracker 的跟踪点连贯性）与 MTScore（蜕变幅度，由 InternVideo2 或 GPT-4o 评判）。官方同时发布了 ChronoMagic-Pro / ProH 训练数据集。

WorldFoundry 在仓内内置 ChronoMagic-Bench runtime，并由 `run_chronomagic_bench_official_runner.py` 直接执行所选官方组件脚本——CHScore、MTScore、GPT4o-MTScore，再经官方 `get_uploaded_json.py` 归一化。

官方参考：

- Paper: [arxiv.org/abs/2406.18522](https://arxiv.org/abs/2406.18522)
- 项目主页: [pku-yuangroup.github.io/ChronoMagic-Bench](https://pku-yuangroup.github.io/ChronoMagic-Bench/)
- 官方仓库: [PKU-YuanGroup/ChronoMagic-Bench](https://github.com/PKU-YuanGroup/ChronoMagic-Bench)

## 评测协议

用 `--components` 选择官方组件（`all`、`chscore`、`mtscore`、`gpt4o_mtscore`），用 `--eval-type` 选择评测集（如 `close` 对应封闭的 1,649 条 prompt 集）。CHScore 需要 CoTracker 权重（`--model-pth-chscore`）；MTScore 需要 InternVideo2 权重（`--model-pth-mtscore`）；GPT4o-MTScore 需要 OpenAI 凭据。已有上游结果可改用 `--official-results-path` / `--from-upstream-results` 归一化。

主指标是 `chronomagic_score`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `chronomagic_score` | 主要的 metamorphic 延时摄影得分族。 | 越高越好 |
| `temporal_transformation` | 延时摄影形变与顺序一致性得分族。 | 越高越好 |

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} worldfoundry/evaluation/tasks/execution/runners/chronomagic_bench/run_chronomagic_bench_official_runner.py \
  --chronomagic-root worldfoundry/evaluation/tasks/execution/runners/chronomagic_bench/runtime/chronomagic_bench \
  --components chscore \
  --generated-video-dir ${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR} \
  --model-name worldfoundry \
  --eval-type close \
  --model-pth-chscore ${WORLDFOUNDRY_CHRONOMAGIC_CHSCORE_CKPT} \
  --output-dir <out> \
  --python ${WORLDFOUNDRY_UNIFIED_PYTHON} \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_CHRONOMAGIC_ROOT`: 可选覆盖项，指向外部 runtime checkout。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。
- `WORLDFOUNDRY_CHRONOMAGIC_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_CHRONOMAGIC_CHSCORE_CKPT`: CHScore 使用的 CoTracker 权重。
- `WORLDFOUNDRY_CHRONOMAGIC_MTSCORE_CKPT`: MTScore 使用的 InternVideo2 权重。
- `WORLDFOUNDRY_CHRONOMAGIC_DATASET_ROOT`: 本地 BestWishYsh/ChronoMagic-Bench 数据集根，用作 discovery 证据。
- `OPENAI_API_KEY`: GPT4o-MTScore 组件必需。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `per_sample_metrics.jsonl`
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `generated_video_manifest.json`
- `dataset_manifest.json`
- `upstream_stdout.log`: 上游官方 scorer 的 stdout 日志。
- `upstream_stderr.log`: 上游官方 scorer 的 stderr 日志。

Scorecard 主键：`chronomagic_score`（leaderboard key `chronomagic_score`），写入 `scorecard.json`。

## 边界与限制

- 组件级验证（如仅 CHScore）不具 leaderboard 效力；leaderboard 对齐还需完整 prompt 覆盖、UMT-FVD、UMTScore 与官方提交协议。
- 完整官方核心运行需要用户提供 MTScore 权重与 OpenAI 凭据。
- 历史记录：worldscore 环境中的一次 MTScore 尝试缺少 InternVideo2 所需的 `flash_attn`/`dropout_layer_norm`，在该环境运行 MTScore 前需先安装。
