## 简介

**发表机构：** Google DeepMind（verified 协议由 Anates Labs 打包发布）

Physics-IQ-Verified 是 Physics-IQ 协议的推荐修订版。它修复了原始发布中的 prompt/mask 不一致，将 verified 条件帧与 switch-view 元数据以 Hugging Face 数据集（`Anates-Labs-Research/Physics-IQ-Verified`）发布，并在聚合前按视角逐一打分。底层物理理解方法论与 Google DeepMind 的 Physics-IQ 一致。

WorldFoundry 通过与 Physics-IQ 相同的仓内 runner 运行它（`--protocol physics-iq-verified`），verified 资产记录在 `worldfoundry/data/benchmarks/assets/physics-iq-verified`。

官方参考：

- Paper: [arxiv.org/abs/2606.18943](https://arxiv.org/abs/2606.18943)
- 项目主页: [physics-iq-verified.anates.ai](https://physics-iq-verified.anates.ai/)
- 官方仓库: [google-deepmind/physics-IQ-benchmark](https://github.com/google-deepmind/physics-IQ-benchmark)

## 评测协议

每次运行对 198 个生成的 5 秒视频用逐视角 verified mask 与真实续写对比打分；维护者建议 leaderboard 结论对四次运行取平均。导入（`--official-results-path raw_metrics.csv`）与重算（`--run-official`）路径与基础协议一致。

主指标是 `physics_iq_verified_score`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `physics_iq_verified_score` | 按场景、按视角做物理方差归一化后的算术平均。 | 越高越好 |
| `physics_iq_verified_spatiotemporal` | 时空 IoU：运动发生的位置与时间与 verified 真实续写的重合度。 | 越高越好 |
| `physics_iq_verified_spatial` | 空间 IoU：动作发生的位置（不考虑时间）。 | 越高越好 |
| `physics_iq_verified_weighted_spatial` | 加权空间 IoU：动作发生的位置与幅度。 | 越高越好 |
| `physics_iq_verified_mse` | 相对 verified 真实续写的逐像素 MSE。 | 越高越好 |

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/physics-iq-verified.yaml
worldfoundry/data/benchmarks/assets/physics-iq-verified
worldfoundry/evaluation/tasks/execution/runners/physics_iq
```

下载 verified 数据集，并按场景 id 准备生成续写：

```bash
hf download Anates-Labs-Research/Physics-IQ-Verified \
  --repo-type dataset \
  --local-dir /path/to/physics-iq-verified

export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/physics-iq-verified/generated_videos
```

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id physics-iq-verified \
  --mode official-validation \
  --official-results-path <raw_metrics.csv> \
  --output-dir <out> \
  --json
```

从生成续写重新计算 verified 指标：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/physics_iq/run_physics_iq_official_runner.py \
  --protocol physics-iq-verified \
  --run-official \
  --dataset-root /path/to/physics-iq-verified \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --output-dir tmp/physics-iq-verified/official-run \
  --strict \
  --json
```

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `raw_metrics.csv`
- `official_metrics.json`
- `results_summary.csv`
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `per_sample_scores.jsonl`: 当结果源包含逐样本数值时写出的逐样本行。

Scorecard 主键：`physics_iq_verified_score`（leaderboard key `physics_iq_verified_score`），写入 `scorecard.json`。

## 边界与限制

- verified 媒体需从 Hugging Face 数据集拉取，仓内不做再分发。
- 单次运行覆盖 198 个视频；leaderboard 级结论需要官方建议的四次运行平均。
- verified 分数与原始协议 Physics-IQ 分数不可互相比较，本地结果也不是官方 leaderboard 条目。
