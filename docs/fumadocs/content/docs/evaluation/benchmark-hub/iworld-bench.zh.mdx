## 简介

**发表机构：** Tsinghua University（清华大学，联合中国东北大学、华南理工大学）

iWorld-Bench（ICML 2026）评测交互式世界模型——响应外部动作序列的生成器——其统一动作生成框架（Action Generation Framework）打通了异构控制接口（文本动作、相机矩阵、轨迹）。它从 33 万视频片段中筛出 2.1k 覆盖多视角、多天气、多场景的高质量样本，定义六类任务（4.9k 测试样本），联合考察视觉生成质量、轨迹跟随与记忆能力（如 `memory_symmetry` 衡量出画再入画内容的一致性）。

WorldFoundry 包装官方指标 runtime，把 iWorld-Bench 报告 CSV/JSON 归一化为 scorecard；有界的纯像素 `memory` 组件无需编译版 VIPe runtime 即可运行。

官方参考：

- 项目主页: [iworld-bench.com](https://iworld-bench.com/)
- 官方仓库: [EmbodiedCity/iWorld-Bench](https://github.com/EmbodiedCity/iWorld-Bench)
- License: `Apache-2.0`

## 评测协议

`--run-official` 用 `--metric` 选择组件（目录记录的有界命令用 `--metric memory`），用 `--split` 选择任务分割；完整官方执行需要数据集元数据、VBench 资产与 CUDA 兼容的 VIPe 构建。`--official-results-path` 归一化已有报告输出；`WORLDFOUNDRY_IWORLD_BENCH_RUNTIME_BACKEND` 选择 runtime 后端。

主指标是 `iworldbench_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `image_quality` | 生成视频的帧级画质。 | 越高越好 |
| `brightness_consistency` | 生成帧间的亮度稳定性。 | 越高越好 |
| `color_temperature_constraint` | 场景约束下的色温稳定性。 | 越高越好 |
| `sharpness_retention` | rollout 全程的清晰度保持。 | 越高越好 |
| `motion_smoothness` | 时序运动平滑度。 | 越高越好 |
| `trajectory_accuracy` | 执行轨迹相对指令动作的准确度。 | 越高越好 |
| `trajectory_tolerance` | 带容差带的轨迹跟随得分。 | 越高越好 |
| `memory_symmetry` | 出画再入画内容的一致性。 | 越高越好 |
| `trajectory_alignment` | 生成相机轨迹与指令轨迹的对齐度。 | 越高越好 |
| `iworldbench_average` | 可用 iWorld-Bench 指标族的均值。 | 越高越好 |

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} worldfoundry/evaluation/tasks/execution/runners/iworldbench/run_iworldbench_official_runner.py \
  --run-official \
  --generated-videos-dir ${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR} \
  --metric memory \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_IWORLD_BENCH_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_IWORLD_BENCH_DATASET_ROOT`: 本地官方数据集根目录。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`
- `WORLDFOUNDRY_IWORLD_BENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_IWORLD_BENCH_RUNTIME_BACKEND`

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `upstream_command.json`

Scorecard 主键：`iworldbench_average`（leaderboard key `iworldbench_average`），写入 `scorecard.json`。

## 边界与限制

- 超出有界 memory 指标的完整官方 GPU 执行需要 VBench 资产与 CUDA/Torch 兼容的 VIPe 扩展构建；内置 VIPe 树缺少原生扩展源码。
- 仅跑有界 memory 的运行只覆盖一个组件，不是完整 iWorld-Bench 成绩。
- 部分指标的方向元数据由上游定义；比较时请对照官方报告格式。
