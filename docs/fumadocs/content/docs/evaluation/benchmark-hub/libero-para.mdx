## About

LIBERO-Para evaluates language generalization of vision-language-action policies on LIBERO tasks: each task instruction is paraphrased into multiple linguistic variants, and a policy is scored on whether success holds across paraphrases rather than only on the canonical instruction wording.

WorldFoundry integrates LIBERO-Para as an official result normalizer only. Unlike the base LIBERO suites, there is no in-tree closed-loop simulator adapter for LIBERO-Para (the simulator registry explicitly keeps it normalizer-only); WorldFoundry converts caller-provided upstream result exports — for example the output of `metrics/analyze_results.py` in the upstream repo or an equivalent structured export — into WorldFoundry scorecards.

Official references:

- Paper: [huggingface.co/papers/2603.28301](https://huggingface.co/papers/2603.28301) (catalog `paper_url`)
- Official source reference: [cau-hai-lab/LIBERO-Para](https://github.com/cau-hai-lab/LIBERO-Para) (pinned `dec2d93a`)
- License: MIT

## In-tree integration

- Catalog: `worldfoundry/data/benchmarks/catalog/embodied/libero-para.yaml`
- Task manifest: `worldfoundry/data/benchmarks/tasks/external/libero-para.yaml`
- Runtime profile: `worldfoundry/data/benchmarks/runtime_profiles/official/libero-para.yaml`
- Result normalizer: `worldfoundry.evaluation.tasks.embodied.normalizer` (track `vla`)
- No simulator adapter and no closed-loop eval config exist for this benchmark id.

## Evaluation protocol and result layout

The embodied normalizer accepts JSON, JSONL, CSV, TSV, and `result.txt`-style logs. Rows are matched on numeric fields such as `success`, `success_rate`, `task_success`, `paraphrase_success_rate`, `language_generalization_success`, and `action_accuracy`; booleans and percent strings are coerced to unit-interval floats, and episode identity is read from `sample_id`/`episode_id`/`task_id`/`task`/`id`/`name`.

Producing the raw results requires the upstream LIBERO-Para runtime: the official repository checkout (cached at `cache/worldfoundry/repos/cau-hai-lab--LIBERO-Para`), the HAI-Lab/LIBERO-Para dataset root, a policy checkpoint for the selected upstream eval script, and the paraphrase split configuration.

## Metrics

Primary metric (scorecard key): `success_rate`.

| Metric | Meaning |
| --- | --- |
| `success_rate` | Overall rollout success across paraphrased instructions; primary leaderboard value. |
| `paraphrase_success_rate` | Success restricted to paraphrased-instruction episodes. |
| `language_generalization_success` | Success on held-out linguistic variations, when reported. |
| `task_success` | Per-task success aggregated across episodes. |
| `action_accuracy` | Agreement of predicted actions with reference actions where reported. |

Success metrics are normalized via the shared registry (`percent_or_fraction_to_unit`). No video-generation metrics apply.

## Preparation and environment

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_LIBERO_PARA_ROOT=/path/to/LIBERO-Para
export WORLDFOUNDRY_LIBERO_PARA_RESULTS_PATH=/path/to/libero_para_results.json
```

The runtime profile configures only the generic Python environment (`needs_new_env: false`); it does not stage the upstream simulator.

Verify runtime wiring:

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile libero-para \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/libero-para.yaml \
  --output-dir tmp/worldfoundry_preflight/libero-para \
  --json
```

## Import official results (official-validation)

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id libero-para \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_LIBERO_PARA_RESULTS_PATH}" \
  --output-dir tmp/libero-para/official-validation \
  --json
```

This routes through the embodied `vla`-track normalizer in-process; no simulator code is executed. There is no in-tree `official-run` rollout path for LIBERO-Para — full runs must be executed with the upstream repository and then imported.

## Outputs

- `scorecard.json`: WorldFoundry scorecard; leaderboard block keyed by `success_rate`.
- `raw_results.jsonl`: extracted raw result rows.
- `evaluation/summary.json`: aggregated per-metric statistics.
- `evaluation/per_sample_metrics.jsonl`: normalized per-episode rows.

## What this page does not claim

- Catalog status is `normalizer_only` with `leaderboard_valid: false` and `official_benchmark_verified: false`. Imported numbers are normalized copies of caller-provided results, not officially reproduced leaderboard values.
- Official LIBERO-Para rollout execution has not produced leaderboard evidence in this tree; paraphrase split mapping and result import fields must be validated on real upstream outputs (catalog blockers).
- No in-tree simulator exists for this benchmark; nothing on this page implies local rollout capability.
