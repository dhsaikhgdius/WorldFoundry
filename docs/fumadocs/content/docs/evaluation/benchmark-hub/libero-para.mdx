## About

**Publisher:** Soongsil University & Chung-Ang University

LIBERO-Para diagnoses paraphrase robustness in vision-language-action models. Built on LIBERO-Goal — where all tasks share an identical initial state, making the instruction the sole task cue — it independently varies action expressions and object references (4,092 held-out paraphrases across 43 categories, including 30 compositional types). The release also introduces PRIDE, a metric that weights success by paraphrase difficulty using semantic and syntactic factors.

WorldFoundry integrates LIBERO-Para as an official-results runner with the `HAI-Lab/LIBERO-Para` dataset tracked as a staged asset; upstream rollout exports are normalized into the unified scorecard.

Official references:

- Paper: [huggingface.co/papers/2603.28301](https://huggingface.co/papers/2603.28301)
- Official repository: [cau-hai-lab/LIBERO-Para](https://github.com/cau-hai-lab/LIBERO-Para)
- License: `mit`

## Evaluation protocol

WorldFoundry integrates this benchmark through the unified result-import path: `worldfoundry-eval zoo benchmark-run --mode official-validation` normalizes a caller-provided official result export (JSON/CSV rollout summaries) into the WorldFoundry scorecard without executing the simulator. Simulator execution, policy loading, and rollout collection remain explicit upstream steps performed with the official tooling.

Primary metric: `success_rate`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `success_rate` | Primary episode success rate over evaluated rollouts. | Higher is better |
| `paraphrase_success_rate` | Success rate under paraphrased instructions. | Higher is better |
| `language_generalization_success` | Success aggregate over linguistic-variation splits. | Higher is better |
| `task_success` | Per-task success aggregate. | Higher is better |
| `action_accuracy` | Offline action-prediction accuracy against reference actions. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id libero-para \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_LIBERO_PARA_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_LIBERO_PARA_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_LIBERO_PARA_DATASET_ROOT`: Local root of the staged official dataset.

This benchmark reuses the shared base-model dependency stack: `libero_para_source_assets`, `libero_para_dataset_assets`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `raw_results.jsonl`: Normalized rows parsed from the official result export.

Scorecard primary key: `success_rate` (leaderboard key `success_rate`), stored in `scorecard.json`.

## Limitations

- Official LIBERO-Para rollout execution has not produced leaderboard evidence in this workspace.
- Paraphrase split mapping and result-import fields must be validated on real upstream outputs.
- Imported scorecards are integration evidence, not leaderboard submissions.
