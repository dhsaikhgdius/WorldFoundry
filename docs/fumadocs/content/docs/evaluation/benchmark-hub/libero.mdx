## About

**Publisher:** The University of Texas at Austin (with Tsinghua & Sony AI)

LIBERO (NeurIPS 2023 D&B) benchmarks knowledge transfer in lifelong robot learning: four task suites — LIBERO-Spatial, LIBERO-Object, LIBERO-Goal, and LIBERO-100 — probe how manipulation policies transfer declarative and procedural knowledge across tasks in a robosuite/MuJoCo tabletop setting. It has become the de-facto evaluation target for vision-language-action models.

WorldFoundry supports both paths: normalizer-first scorecards through `worldfoundry.evaluation.tasks.embodied.normalizer` (official result import), and native closed-loop execution wired through `worldfoundry-eval embodied run`. LIBERO dataset snapshots (`yifengzhu-hf/LIBERO-datasets`, `lerobot/libero`) and the upstream repo are tracked as staged assets.

Official references:

- Paper: [arxiv.org/abs/2306.03310](https://arxiv.org/abs/2306.03310)
- Project page: [libero-project.github.io](https://libero-project.github.io/)
- Official repository: [Lifelong-Robot-Learning/LIBERO](https://github.com/Lifelong-Robot-Learning/LIBERO)
- License: `mit`

## Evaluation protocol

Result import normalizes an official eval_result tree or structured export via `--official-results-path` / `WORLDFOUNDRY_LIBERO_RESULTS_PATH`. Closed-loop execution needs the upstream simulator runtime, task-suite assets, and a policy checkpoint for the selected upstream eval script.

Primary metric: `success_rate`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `success_rate` | Primary episode success rate over evaluated rollouts. | Higher is better |
| `task_success` | Per-task success aggregate. | Higher is better |
| `episode_success` | Per-episode success indicator aggregate. | Higher is better |
| `action_accuracy` | Offline action-prediction accuracy against reference actions. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id libero \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_LIBERO_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_LIBERO_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.

This benchmark reuses the shared base-model dependency stack: `libero_source_assets`, `libero_dataset_assets`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `run_manifest.json`: Manifest of the executed rollout run.
- `results.jsonl`: Per-episode rollout records.
- `metrics/summary.json`: Aggregated metric summary for the run.

Scorecard primary key: `success_rate` (leaderboard key `success_rate`), stored in `scorecard.json`.

## Limitations

- Full leaderboard parity requires a recorded LIBERO/OpenVLA parity run with simulator assets and policy checkpoints.
- Imported scorecards are integration evidence, not leaderboard submissions.
- Suite selection and evaluation seeds must match the upstream protocol for comparability.
