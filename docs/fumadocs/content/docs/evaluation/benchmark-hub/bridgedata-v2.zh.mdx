## 关于

BridgeData V2 是大规模、多样化的真机操作示范数据集（WidowX 250 机械臂上 6 万余条轨迹，覆盖多场景多技能），用于训练与评测可泛化、开放词表的机器人策略。评测方式是在数据分布内的任务上 rollout 策略并报告成功率；与仿真基准不同，官方评测涉及作者定义的真机或离线协议。

WorldFoundry 仅以官方结果归一化器方式集成 BridgeData V2：调用方提供的评测结果文件被转换为 WorldFoundry scorecard。仓内没有仿真适配器（仿真器注册表显式将 BridgeData V2 保持为 normalizer-only），本树不执行任何 rollout。

官方来源：

- 论文：[arXiv:2308.12952](https://arxiv.org/abs/2308.12952)
- 项目主页：[rail-berkeley.github.io/bridgedata](https://rail-berkeley.github.io/bridgedata/)
- 官方仓库：[rail-berkeley/bridge_data_v2](https://github.com/rail-berkeley/bridge_data_v2)（固定 `bc60a35b`）
- 许可：MIT
- Hugging Face 状态：`third_party_conversions_only`——官方下载走 HTTP/项目主页，不是确认过的 HF 基准表。

## 仓内路径

- Catalog：`worldfoundry/data/benchmarks/catalog/embodied/bridgedata-v2.yaml`
- 任务清单：`worldfoundry/data/benchmarks/tasks/external/bridgedata-v2.yaml`
- 运行时 profile：`worldfoundry/data/benchmarks/runtime_profiles/official/bridgedata-v2.yaml`
- 结果归一化器：`worldfoundry.evaluation.tasks.embodied.normalizer`（track `vla`）
- 该 benchmark id 不存在仿真适配器与闭环 eval config。

## 评测协议与数据布局

catalog 声明数据集根目录为 `${WORLDFOUNDRY_DATA_DIR}/datasets/bridgedata-v2`，split 为 `eval`。数据集物化、eval split 定义、动作归一化与任务-目标映射由调用方负责（catalog `requires`）。

结果导入侧，embodied normalizer 接受 JSON、JSONL、CSV、TSV 及 `result.txt` 风格日志。行记录按 `success`、`success_rate`、`task_success`、`goal_success`、`action_accuracy`、`rollout_success` 等数值字段匹配；布尔值与百分比字符串会被强制转换为 [0,1] 浮点数。

## 指标

主指标（scorecard 主键）：`success_rate`。

| 指标 | 含义 |
| --- | --- |
| `success_rate` | 评测 rollout 的成功占比；leaderboard 主值。 |
| `task_success` | 按任务聚合的成功率。 |
| `goal_success` | 协议区分目标与任务时的目标条件成功率。 |
| `action_accuracy` | 离线协议下预测动作与参考动作的一致度。 |
| `rollout_success` | 单独上报时的逐 rollout 二值成功。 |

成功类指标经共享 registry 的 `percent_or_fraction_to_unit` 归一化；不涉及视频生成类指标。

## 准备命令与环境变量

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_BRIDGEDATA_V2_RESULTS_PATH=/path/to/bridgedata_v2_results.json
```

运行时 profile 只配置通用 Python 环境（`needs_new_env: false`），不下载数据集也不部署任何机器人运行时。

校验运行时接线：

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile bridgedata-v2 \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/bridgedata-v2.yaml \
  --output-dir tmp/worldfoundry_preflight/bridgedata-v2 \
  --json
```

## 导入官方结果（official-validation）

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id bridgedata-v2 \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_BRIDGEDATA_V2_RESULTS_PATH}" \
  --output-dir tmp/bridgedata-v2/official-validation \
  --json
```

该路径在进程内走 embodied `vla` track normalizer。BridgeData V2 没有仓内 `official-run` rollout 路径——评测必须用上游工具或真机环境产出后再导入。

## 输出

- `scorecard.json`：WorldFoundry scorecard；leaderboard 块以 `success_rate` 为主键。
- `raw_results.jsonl`：提取的原始结果行。
- `evaluation/summary.json`：按指标聚合的统计。
- `evaluation/per_sample_metrics.jsonl`：归一化后的逐 rollout 行。

## 不能声称的边界

- catalog 状态为 `normalizer_only`，`leaderboard_valid: false`、`official_benchmark_verified: false`。导入的数字是调用方结果的归一化副本，不是官方复现的 leaderboard 值。
- BridgeData V2 数据集未随仓库分发；数据集物化、split 定义与策略结果导入验证仍未完成（catalog blocker）。
- 本树不发生任何机器人或仿真执行；本页不暗示任何本地 rollout 能力。
