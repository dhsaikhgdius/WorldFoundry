## 简介

**发表机构：** UC Berkeley（加州大学伯克利分校 RAIL 实验室）

BridgeData V2 是 UC Berkeley RAIL 的大规模真实机器人操作数据集——在低成本 WidowX 机械臂上跨 24 个环境采集的 6 万余条轨迹——用于训练与评测具备语言/目标图像条件的广义机器人策略。评测按脚本化真机或离线协议报告任务成功率。

WorldFoundry 以官方结果 runner 集成 BridgeData V2：策略评测导出（任务/目标成功率、动作准确率、rollout 成功率）被归一化为统一 scorecard；数据集就位与策略 rollout 保持在上游完成。

官方参考：

- Paper: [arxiv.org/abs/2308.12952](https://arxiv.org/abs/2308.12952)
- 项目主页: [rail-berkeley.github.io/bridgedata](https://rail-berkeley.github.io/bridgedata/)
- 官方仓库: [rail-berkeley/bridge_data_v2](https://github.com/rail-berkeley/bridge_data_v2)
- License: `mit`

## 评测协议

WorldFoundry 通过统一的结果导入路径集成该 benchmark：`worldfoundry-eval zoo benchmark-run --mode official-validation` 把调用方提供的官方结果导出（JSON/CSV rollout 汇总）归一化为 WorldFoundry scorecard，不执行模拟器。模拟器执行、策略加载与 rollout 采集仍是使用官方工具完成的显式上游步骤。

主指标是 `success_rate`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `success_rate` | 评测 rollout 上的主成功率（逐 episode 成功比例）。 | 越高越好 |
| `task_success` | 按任务聚合的成功率。 | 越高越好 |
| `goal_success` | 目标图像条件下的任务成功率。 | 越高越好 |
| `action_accuracy` | 相对参考动作的离线动作预测准确率。 | 越高越好 |
| `rollout_success` | 已执行策略 rollout 的成功率。 | 越高越好 |

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/bridgedata-v2.yaml
```

```text
<official_results.json>                 # 官方工具产出的 rollout 汇总导出
${WORLDFOUNDRY_BRIDGEDATA_V2_RESULTS_PATH}   # 默认导入路径
```
数据集就位在 `${WORLDFOUNDRY_DATA_DIR}/datasets/bridgedata-v2`；官方下载走 HTTP/项目主页，而非单一 Hugging Face 数据表。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id bridgedata-v2 \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_BRIDGEDATA_V2_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_results.jsonl`: 从官方结果导出解析出的归一化行。

Scorecard 主键：`success_rate`（leaderboard key `success_rate`），写入 `scorecard.json`。

## 边界与限制

- 数据集就位、评测分割定义与策略结果导入验证是达到 integrated 状态的前置条件。
- WorldFoundry 不为 BridgeData V2 运行真机或仿真 rollout；动作归一化与任务-目标映射遵循上游协议。
- 导入的 scorecard 是集成证据，不是 leaderboard 提交。
