## About

**Publisher:** Allen Institute for AI (Ai2)

AI2-THOR is the Allen Institute for AI's interactive 3D environment for embodied AI: near photo-realistic household scenes with actionable objects, physics, and an agent that navigates and manipulates through discrete actions. It underpins task suites such as ALFRED and TEACh.

WorldFoundry wires AI2-THOR as a *native closed-loop simulator*: `worldfoundry-eval embodied run` boots the Unity-based simulator, steps a policy that emits discrete simulator tokens (`forward`, `left`, `pickup`, …), and writes rollout records plus a scorecard. Default scene tasks (e.g. FloorPlan1) are provided for wiring validation.

Official references:

- Paper: [ai2thor.allenai.org/](https://ai2thor.allenai.org/)
- Official repository: [allenai/ai2thor](https://github.com/allenai/ai2thor)
- License: `upstream_terms`

## Evaluation protocol

Closed-loop runs are driven by eval configs under `worldfoundry/data/benchmarks/eval_configs/embodied/ai2thor/`; the policy is a checkpoint or an external policy server that maps observations to discrete simulator tokens. Result import via `WORLDFOUNDRY_AI2THOR_RESULTS_PATH` normalizes existing rollout summaries instead.

Primary metric: `success_rate`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `success_rate` | Primary episode success rate over evaluated rollouts. | Higher is better |
| `task_success` | Per-task success aggregate. | Higher is better |
| `episode_success` | Per-episode success indicator aggregate. | Higher is better |
| `reward` | Mean episode reward / return. | Higher is better |



Requires the AI2-THOR Python package, the Unity simulator build/cache, and a headless CloudRendering or X11 display backend.

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval embodied run \
  --config worldfoundry/data/benchmarks/eval_configs/embodied/ai2thor/floorplan1.yaml
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_AI2THOR_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_AI2THOR_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `run_manifest.json`: Manifest of the executed rollout run.
- `results.jsonl`: Per-episode rollout records.
- `metrics/summary.json`: Aggregated metric summary for the run.

Scorecard primary key: `success_rate` (leaderboard key `success_rate`), stored in `scorecard.json`.

## Limitations

- Official task suites such as ALFRED/TEACh are not bundled yet; the default scene tasks validate wiring only.
- Non-zero rollouts require a policy checkpoint or an external policy server.
- Closed-loop scores over default scene tasks are not comparable to published ALFRED/TEACh numbers.
