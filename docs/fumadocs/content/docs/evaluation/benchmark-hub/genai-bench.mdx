## About

**Publisher:** TIGER-Lab, University of Waterloo

GenAI-Bench (released with the GenAI-Arena platform) measures how well automatic judges align with human preferences over generative outputs. Each record pairs candidate outputs for the same prompt with a human preference label; a judge's prediction is scored by pairwise accuracy overall and per task (image generation, image editing, video generation).

WorldFoundry normalizes official GenAI-Bench result exports through the in-tree runner into pairwise-accuracy metrics and a standard scorecard.

Official references:

- Paper: [arxiv.org/abs/2406.04485](https://arxiv.org/abs/2406.04485)
- Project page: [github.com/TIGER-AI-Lab/GenAI-Bench](https://github.com/TIGER-AI-Lab/GenAI-Bench)
- Official repository: [TIGER-AI-Lab/GenAI-Bench](https://github.com/TIGER-AI-Lab/GenAI-Bench)

## Evaluation protocol

Result rows must expose a task field (`image_generation`, `image_editing`, or `video_generation`), a human label (`human_label`/`human_preference`), and a judge prediction (`prediction`/`judge_prediction`). `--preference-pairs-path` supplies the pair inventory; `--run-fixture` exercises the wiring with bundled fixtures.

Primary metric: `genai_bench_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `pairwise_accuracy` | GenAI-Bench pairwise accuracy against human preference labels across available tasks. | Higher is better |
| `image_generation_preference_accuracy` | GenAI-Bench image-generation preference accuracy against human labels. | Higher is better |
| `image_editing_preference_accuracy` | GenAI-Bench image-editing preference accuracy against human labels. | Higher is better |
| `video_preference_accuracy` | GenAI-Bench video-generation preference accuracy against human labels. | Higher is better |
| `genai_bench_average` | Mean of task preference accuracies when task-level labels and predictions are available. | Higher is better |

## Data and artifact layout

In-tree paths:

worldfoundry/data/benchmarks/tasks/external/genai-bench.yaml

```bash
export WORLDFOUNDRY_GENAI_BENCH_RESULTS_PATH=/path/to/genai_bench_results.jsonl
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/generated_artifacts
```

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id genai-bench \
  --mode official-validation \
  --official-results-path <official_results.jsonl> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_GENAI_BENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

This benchmark reuses the shared base-model dependency stack: `genai_bench_dataset_assets`, `t2v_metrics_source_assets`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `benchmark_contract.json`: Benchmark contract record for the run (inputs, mode, provenance).
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.

Scorecard primary key: `genai_bench_average` (leaderboard key `genai_bench_average`), stored in `scorecard.json`.

## Limitations

- This is a judge-alignment benchmark: it scores predictions against human preference labels and does not synthesize preference data itself.
- Leaderboard-grade claims require official human preference labels (or judge outputs) plus the referenced generated artifacts.
- A local scorecard is not a GenAI-Arena leaderboard entry.
