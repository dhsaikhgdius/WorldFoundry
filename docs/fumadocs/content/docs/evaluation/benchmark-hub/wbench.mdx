## About

**Publisher:** Meituan (LongCat team)

WBench, from Meituan's LongCat team, evaluates multi-turn interactive video world models along five dimensions: quality (aesthetic/imaging/flicker/dynamics/smoothness/HPSv3), setting adherence (scene/subject), interaction (navigation trajectory, event edits, subject actions, perspective switches), consistency (background, segment continuity, perspective, subject, geometric and photometric reconstruction, spatial), and physical (visual plausibility, causal fidelity). Dimension means roll up into `wbench_average`.

WorldFoundry checks in the WBench metric runtime and backs it with shared base-model assets — HPSv3, TransNetV2 (segment continuity), PAVRM (visual plausibility), DreamSim, and MegaSAM pose precompute — while `--official-results-path` normalizes existing WBench `report.json` or per-metric evaluation directories.

Official references:

- Paper: [arxiv.org/abs/2605.25874](https://arxiv.org/abs/2605.25874)
- Project page: [meituan-longcat.github.io/WBench](https://meituan-longcat.github.io/WBench/)
- Official repository: [meituan-longcat/WBench](https://github.com/meituan-longcat/WBench)

## Evaluation protocol

`--run-official` needs `--model-name` (or `WORLDFOUNDRY_MODEL_ID`), `--dataset-root` pointing at the WBench dataset, and officially named generated videos; `--phase gpu` selects the GPU metric phase and `--metrics` restricts computation. Pass `--submission-protocol text_multi_turn|camera_conditioned|action_conditioned` only when the videos genuinely follow that official multi-turn interface. Generated videos are staged into an isolated work directory under `--output-dir`.

Primary metric: `wbench_average`.

## Data and artifact layout

In-tree paths:

```text
worldfoundry/data/benchmarks/tasks/external/wbench.yaml
worldfoundry/evaluation/tasks/execution/runners/wbench
```

```text
worldfoundry/evaluation/tasks/execution/runners/wbench      # checked-in metric runtime
<WBench_dataset>/                                           # HF dataset meituan-longcat/WBench
${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}/                     # officially named generated videos
```

Metric weights come from Hugging Face `meituan-longcat/WBench-weights`.

## Run the benchmark

Catalog-recorded validation command:

```bash
python worldfoundry/evaluation/tasks/execution/runners/wbench/run_wbench_official_runner.py \
  --run-official \
  --model-name <model_name> \
  --phase gpu \
  --metrics temporal_flickering \
  --dataset-root <WBench_dataset> \
  --generated-artifact-dir <one_officially_named_generated_video> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_WBENCH_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_WBENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.

Shared checkpoint assets: `meituan-longcat/WBench-weights` (metric_weights).

This benchmark reuses the shared base-model dependency stack: `video_world_perception_stack`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.

Scorecard primary key: `wbench_average` (leaderboard key `wbench_average`), stored in `scorecard.json`.

## Limitations

- A video-only or partial-metric run is integration evidence only; WBench comparability additionally requires a declared multi-turn submission protocol and full official coverage.
- Leaderboard-valid scores require a complete official report for the full split.
- Official GitHub sources are provenance only; runtime execution uses the checked-in WorldFoundry runner.
