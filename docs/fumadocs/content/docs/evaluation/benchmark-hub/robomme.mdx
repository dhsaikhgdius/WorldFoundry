## About

**Publisher:** University of Michigan (with Stanford & Figure AI)

RoboMME (ICML 2026 Spotlight) is the first large-scale standardized benchmark for memory-augmented robotic manipulation. Following cognitive memory taxonomy, its 16 long-horizon tasks split into four suites: **Counting** (temporal memory — repeat actions an exact number of times), **Permanence** (spatial memory — track objects through occlusion and swaps), **Reference** (object memory — resolve identity from earlier visual/language cues), and **Imitation** (procedural memory — reproduce demonstrated trajectories). The release includes 770k training timesteps and 14 memory-augmented VLA variants on the π0.5 backbone.

WorldFoundry integrates RoboMME as an official-results runner: per-suite success rates from upstream rollout exports are normalized into the unified scorecard.

Official references:

- Paper: [arxiv.org/abs/2603.04639](https://arxiv.org/abs/2603.04639)
- Official repository: [RoboMME/robomme_policy_learning](https://github.com/RoboMME/robomme_policy_learning)
- License: `upstream_terms`

## Evaluation protocol

WorldFoundry integrates this benchmark through the unified result-import path: `worldfoundry-eval zoo benchmark-run --mode official-validation` normalizes a caller-provided official result export (JSON/CSV rollout summaries) into the WorldFoundry scorecard without executing the simulator. Simulator execution, policy loading, and rollout collection remain explicit upstream steps performed with the official tooling.

Primary metric: `success_rate`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `success_rate` | Primary episode success rate over evaluated rollouts. | Higher is better |
| `counting_success_rate` | Success rate on the Counting suite (temporal memory). | Higher is better |
| `permanence_success_rate` | Success rate on the Permanence suite (spatial memory). | Higher is better |
| `reference_success_rate` | Success rate on the Reference suite (object memory). | Higher is better |
| `imitation_success_rate` | Success rate on the Imitation suite (procedural memory). | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id robomme \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_ROBOMME_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_ROBOMME_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `raw_results.jsonl`: Normalized rows parsed from the official result export.
- `evaluation/summary.json`: Aggregated evaluation summary.

Scorecard primary key: `success_rate` (leaderboard key `success_rate`), stored in `scorecard.json`.

## Limitations

- WorldFoundry normalizes supplied rollout results; it does not run the official simulator or policies in tree.
- Full leaderboard parity is not claimed until official rollouts are executed with staged simulator assets and policy checkpoints, then imported.
- Imported scorecards are integration evidence, not leaderboard submissions.
