## 关于

VLABench 是面向语言条件机器人操作的大规模基准，强调需要世界知识与推理的任务——按语言指令在干扰物中选出正确的水果、玩具、饮品、书籍或画作——而不是单纯的运动技能。它提供带成功谓词的标准化原语与组合任务族，用于视觉-语言-动作评测。

WorldFoundry 通过仓内闭环仿真适配器 `worldfoundry/evaluation/tasks/embodied/simulators/vlabench/`（别名 `vla-bench`、`vla_bench`）以及共享官方结果归一化器集成 VLABench。catalog 校验状态为 `normalizer_only`。

官方来源：

- 论文：[arXiv:2502.09858](https://arxiv.org/abs/2502.09858)（catalog `paper_url`）
- 官方仓库：[OpenMOSS/VLABench](https://github.com/OpenMOSS/VLABench)
- 许可：上游条款（见仓库）

## 仓内路径

- Catalog：`worldfoundry/data/benchmarks/catalog/embodied/vlabench.yaml`
- 任务清单：`worldfoundry/data/benchmarks/tasks/external/vlabench.yaml`
- 运行时 profile：`worldfoundry/data/benchmarks/runtime_profiles/official/vlabench.yaml`
- 仿真适配器：`worldfoundry/evaluation/tasks/embodied/simulators/vlabench/`
- 闭环 eval config：`worldfoundry/data/benchmarks/eval_configs/embodied/vlabench/eval.yaml`
- 结果归一化器：`worldfoundry.evaluation.tasks.embodied.normalizer`（track `vla`）

## 评测协议与数据布局

结果导入侧，embodied normalizer 接受 JSON、JSONL、CSV、TSV 及 `result.txt` 风格日志。行记录按 `success`、`success_rate`、`task_success`、`episode_success`、`reward` 等数值字段匹配；布尔值与百分比字符串会被强制转换为 [0,1] 浮点数。

内置 eval config rollout 五个选择任务（`select_fruit`、`select_toy`、`select_drink`、`select_book`、`select_painting`），Franka 机器人、最长 200 步、每任务 20 个 episode，由 `ws://localhost:8000` 上的外部 policy server 驱动。

## 指标

主指标（scorecard 主键）：`success_rate`。

| 指标 | 含义 |
| --- | --- |
| `success_rate` | 成功完成的 rollout 占比；leaderboard 主值。 |
| `task_success` | 按任务聚合的成功率。 |
| `episode_success` | 单 episode 的二值成功。 |
| `reward` | episode 累计奖励。 |

成功类指标经共享 registry 的 `percent_or_fraction_to_unit` 归一化；不涉及视频生成类指标。

## 准备命令与环境变量

```bash
cd /path/to/WorldFoundry
export WORLDFOUNDRY_VLABENCH_ROOT=/path/to/VLABench
export WORLDFOUNDRY_VLABENCH_RESULTS_PATH=/path/to/vlabench_results.json
```

运行时 profile 标记 `needs_new_env: true`。闭环 rollout 需要 VLABench 运行时、其仿真 assets，以及通过 WebSocket 提供动作的策略 checkpoint（catalog `required_assets`）。

校验运行时接线：

```bash
python -m worldfoundry.evaluation.tasks.execution.orchestration.runtime_preflight \
  --profile vlabench \
  --manifest worldfoundry/data/benchmarks/runtime_profiles/official/vlabench.yaml \
  --output-dir tmp/worldfoundry_preflight/vlabench \
  --json
```

## 导入官方结果（official-validation）

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id vlabench \
  --mode official-validation \
  --official-results-path "${WORLDFOUNDRY_VLABENCH_RESULTS_PATH}" \
  --output-dir tmp/vlabench/official-validation \
  --json
```

该路径在进程内走 embodied `vla` track normalizer，不执行任何仿真代码。

## 闭环 rollout（原生仿真器）

```bash
worldfoundry-eval embodied run \
  --config worldfoundry/data/benchmarks/eval_configs/embodied/vlabench/eval.yaml \
  --output-dir tmp/vlabench/embodied-run \
  --json
```

`embodied run` 入口支持 `--server-url`、`--shard-id`/`--num-shards`、`--no-docker`。

## 输出

- `scorecard.json`：WorldFoundry scorecard；leaderboard 块以 `success_rate` 为主键。
- `raw_results.jsonl`：提取的原始结果行。
- `evaluation/summary.json`：按指标聚合的统计。
- `evaluation/per_sample_metrics.jsonl`：归一化后的逐 episode 行。

## 不能声称的边界

- catalog 状态为 `normalizer_only`，`leaderboard_valid: false`、`official_benchmark_verified: false`。导入的数字是调用方结果的归一化副本，不是官方复现的 leaderboard 值。
- VLABench 运行时、仿真 assets、策略 checkpoint 均未随仓库分发；闭环 rollout 需要外部环境（`needs_new_env: true`）并运行 policy server。本页不声称任何本地 GPU rollout 证据。
- catalog blocker：官方 rollout 执行并导入之前，不声称完整 leaderboard 对齐。
