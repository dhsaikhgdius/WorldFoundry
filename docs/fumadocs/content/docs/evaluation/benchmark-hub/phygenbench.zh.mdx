## 简介

**发表机构：** 上海人工智能实验室（OpenGVLab）

PhyGenBench 检验文生视频模型是否遵守物理常识。它提供 160 条 prompt，覆盖力学、光学、热学、材料属性四大领域的 27 条物理定律；生成视频由 PhyGenEval 层级流水线评分——逐阶段 judge（VQAScore、GPT-4o/LLaVA 风格 VLM 判断、InternVideo2）的输出交给 `overall.py` 聚合，得到 Physical Commonsense 与 Semantic Adherence 分数。

WorldFoundry 在仓内捆绑了官方 prompt 列表与 PhyGenEval 的 `overall.py` 聚合。仓内 runner 支持两条路径：导入调用方提供的官方结果文件；或对已准备好的 stage 输出执行有界的 `overall.py` 聚合。

官方参考：

- Paper: [arxiv.org/abs/2410.05363](https://arxiv.org/abs/2410.05363)
- 项目主页: [phygenbench123.github.io](https://phygenbench123.github.io/)
- 官方仓库: [OpenGVLab/PhyGenBench](https://github.com/OpenGVLab/PhyGenBench)

## 评测协议

official-validation 模式把官方 PhyGenBench 结果导出归一化到 WorldFoundry 指标面。有界的 `--run-official` 路径只对已准备好的 stage 输出执行 PhyGenEval `overall.py` 聚合——它不运行 VQAScore、GPT-4o/LLaVA 或 InternVideo2 阶段 judge，因此仅有聚合结果不构成官方 benchmark 证据。

主指标是 `phygenbench_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `physical_commonsense` | Physical Commonsense（物理常识）归一化基准分。 | 越高越好 |
| `physical_law_adherence` | Physical Law Adherence（物理定律遵循）归一化基准分。 | 越高越好 |
| `semantic_adherence` | Semantic Adherence（语义符合度）归一化基准分。 | 越高越好 |
| `phygenbench_average` | PhyGenBench 平均分（归一化基准分）。 | 越高越好 |

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/phygenbench.yaml
worldfoundry/data/benchmarks/assets/phygenbench/PhyGenBench/prompts.json
worldfoundry/evaluation/tasks/execution/runners/phygenbench/runtime/phygenbench/PhyGenEval/overall.py
```

捆绑资产与 runtime 聚合脚本都在仓内；候选生成视频由调用方提供：

```text
worldfoundry/data/benchmarks/assets/phygenbench/PhyGenBench/prompts.json   # 官方 160 条 prompt
.../runners/phygenbench/runtime/phygenbench/PhyGenEval/overall.py          # 有界聚合入口
${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}/                                    # 候选视频
```

不需要 Hugging Face 数据集：prompt 资产已捆绑，结果导入 / 已备 stage 聚合均基于文件。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id phygenbench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

对已准备好的 stage 输出执行有界 PhyGenEval overall 聚合：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/phygenbench/run_phygenbench_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --output-dir tmp/phygenbench/official \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_PHYGENBENCH_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_PHYGENBENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。

Scorecard 主键：`phygenbench_average`（leaderboard key `phygenbench_average`），写入 `scorecard.json`。

## 边界与限制

- WorldFoundry 不执行 PhyGenEval 各阶段 judge（VQAScore、GPT-4o/LLaVA、InternVideo2）；仅有有界 overall 聚合不构成官方 benchmark 证据。
- mock 后端输出是确定性接线数据，绝不能作为 benchmark 证据上报。
- 与 leaderboard 可比的数字需要在官方 160 条 prompt 套件上运行完整上游 PhyGenEval 流水线。
