## 简介

**发表机构：** Chinese Academy of Sciences（中国科学院）与 Tsinghua University（清华大学，联合瑞莱智慧 RealAI）

T2VSafetyBench 是首个面向文生视频模型的综合安全评测。它定义了 4 个主类、14 个视频生成安全关键维度——色情、边缘色情、暴力、血腥、公众人物、歧视、政治敏感、违法活动、令人不适内容、虚假信息、版权，以及视频特有的*时序风险*（只有跨帧才显现的不安全内容）——恶意 prompt 数据集由真实世界 prompt、LLM 生成 prompt 与越狱攻击 prompt 构成。视频由 GPT 按维度判定 NSFW/安全，与人工复核相关性高；所有指标均为越低越好的 NSFW 比率。

WorldFoundry 同时支持官方结果导入与严格的 prompt-视频就位后送入入库 GPT judge；命令构造、就位、失败语义与归一化均经测试，且绝不把 mock API 当作指标证据。

官方参考：

- Paper: [arxiv.org/abs/2407.05965](https://arxiv.org/abs/2407.05965)

## 评测协议

导入模式通过 `WORLDFOUNDRY_T2V_SAFETY_BENCH_RESULTS_PATH` / `--official-results-path` 归一化官方结果导出。judge 模式把生成视频与所选 prompt 类别对齐就位（`--classes`、`--prompt-path`），并驱动入库的上游 GPT 评审 prompt（`--gpt-model`、`--api-base`）；`--limit` 限定集成运行规模。scorecard 主键为 `nsfw_average`。

主指标是 `nsfw_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `pornography_nsfw_rate` | 色情内容 NSFW 触发率（归一化基准分）。 | 越低越好 |
| `borderline_pornography_nsfw_rate` | 边缘色情内容 NSFW 触发率（归一化基准分）。 | 越低越好 |
| `violence_nsfw_rate` | 暴力内容 NSFW 触发率（归一化基准分）。 | 越低越好 |
| `gore_nsfw_rate` | 血腥内容 NSFW 触发率（归一化基准分）。 | 越低越好 |
| `public_figures_nsfw_rate` | 公众人物 NSFW 触发率（归一化基准分）。 | 越低越好 |
| `discrimination_nsfw_rate` | 歧视内容 NSFW 触发率（归一化基准分）。 | 越低越好 |
| `political_sensitivity_nsfw_rate` | 政治敏感 NSFW 触发率（归一化基准分）。 | 越低越好 |
| `illegal_activities_nsfw_rate` | 违法活动 NSFW 触发率（归一化基准分）。 | 越低越好 |
| `disturbing_content_nsfw_rate` | 不适内容 NSFW 触发率（归一化基准分）。 | 越低越好 |

官方 prompt 类别随源仓库提供；不需要 Hugging Face 数据集。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id t2v-safety-bench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_T2V_SAFETY_BENCH_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_T2V_SAFETY_BENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。
- `WORLDFOUNDRY_T2V_SAFETY_BENCH_GPT_API_KEY`: GPT judge 的 API key（回退到 `OPENAI_API_KEY`）。
- `WORLDFOUNDRY_T2V_SAFETY_BENCH_GPT_MODEL`: GPT 评审使用的 judge 模型覆盖项。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。

Scorecard 主键：`nsfw_average`（leaderboard key `nsfw_average`），写入 `scorecard.json`。

## 边界与限制

- 真实 judge 执行需要用户提供 API 凭据；发布验证期间未运行。
- 完整验证需要覆盖全部官方 prompt 类别的所有生成视频。
- leaderboard 对齐需要与 benchmark 作者相同的 judge 模型与协议；mock API 运行绝不构成指标证据。
