## About

**Publisher:** UCLA (with Sony AI, Yale & DEVCOM ARL)

WorldBench diagnoses how close world models are to the physical world. It uses Kubric (PyBullet + Blender) to render 425 physically accurate scenes across four concepts — motion physics, object permanence, support relations, and scale/perspective — each with ground-truth depth, normals, segmentation, and flow. Models generate video continuations from initial frames; SAM2 propagates first-frame object boxes through the generated video and the masks are compared against ground-truth simulation (foreground mIoU, background RMSE). A textual subset adds multiple-choice and yes/no questions.

WorldFoundry implements the evaluator in tree as a model-backed runner over the `worldbenchmark/IntuitivePhysics` dataset, reporting both the conventional mIoU and the public release's Dice-named compatibility value separately.

Official references:

- Paper: [arxiv.org/abs/2601.21282](https://arxiv.org/abs/2601.21282)
- Project page: [world-bench.github.io](https://world-bench.github.io/)

## Evaluation protocol

`--run-official` evaluates raw generated videos (needs the SAM2.1-hiera-large checkpoint) or precomputed masks via `--predicted-mask-dir`; `--video-only` / `--text-only` restrict tracks, and `--answer-manifest` supplies textual answers. Compatibility import via `WORLDFOUNDRY_WORLDBENCH_RESULTS_PATH` normalizes existing result files. Frame alignment knobs (`--ground-truth-start-frame`, `--generated-skip-frames`) handle conditioning offsets.

Primary metric: `foreground_miou`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `foreground_miou` | Conventional per-object IoU averaged across objects, frames, and scenes. | Higher is better |
| `foreground_dice` | Compatibility value computed by the public release while naming it mIoU. | Higher is better |
| `background_rmse` | RGBA RMSE over pixels labeled as background in the ground-truth segmentation. | Lower is better |
| `text_based_accuracy` | Exact normalized answer accuracy over available WorldBench textual questions. | Higher is better |
| `multiple_choice_accuracy` | Accuracy over questions containing an explicit Options list. | Higher is better |
| `binary_accuracy` | Accuracy over WorldBench yes/no questions. | Higher is better |

## Run the benchmark

Run the video track over generated continuations:

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/worldbench/run_worldbench_official_runner.py \
  --run-official \
  --video-only \
  --dataset-root "${WORLDFOUNDRY_WORLDBENCH_DATASET_ROOT}" \
  --generated-video-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --sam2-checkpoint "${WORLDFOUNDRY_WORLDBENCH_SAM2_CKPT}" \
  --output-dir tmp/worldbench/video \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_WORLDBENCH_DATASET_ROOT`: Local root of the staged official dataset.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.
- `WORLDFOUNDRY_WORLDBENCH_ANSWER_MANIFEST`
- `WORLDFOUNDRY_WORLDBENCH_SAM2_CKPT`
- `WORLDFOUNDRY_WORLDBENCH_RESULTS_PATH`

Shared checkpoint assets: `facebook/sam2.1-hiera-large`.

This benchmark reuses the shared base-model dependency stack: `worldbench_dataset_assets`, `sam2`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `worldbench_evaluation.json`

Scorecard primary key: `foreground_miou` (leaderboard key `foreground_miou`), stored in `scorecard.json`.

## Limitations

- The dataset and evaluator bundle declare no redistribution license; treat assets as upstream-controlled.
- The public evaluator calls Dice "mIoU" and contains unresolved runtime defects; WorldFoundry reports both overlap definitions separately.
- Full-dataset numerical parity and an official submission protocol have not been audited.
