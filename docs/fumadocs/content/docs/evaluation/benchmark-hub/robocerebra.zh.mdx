## 简介

**发表机构：** Beihang University（北京航空航天大学 CoLa 实验室）

RoboCerebra 来自北京航空航天大学 CoLa 实验室，评测需要在反应式底层控制之上进行深思式高层规划（“cerebra” System-2 推理）的长时程机器人操作：加长的家务任务序列包含动态子目标变化、观测核查与记忆要求，由分层的 VLM 规划器 + VLA 控制器栈完成评测。

WorldFoundry 以官方结果 runner 集成 RoboCerebra：rollout 导出被归一化为统一 scorecard。

官方参考：

- Paper: [arxiv.org/abs/2502.02853](https://arxiv.org/abs/2502.02853)
- 官方仓库: [buaa-colalab/RoboCerebra](https://github.com/buaa-colalab/RoboCerebra)
- License: `upstream_terms`

## 评测协议

WorldFoundry 通过统一的结果导入路径集成该 benchmark：`worldfoundry-eval zoo benchmark-run --mode official-validation` 把调用方提供的官方结果导出（JSON/CSV rollout 汇总）归一化为 WorldFoundry scorecard，不执行模拟器。模拟器执行、策略加载与 rollout 采集仍是使用官方工具完成的显式上游步骤。

主指标是 `success_rate`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `success_rate` | 评测 rollout 上的主成功率（逐 episode 成功比例）。 | 越高越好 |
| `task_success` | 按任务聚合的成功率。 | 越高越好 |
| `episode_success` | 逐 episode 成功指示的聚合值。 | 越高越好 |
| `reward` | 平均 episode 奖励 / 回报。 | 越高越好 |

```text
<official_results.json>                 # 官方工具产出的 rollout 汇总导出

```

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id robocerebra \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_ROBOCEREBRA_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_ROBOCEREBRA_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_results.jsonl`: 从官方结果导出解析出的归一化行。
- `evaluation/summary.json`: 聚合评测摘要。

Scorecard 主键：`success_rate`（leaderboard key `success_rate`），写入 `scorecard.json`。

## 边界与限制

- WorldFoundry 只归一化所提供的 rollout 结果；不在仓内运行官方模拟器或策略。
- 在用就位的模拟器资产与策略权重执行官方 rollout 并导入之前，不声称完整 leaderboard 对齐。
- 导入的 scorecard 是集成证据，不是 leaderboard 提交。
