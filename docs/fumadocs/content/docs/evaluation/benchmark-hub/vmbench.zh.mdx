## 简介

**发表机构：** 阿里巴巴高德地图（AMAP-ML）

VMBench（ICCV 2025）用五个感知对齐指标评测运动生成质量：perceptible amplitude、object integrity、temporal coherence、commonsense adherence 与 motion smoothness。prompt suite 包含 1,050 条以运动为核心的 prompt；生成视频由本地指标 runtime 打分，无需任何托管 judge API。

WorldFoundry 把官方 VMBench 指标代码内置在仓内（`runtime/official`），prompt suite 打包在 `worldfoundry/data/benchmarks/assets/vmbench/prompts/prompts.json`，既可运行内置指标，也可归一化官方 `results.json`/`scores.csv` 导出。

官方参考：

- Paper: [openaccess.thecvf.com/content/ICCV2025/html/Ling_VMBench_A_Benchmark_for_Perception-Aligned_Video_Motion_Generation_ICCV_2025_paper.html](https://openaccess.thecvf.com/content/ICCV2025/html/Ling_VMBench_A_Benchmark_for_Perception-Aligned_Video_Motion_Generation_ICCV_2025_paper.html)
- 项目主页: [amap-ml.github.io/VMBench-Website](https://amap-ml.github.io/VMBench-Website/)
- 官方仓库: [AMAP-ML/VMBench](https://github.com/AMAP-ML/VMBench)
- License: `apache-2.0`

## 评测协议

生成视频必须遵守官方 prompt-index 命名约定 `0001.mp4` … `1050.mp4`。runner 从视频目录 materialize `meta_info` 行，随后调度内置指标栈（`--run-official`），或导入官方结果导出（`--official-results-path` / `--from-upstream-results`）。

主指标是 `vmbench_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `perceptible_amplitude_score` | Official VMBench PAS metric for perceptible motion amplitude. | 越高越好 |
| `object_integrity_score` | Official VMBench OIS metric for object identity and integrity under motion. | 越高越好 |
| `temporal_coherence_score` | Official VMBench TCS metric for temporal coherence. | 越高越好 |
| `commonsense_adherence_score` | Official VMBench CAS metric for action and motion commonsense adherence. | 越高越好 |
| `motion_smoothness_score` | Official VMBench MSS metric for motion smoothness. | 越高越好 |
| `vmbench_average` | Mean of available official VMBench PAS/OIS/TCS/CAS/MSS component scores. | 越高越好 |

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id vmbench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

对生成视频运行内置指标栈：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/vmbench/run_vmbench_official_runner.py \
  --run-official \
  --generated-video-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --prompt-manifest "${WORLDFOUNDRY_VMBENCH_PROMPT_MANIFEST}" \
  --output-dir tmp/vmbench/official-run \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_VMBENCH_PROMPT_MANIFEST`: prompt manifest 路径；默认使用仓内内置 suite。
- `WORLDFOUNDRY_VMBENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。

该 benchmark 复用共享 base-model 依赖栈：`motion_stack`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `per_sample_metrics.jsonl`
- `upstream_stdout.log`: 上游官方 scorer 的 stdout 日志。
- `upstream_stderr.log`: 上游官方 scorer 的 stderr 日志。

Scorecard 主键：`vmbench_average`（leaderboard key `Avg`），写入 `scorecard.json`。

## 边界与限制

- 完整指标重算是 GPU 重载任务，需要 CUDA 指标依赖与多个检测/跟踪权重。
- 集成时官方 Hugging Face 数据集端点未公开；仓内 prompt bundle 是被跟踪的数据源。
- 本地 scorecard 不是官方 VMBench leaderboard 结果。
