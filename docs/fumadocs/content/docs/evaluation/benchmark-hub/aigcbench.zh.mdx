## 简介

**发表机构：** BenchCouncil（中国科学院计算技术研究所）

AIGCBench 评测图生视频，指标族覆盖首帧保真（与条件图像的 MSE/SSIM）、图-视频与文-视频 CLIP 对齐、参考视频对比（关键帧与对应帧 CLIP、SSIM）、运动强度（光流平方均值）、时序连贯（相邻帧 CLIP）与感知质量（DOVER）。

WorldFoundry 从官方 Hugging Face 数据集 materialize AIGCBench prompt 列表，通过自有模型集成生成候选视频，再由仓内 runner 导入指标产物并写出标准 scorecard。内置资产位于 `worldfoundry/data/benchmarks/assets/aigcbench`。

官方参考：

- Paper: [arxiv.org/abs/2401.01651](https://arxiv.org/abs/2401.01651)
- 项目主页: [huggingface.co/papers/2401.01651](https://huggingface.co/papers/2401.01651)
- 官方仓库: [BenchCouncil/AIGCBench](https://github.com/BenchCouncil/AIGCBench)
- License: `apache-2.0`

## 评测协议

runner 可导入官方指标 CSV 导出（`--official-results-path`），或导入 WorldFoundry 评测管线产出的指标（`--run-official` 处理已准备的 artifact scores）。参考图像/参考视频指标族需要相应官方资产；`--prompt-manifest` 可将打分限制到指定 prompt 子集，`--strict` 在覆盖缺口时直接失败。

主指标是 `aigcbench_average`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `mse_first` | AIGCBench：条件图像与生成首帧间的 MSE；越低越好。 | 越低越好 |
| `ssim_first` | AIGCBench：条件图像与生成首帧间的 SSIM。 | 越高越好 |
| `image_genvideo_clip` | AIGCBench：条件图像与生成视频间的 CLIP 相似度。 | 越高越好 |
| `genvideo_text_clip` | AIGCBench：生成视频与文本 prompt 间的 CLIP 相似度。 | 越高越好 |
| `genvideo_refvideo_clip_keyframes` | AIGCBench：生成视频与参考视频关键帧间的 CLIP 相似度。 | 越高越好 |
| `flow_square_mean` | AIGCBench：生成视频运动效果的光流平方均值。 | 越高越好 |
| `genvideo_refvideo_clip_corresponding_frames` | AIGCBench：生成视频与参考视频对应帧间的 CLIP 相似度。 | 越高越好 |
| `genvideo_clip_adjacent_frames` | AIGCBench：相邻帧 CLIP 相似度（时序一致性）。 | 越高越好 |
| `frame_count` | AIGCBench：生成视频帧数。 | 越高越好 |
| `dover` | AIGCBench：DOVER 视频质量分。 | 越高越好 |
| `genvideo_refvideo_ssim` | AIGCBench：生成视频与参考视频间的 SSIM。 | 越高越好 |
| `aigcbench_average` | AIGCBench：由官方 scorer 或归一化输出提供的官方聚合分。 | 越高越好 |

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/aigcbench.yaml
worldfoundry/data/benchmarks/assets/aigcbench
```

```bash
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/aigcbench/generated_videos
export WORLDFOUNDRY_AIGCBENCH_RESULTS_PATH=/path/to/aigcbench_metrics.csv
```

内置 `prompt_suite.json` 支持不下载完整数据集即可 materialize 生成请求；leaderboard 对齐仍需官方数据集资产。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id aigcbench \
  --mode official-validation \
  --official-results-path <official_results.csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_AIGCBENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。

该 benchmark 复用共享 base-model 依赖栈：`video_quality_motion_stack`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。

Scorecard 主键：`aigcbench_average`（leaderboard key `aigcbench_average`），写入 `scorecard.json`。

## 边界与限制

- 依赖参考的指标（首帧保真、参考视频 CLIP/SSIM）只有在准备了官方参考资产时才有意义。
- Leaderboard 对齐需要官方 prompt suite 的生成视频，以及 CLIP/DOVER/光流指标输出。
- 本地 scorecard 不是官方 AIGCBench leaderboard 结果。
