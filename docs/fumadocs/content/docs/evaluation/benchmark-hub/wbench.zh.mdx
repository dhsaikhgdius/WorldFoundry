## 简介

**发表机构：** Meituan（美团 LongCat 团队）

WBench 由美团 LongCat 团队发布，沿五个维度评测多轮交互视频世界模型：质量（美学/成像/闪烁/动态度/平滑度/HPSv3）、设定遵循（场景/主体）、交互（导航轨迹、事件编辑、主体动作、视角切换）、一致性（背景、片段连续性、视角、主体、几何与光度重建、空间）与物理（视觉合理性、因果保真）。各维度均值汇总为 `wbench_average`。

WorldFoundry 入库了 WBench 指标 runtime，并以共享 base-model 资产支撑——HPSv3、TransNetV2（片段连续性）、PAVRM（视觉合理性）、DreamSim、MegaSAM 位姿预计算；`--official-results-path` 可归一化已有的 WBench `report.json` 或逐指标评测目录。

官方参考：

- Paper: [arxiv.org/abs/2605.25874](https://arxiv.org/abs/2605.25874)
- 项目主页: [meituan-longcat.github.io/WBench](https://meituan-longcat.github.io/WBench/)
- 官方仓库: [meituan-longcat/WBench](https://github.com/meituan-longcat/WBench)

## 评测协议

`--run-official` 需要 `--model-name`（或 `WORLDFOUNDRY_MODEL_ID`）、指向 WBench 数据集的 `--dataset-root`，以及按官方规则命名的生成视频；`--phase gpu` 选择 GPU 指标阶段，`--metrics` 限定计算范围。只有当生成视频确实遵循官方多轮接口时才传 `--submission-protocol text_multi_turn|camera_conditioned|action_conditioned`。生成视频会被就位到 `--output-dir` 下的隔离工作目录。

主指标是 `wbench_average`。

## 数据与产物布局

WorldFoundry 仓内路径：

```text
worldfoundry/data/benchmarks/tasks/external/wbench.yaml
worldfoundry/evaluation/tasks/execution/runners/wbench
```

```text
worldfoundry/evaluation/tasks/execution/runners/wbench      # 入库指标 runtime
<WBench_dataset>/                                           # HF 数据集 meituan-longcat/WBench
${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}/                     # 按官方规则命名的生成视频
```

指标权重来自 Hugging Face `meituan-longcat/WBench-weights`。

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
python worldfoundry/evaluation/tasks/execution/runners/wbench/run_wbench_official_runner.py \
  --run-official \
  --model-name <model_name> \
  --phase gpu \
  --metrics temporal_flickering \
  --dataset-root <WBench_dataset> \
  --generated-artifact-dir <one_officially_named_generated_video> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_WBENCH_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_WBENCH_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: 存放待评测生成产物（候选视频/rollout）的目录。

共享 checkpoint 资产：`meituan-longcat/WBench-weights`（metric_weights）。

该 benchmark 复用共享 base-model 依赖栈：`video_world_perception_stack`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。

Scorecard 主键：`wbench_average`（leaderboard key `wbench_average`），写入 `scorecard.json`。

## 边界与限制

- 仅视频或部分指标的运行只是集成证据；WBench 可比性还要求声明多轮提交协议并覆盖完整官方集。
- leaderboard 有效分数需要完整分割上的完整官方报告。
- 官方 GitHub 源仅作为 provenance；runtime 执行使用入库的 WorldFoundry runner。
