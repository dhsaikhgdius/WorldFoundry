## About

**Publisher:** Beihang University (CoLa Lab)

RoboCerebra, from Beihang University's CoLa Lab, benchmarks long-horizon robotic manipulation that requires deliberate high-level planning ("cerebra" System-2 reasoning) on top of reactive low-level control: extended household task sequences with dynamic subgoal changes, observation checks, and memory demands, evaluated by hierarchical VLM-planner + VLA-controller stacks.

WorldFoundry integrates RoboCerebra as an official-results runner: rollout exports are normalized into the unified scorecard.

Official references:

- Paper: [arxiv.org/abs/2502.02853](https://arxiv.org/abs/2502.02853)
- Official repository: [buaa-colalab/RoboCerebra](https://github.com/buaa-colalab/RoboCerebra)
- License: `upstream_terms`

## Evaluation protocol

WorldFoundry integrates this benchmark through the unified result-import path: `worldfoundry-eval zoo benchmark-run --mode official-validation` normalizes a caller-provided official result export (JSON/CSV rollout summaries) into the WorldFoundry scorecard without executing the simulator. Simulator execution, policy loading, and rollout collection remain explicit upstream steps performed with the official tooling.

Primary metric: `success_rate`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `success_rate` | Primary episode success rate over evaluated rollouts. | Higher is better |
| `task_success` | Per-task success aggregate. | Higher is better |
| `episode_success` | Per-episode success indicator aggregate. | Higher is better |
| `reward` | Mean episode reward / return. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id robocerebra \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_ROBOCEREBRA_ROOT`: Optional override pointing at a local benchmark runtime/repository root.
- `WORLDFOUNDRY_ROBOCEREBRA_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `raw_results.jsonl`: Normalized rows parsed from the official result export.
- `evaluation/summary.json`: Aggregated evaluation summary.

Scorecard primary key: `success_rate` (leaderboard key `success_rate`), stored in `scorecard.json`.

## Limitations

- WorldFoundry normalizes supplied rollout results; it does not run the official simulator or policies in tree.
- Full leaderboard parity is not claimed until official rollouts are executed with staged simulator assets and policy checkpoints, then imported.
- Imported scorecards are integration evidence, not leaderboard submissions.
