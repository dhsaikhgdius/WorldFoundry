## About

**Publisher:** Shanghai Jiao Tong University (with NUS, CMU, Stanford et al.)

Video-Bench (CVPR 2025) evaluates generated video with MLLM judges aligned to human preference. Its dimensions split into two families: video quality (imaging quality, aesthetics, temporal consistency, motion effects, on a 1-5 scale) and video-condition alignment (overall video-text consistency on 1-5; object class, color, action, and scene consistency on 1-3). Few-shot scoring and chain-of-query techniques give the GPT-4o judge structured, human-correlated assessments; the release includes a human-annotation dataset for calibration.

WorldFoundry vendors the Video-Bench runtime and wraps it: official `*_score_results.json` outputs are normalized with the 1-5/1-3 ranges mapped to 0-1, runtime execution passes the resolved generated-video directory to the official `evaluate.py`, prompt metadata is rebuilt from the human-annotation JSONs when `VideoBench_full.json` is unavailable, and a temporary private config is written from environment variables instead of mutating the upstream `config.json`.

## Evaluation protocol

Import mode normalizes official score results via `--official-results-path`. Runtime mode needs a generated-video directory (`--generated-video-dir` / `--model-output-dir`), the human-annotation root, and GPT-4o (+ optional GPT-4o-mini) API credentials; `--dimension` restricts judging to selected dimensions and `--mode` selects the judging protocol. Local preflight validates annotation mirrors, prompt manifests, video decode, layout matching, and dependency imports.

Primary metric: `videobench_average`.

| Metric | Meaning | Direction |
| --- | --- | --- |
| `imaging_quality` | Video-Bench static image quality score on the official 1-5 scale. | Higher is better |
| `aesthetic_quality` | Video-Bench aesthetic quality score on the official 1-5 scale. | Higher is better |
| `temporal_consistency` | Video-Bench temporal consistency score on the official 1-5 scale. | Higher is better |
| `motion_effects` | Video-Bench motion effects score on the official 1-5 scale. | Higher is better |
| `video_text_consistency` | Video-Bench overall video-text consistency score on the official 1-5 scale. | Higher is better |
| `object_class_consistency` | Video-Bench object-class consistency score on the official 1-3 scale. | Higher is better |
| `color_consistency` | Video-Bench color consistency score on the official 1-3 scale. | Higher is better |
| `action_consistency` | Video-Bench action consistency score on the official 1-3 scale. | Higher is better |
| `scene_consistency` | Video-Bench scene consistency score on the official 1-3 scale. | Higher is better |
| `videobench_average` | Mean normalized score across available Video-Bench dimensions. | Higher is better |

## Run the benchmark

Catalog-recorded validation command:

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id video-bench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir <out> \
  --json
```

## Checkpoints and environment variables

- `WORLDFOUNDRY_VIDEOBENCH_ROOT`: Optional override pointing at an external runtime checkout.
- `WORLDFOUNDRY_VIDEOBENCH_RESULTS_PATH`: Default path the importer reads official result exports from when `--official-results-path` is not passed.
- `WORLDFOUNDRY_GENERATED_ARTIFACT_DIR`: Directory containing the candidate generated artifacts to score or import against.
- `WORLDFOUNDRY_VIDEOBENCH_GPT4O_API_KEY`: GPT-4o judge API key (falls back to OPENAI_API_KEY).
- `WORLDFOUNDRY_VIDEOBENCH_ANNOTATION_ROOT`: Override for the human-annotation dataset root.
- `WORLDFOUNDRY_VIDEOBENCH_MODEL_OUTPUT_DIR`: Model output tree holding the generated videos to judge.

This benchmark reuses the shared base-model dependency stack: `video_bench_dataset_assets`.

## Outputs

The run writes into `--output-dir`:

- `scorecard.json`: WorldFoundry scorecard with the metric values recorded above.
- `per_sample_scores.jsonl`: Per-sample rows when the result source exposes sample-level values.
- `raw_metric_table.jsonl`: Metric rows backing the scorecard.
- `upstream_stdout.log`: Captured stdout of the upstream official scorer.
- `upstream_stderr.log`: Captured stderr of the upstream official scorer.

Scorecard primary key: `videobench_average` (leaderboard key `overall_average`), stored in `scorecard.json`.

## Limitations

- Official GPT judge execution is gated only by explicit user-provided API credentials; missing credentials are a runtime configuration requirement, not an integration blocker.
- Access to the gated Video-Bench_videos dataset is needed only when official videos are required.
- Full leaderboard parity requires the complete official assets, generated artifacts, and verified scorecard evidence.
