## 简介

**发表机构：** The University of Hong Kong（香港大学）与 Shanghai AI Laboratory（上海人工智能实验室，联合松灵机器人 AgileX）

RoboTwin 2.0 是可扩展的双臂机器人操作仿真评测：五种机器人形态、731 个物体上的 50 个双臂任务，配自动专家数据生成器与系统性域随机化（杂物、光照、背景、桌面高度、语言指令）以度量鲁棒性——clean 与 randomized 成功率分开跟踪。配套预采集数据集超过 10 万条轨迹。

WorldFoundry 把官方 `eval_result/_result.txt` 与结构化 JSON/CSV 导出导入为 scorecard 产物，包括任务 manifest、官方命令 manifest 与模拟器验证记录。离线归一化不需要模拟器；真实对齐需要上游 SAPIEN/Curobo 栈。

官方参考：

- Paper: [arxiv.org/abs/2506.18088](https://arxiv.org/abs/2506.18088)
- 项目主页: [robotwin-platform.github.io](https://robotwin-platform.github.io/)
- 官方仓库: [RoboTwin-Platform/RoboTwin](https://github.com/RoboTwin-Platform/RoboTwin)

## 评测协议

离线归一化通过 `--official-results-path` / `WORLDFOUNDRY_ROBOTWIN_RESULTS_PATH` 接受显式官方 `eval_result/_result.txt` 或结构化导出。真实模拟器/策略对齐需要上游 SAPIEN/Curobo 资产与策略权重，并用官方脚本执行。

主指标是 `success_rate`。

| Metric | 含义 | 方向 |
| --- | --- | --- |
| `success_rate` | 评测 rollout 上的主成功率（逐 episode 成功比例）。 | 越高越好 |
| `task_success` | 按任务聚合的成功率。 | 越高越好 |
| `episode_success` | 逐 episode 成功指示的聚合值。 | 越高越好 |
| `bimanual_task_success` | 双臂协同任务的成功率聚合。 | 越高越好 |
| `domain_randomization_success` | 官方域随机化条件下的成功率。 | 越高越好 |
| `clean_success` | clean（无随机化）条件下的成功率。 | 越高越好 |
| `randomized_success` | 随机化杂物/光照/背景条件下的成功率。 | 越高越好 |
| `reward` | 平均 episode 奖励 / 回报。 | 越高越好 |

## 运行评测

目录 manifest 记录的 validation 命令：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id robotwin \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir <out> \
  --json
```

## 权重与环境变量

- `WORLDFOUNDRY_ROBOTWIN_ROOT`: 可选覆盖项，指向本地 benchmark runtime / 仓库根目录。
- `WORLDFOUNDRY_ROBOTWIN_RESULTS_PATH`: 未显式传 `--official-results-path` 时，导入器默认从该路径读取官方结果导出文件。

该 benchmark 复用共享 base-model 依赖栈：`robotwin_dataset_assets`。

## 输出文件

运行会在 `--output-dir` 下写出：

- `scorecard.json`: WorldFoundry 统一 scorecard，记录上表中的指标值。
- `benchmark_contract.json`: 本次运行的 benchmark contract 记录（输入、模式、来源信息）。
- `task_manifest.json`
- `official_command_manifest.json`
- `simulator_validation.json`
- `raw_metric_table.jsonl`: 支撑 scorecard 的原始 metric 行。
- `evaluation/per_sample_metrics.jsonl`

Scorecard 主键：`success_rate`（leaderboard key `success_rate`），写入 `scorecard.json`。

## 边界与限制

- 结果导入仅为归一化；完整 leaderboard 对齐需用就位资产与权重执行上游 SAPIEN/Curobo 模拟器与策略脚本。
- 2026-05-25 的有界模拟器验证在本地达到 CUDA 驱动分配，但上游 `script/test_render.py` 超过硬超时；本环境中 SAPIEN/Vulkan 渲染仍被阻塞。
- RoboTwin 2.0 是具身双臂操作评测，不是视频生成评测。
