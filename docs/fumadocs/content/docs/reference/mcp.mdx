WorldFoundry exposes the same catalogs and evaluation contracts through an MCP server so agents can discover models, benchmarks, metrics, and runs without a private backend.

## Install

```bash
python -m pip install -e ".[mcp]"
```

## Start

```bash
worldfoundry-mcp
# or
worldfoundry-eval mcp
```

`server_info` lists tool names, output roots, and documentation paths. Prefer discovery tools (`list_models`, `list_benchmarks`, `list_tasks`, `list_metrics`) before `evaluate`.
