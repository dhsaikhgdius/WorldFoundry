# Echo-Memory network components

This package contains the checkpoint-specific network components used by the
native Echo-Memory recipes. The reusable memory lifecycle, model assembly, and
runtime contract live in the shared WorldFoundry diffusion infrastructure.

These modules are not a standalone command-line entry point. For public usage,
checkpoint layout, and current validation status, see:

- [Inference guide](../../../../../../docs/fumadocs/content/docs/guides/inference.mdx)
- [Local asset preparation](../../../../../../docs/fumadocs/content/docs/guides/local-assets.mdx)
- [Validation reference](../../../../../../docs/fumadocs/content/docs/reference/validation.mdx)
