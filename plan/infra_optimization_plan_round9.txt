6. pyproject extras / 可选依赖分层
---------------------------------
来源：主会话本地评审。
勿重复 round1 conda/pip 分层、round8 WF-01 ruff CI pin / WF-04/09 发布冒烟。

[EX-01] P0 ``[ui]`` gradio 未 pin → Studio 启动失败
  问题：``pyproject.toml`` ``ui`` 列表为裸 ``gradio``；AGENTS.md 已记录 Gradio 6 去掉
        ``app.add_event_handler`` → ``'FastAPI' object has no attribute 'add_event_handler'``。
  改法：``gradio>=5.50,<6``（或与现网一致的精确 pin）+ ``starlette<1`` 若需显式；
        加 eval_core 契约：解析 ``[ui]`` 断言 gradio 上界 <6。
  文件：``pyproject.toml``、``test/eval_core/test_packaging_dependencies.py``、AGENTS.md（已有警告可保留）

[EX-02] P1 ``dev`` / ``dependency-groups.lint`` 写 ``ruff>=0.12.7``
  问题：与 Makefile/pre-commit/AGENTS.md 的 ``ruff==0.12.7`` 分叉；``pip install -e ".[dev]"``
        会漂到新 ruff 改 import-sort。
  改法：两处改为 ``ruff==0.12.7``。交叉：round8 WF-01（CI workflow）。
  文件：``pyproject.toml`` ``[project.optional-dependencies].dev``、``[dependency-groups].lint``

[EX-03] P1 ``[all]`` 与专项 extra pin 互相矛盾
  问题：``molmoact2`` 要求 ``transformers>=4.57,<4.58``，``all``/``train_core`` 为 ``<5``；
        ``train_core`` ``torch>=2.9`` vs ``optimized_core``/``all`` ``>=2.7``；
        ``all`` 中 ``av`` 无上界而 ``train_video`` 为 ``av>=12,<20``。
        同环境 ``pip install -e ".[all,molmoact2]"`` 或组合训练 extras 时解析不确定/失败。
  改法：为 ``all`` 取各专项约束的**可解析交集**或从 ``all`` 排除互斥专项并文档化；
        加「两两 extra 组合可解析」轻量门（或至少 all+molmoact2 / all+train_core）。
  文件：``pyproject.toml``、``test/eval_core/test_packaging_dependencies.py``

[EX-04] P1 无 eval_core / 测试用 extra
  问题：CPU 发布门 ``make test-eval-core`` 依赖 torch 等，不在任何声明 extra；
        云环境靠 update 脚本手工装，贡献者 ``pip install -e .`` 后直接 make 易 ImportError。
  改法：新增 ``eval_core``（或 ``test``）extra：CPU torch 索引说明 + 套件真实 import 集；
        ``make test-eval-core`` 文档写明 ``pip install -e ".[eval_core]"``。
  文件：``pyproject.toml``、``Makefile`` help、quickstart/AGENTS.md

[EX-05] P2 ``make install-dev`` 绕过 ``[dev]``
  问题：目标手写 ``build pre-commit PyYAML ruff``，与 ``[dev]`` 不同步（缺/多包、ruff 无 pin）。
  改法：改为 ``$(PIP) install -e ".[dev]"``（PyYAML 若仍需要则并入 ``[dev]``）。
  文件：``Makefile``

[EX-06] P2 optional-dependencies vs dependency-groups 双轨
  问题：``dependency-groups`` 含 flash_attn_*、runtime_*_bundle、transformers_high/low 等，
        docs/quickstart 几乎只教 ``pip install -e ".[extra]"``；两套何时用未说明。
  改法：environments 或 packaging 文档一小节：extras=用户面安装；groups=锁/工具链内部；
        列出现有 groups 名称与用途。
  文件：``docs/fumadocs/content/docs/reference/`` 或 guides/install

[EX-07] P2 文档称 ``[ui]`` 已含 realtime，实际缺依赖
  问题：``studio.zh.mdx`` 写 ``worldfoundry[ui]`` 已包含 ``studio_realtime``；
        但 ``studio_realtime`` 有 ``numpy``/``pillow``，``[ui]`` 名字集合中没有二者。
  改法：``[ui]`` 显式 include realtime 依赖（或文档改为 ``.[ui,studio_realtime]``）；
        契约测试：``names(studio_realtime) ⊆ names(ui)``（忽略版本时）。
  文件：``pyproject.toml``、``docs/.../guides/studio{,.zh}.mdx``、packaging 测试

[EX-08] P3 多 extra 同装 peft 等冲突
  问题：``distribution_metrics`` ``peft>=0.2`` vs ``train_core`` ``peft>=0.14,<1``（可解析但下限漂移）。
  改法：统一下限到 train_core 或文档标注互斥组合。

[EX-09] P3 extras 矩阵文档缺失
  改法：一张表列出全部 optional-dependencies 名称、用途、是否进 ``all``、典型命令。
