0. 现状一句话
--------------
Studio 进程组终止链质量高，但默认把 HF 端点指到第三方镜像、关停被作业挂住、媒体 Range 全表重扫；
embodied DLC 多分片未接线、许可证闸门指向不存在 CLI 旗标；训练 exact-resume 强但 torchrun 失败无 traceback 汇聚；
CLI operators 漏注册、catalog YAML 纯 Python 解析、evaluation.utils 拖慢冷启动。


1. 不建议改的地方
------------------
Studio：不要换外部队列；不要改 resident worker JSON-line 协议；不要放松失败即退休 worker；
不要动进程组终止链；不要放宽 artifact 精确路径访问模型（只优化索引，见 ST-03）。
Embodied：保留 BaseSimulator + SIMULATOR_ENTRIES；不要清理 behavior1k signal 猴补丁等防御代码；
ensure_license fail-closed 只修 EM-02 指引；17 个 python_env 容器名不统一；merge_results 走 existing-results。
Training：保留 DCP 原子提交链、exact-resume 默认 fail-closed、DistributedTrainingContext 语义、Ray STRICT_PACK；
不要加训练循环周期 barrier（TE-07）。
CLI：operators 惰性 __getattr__、TUI 子进程模型、_extract_logging_flags、CudaDeviceLeasePool 轮询取消。
第 1–5 轮边界继续有效。

3. Studio workspace
-------------------
来源：[Studio 云端子代理](bc-f4904408-a50e-56a5-8461-497bc3a35cbe)

[ST-01] P0 子进程默认 HF_ENDPOINT 指第三方镜像
  文件：studio/conda_dispatch.py _runtime_env ~1553
  改法：删 setdefault("HF_ENDPOINT","https://hf-mirror.com")；增 WORLDFOUNDRY_HF_ENDPOINT opt-in；
        文档写 local-assets.mdx。

[ST-02] P1 Ctrl+C 被运行中作业无限挂住
  文件：studio/jobs.py、workspace_app.py shutdown
  改法：StudioJobStore.shutdown(grace)；cancel_requested + executor.shutdown(wait=False)；
        交叉：round1 R-03 孤儿对账，此处补优雅关停。

[ST-03] P1 媒体热路径全量重扫 workspace
  文件：workspace_app.py _registered_artifact_paths；execution.py list_recent_runs/load_run
  改法：load_run 直读 manifest；list_recent_runs 缓存；增量 artifact 索引。

[ST-04] P1 可视化启动持全局锁最长 120s
  文件：workspace_app.py _launch_visualizer_locked
  改法：锁内仅登记，锁外轮询就绪；per-mode 锁；就绪判定 <400。

[ST-05] P2 一次性 dispatch 无超时；nvidia-smi 无 timeout
  文件：conda_dispatch.py _run_manager_payload_in_conda_impl、_parse_nvidia_smi_rows
  改法：复用 resident 超时 env；nvidia-smi timeout=10 降级。

[ST-06] P2 常驻 worker acquire 持生命周期锁且无取消
  交叉：round6 CL-02；acquire 出锁 + cancel_requested + deadline。

[ST-07] P2 评测作业在 FastAPI 进程内且不可取消
  文件：workspace_app.py _run_evaluation
  改法：短期阶段边界查 cancel；中期走 runtime_job 子进程。

[ST-08] P2 作业日志内存无上限
  文件：jobs.py append_log
  改法：append 期环形截断；日志偏移用单调计数器。

[ST-09] P3 workspace 产物无保留策略
  改法：WORLDFOUNDRY_STUDIO_RUNS_KEEP + mtime 清理 runtime_jobs/visualizer 日志。

[ST-10] P3 run_workspace.sh 参数与目录优先级
  改法：--max-jobs/--port 校验；env-file vs 邻目录 ckpt 冲突 WARNING；合并 Python 预检。

[ST-11] P3 _runtime_cache_dir 默认 /tmp 且 mkdir 吞错
  改法：默认 ~/.cache/worldfoundry/runtime-cache；失败 log + tempfile 回退。

[ST-12] P1 execution.py atomic=False（主会话补充）
  交叉：round5 IO-01；与 runtime_job._write_json_atomic 统一。

  改法：DistributedSpec.timeout_seconds + device_id=local_rank。

  改法：per-rank runtime 键；inspect 仅 rank0 + broadcast。

  改法：save_on_completion 默认开。

8. 验收（汇总）
---------------
- ST-01：dispatch 子进程 env 无默认 HF_ENDPOINT；opt-in 后透传。
- ST-02：SIGTERM 后 ≤15s 退出，无 orphan GPU 子进程。
- ST-03：500 runs 上 100 次 Range，manifest 全扫 ≤1 次。
- EM-01：DLC workers=2 产生 shard0of2/shard1of2 且 rank0 merge。
- EM-02：--accept-license 通过闸门；docker -e 可见。
- TR-01：单 rank 抛错时 torchrun 摘要含 traceback。
- TR-07：steps=1000 save_every=300 结束后 latest 指向 step-1000。
- CL-01~04：同 §6 子代理验收（DualCamCtrl import；acquire 可取消；catalog ≤1.5s；cli import ≤0.2s）。
